# 巡检测试用例

> 版本: v0.1.0
> 最后更新: 2026-09-21

## 核心测试要点

> 巡检是**唯一跨端闭环**的模块：Web 端创建并指派 → 移动端由被指派人完成 → 回收为巡检记录。
> 三个关键点：
>
> 1. **发布即生效**——`CreateTask` 后 `status` 直接为 `published`，不是 `pending`（`pending` 表示「待发布」）
> 2. **越权拦截**——`FinishTask` 必须校验 `userID == task.inspector_id`，否则任一用户可完成他人任务
> 3. **记录快照**——`InspectRecord` 冗余保留 `task_name`/`inspector`/`content`/`region_id`/`location`，
>    使任务被改动或删除后记录仍可独立查看

## InspectService

### 1. 创建巡检任务
- **测试方法**: `TestInspectService_CreateTask`
- **输入**: `CreateInspectTaskReq{Name:"东门日巡", RegionID:r, Location:"东门", InspectorID:u, Content:"检查摄像头角度与遮挡", PlanDT:tomorrow, Remark:"重点区域"}`
- **预期结果**: 创建成功，**并逐字段核对**：`name`="东门日巡"、`region_id`=r、`location`="东门"、`inspector_id`=u、`content`="检查摄像头角度与遮挡"、`plan_dt` 等于传入时间、`remark`="重点区域"、`active`=true、`dept_id`、`created_by`、`created_dt`
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 2. 任务状态默认值 —— 发布即生效
- **测试方法**: `TestInspectService_CreateTask_DefaultStatus`
- **输入**: 不传 `status`
- **预期结果**: 回读 `ac_inspect_task.status == "published"`（**不是 `pending`**——任务创建即发布，被指派人立即可见）；`read`=false、`read_dt`=nil
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 3. 创建任务校验
- **测试方法**: `TestInspectService_CreateTask_Validation`
- **输入**: ① 缺 `inspector_id`；② `inspector_id` 指向不存在的用户；③ 缺 `name`；④ 缺 `plan_dt`
- **预期结果**: 均返回明确错误；`ac_inspect_task` **不新增**记录（不产生无巡检人的孤儿任务）
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 4. 获取任务详情
- **测试方法**: `TestInspectService_GetTask`
- **输入**: 任务 ID
- **预期结果**: 返回 `*model.InspectTask`，逐字段核对 `name`/`region_id`/`location`/`inspector_id`/`content`/`plan_dt`/`status`/`read`/`remark`；`Preload Region` 后 `Region.Name` 非空
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 5. 查看任务转为已读
- **测试方法**: `TestInspectService_GetTask_MarkRead`
- **输入**: 任务 `read=false` 时调用 `GetTask`
- **预期结果**: `read` 变为 **true**、`read_dt` 非空；`status` 与其他字段不变（对应页面「点击查看，且该消息通知由未读转为已读状态」）
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 6. 任务分页查询
- **测试方法**: `TestInspectService_PageTasks`
- **输入**: `PageInspectTaskReq{Page:1, PageSize:20}`
- **预期结果**: 返回 `PageInspectTaskResp`；`total`/`page`/`page_size` 正确；`items` 长度 = `min(page_size, total)`；软删除记录不返回
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 7. 任务列表关联名称回显
- **测试方法**: `TestInspectService_PageTasks_Preload`
- **输入**: 任务绑定区域后调用 `PageTasks`
- **预期结果**: `items[0].Region.Name` 等于区域名称（**列表必须展示区域名称，不能只展示 `region_id`**）
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 8. 任务列表过滤
- **测试方法**: `TestInspectService_PageTasks_Filters`
- **输入**: 按 `region_id`、`name`（模糊）、`inspector_id`、`plan_dt` 时间范围、`status` 分别过滤
- **预期结果**: 各条件命中数正确；时间范围为闭区间；组合条件为 AND
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 9. 更新巡检任务
- **测试方法**: `TestInspectService_UpdateTask`
- **输入**: 改 `name`/`region_id`/`location`/`inspector_id`/`content`/`plan_dt`/`remark`
- **预期结果**: 上述 7 字段全部更新为输入值；`updated_by`/`updated_dt` 刷新；`status`/`read`/`created_by`/`created_dt` 不变
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 10. 编辑已完成任务被拒
- **测试方法**: `TestInspectService_UpdateTask_Finished`
- **输入**: 对 `status=finished` 的任务调用 `UpdateTask`
- **预期结果**: 返回明确错误；该任务全部字段**未被修改**（已完成任务不可再编辑）
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 11. 删除巡检任务
- **测试方法**: `TestInspectService_DeleteTask`
- **输入**: 任务 ID
- **预期结果**: `ac_inspect_task.deleted_at` 非空（软删除）；`PageTasks` 不再返回且 `total` 减 1；**已生成的巡检记录仍存在**（记录持有快照，不随任务删除而丢失）
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 12. 完成任务生成巡检记录
- **测试方法**: `TestInspectService_FinishTask`
- **输入**: `FinishTask(taskID, userID, FinishInspectTaskReq{Result:"角度已调整", ResultImage:"/upload/i.png"})`，其中 `userID` == 任务的 `inspector_id`
- **预期结果**:
  - `ac_inspect_record` **新增 1 条**，**逐字段核对**：`task_id`=taskID、`task_name`（快照）、`region_id`（快照）、`location`（快照）、`inspector_id`、`inspector`（冗余登录名）、`content`（快照）、`plan_dt`（快照）、`result`="角度已调整"、`result_image`="/upload/i.png"、`handled_dt` 非空、`status`="finished"、`dept_id`、`created_by`
  - `ac_inspect_task.status` **更新为 `finished`**
  - `ac_inspect_task.read` 更新为 `true`
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 13. 记录快照独立性
- **测试方法**: `TestInspectService_FinishTask_Snapshot`
- **输入**: 完成任务生成记录后，修改任务的 `name`/`content`/`location`
- **预期结果**: `ac_inspect_record` 的 `task_name`/`content`/`location` **保持生成时的值不变**（快照语义，用于任务被改动后记录仍可独立查看）
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 14. 越权完成他人任务
- **测试方法**: `TestInspectService_FinishTask_Forbidden`
- **输入**: `FinishTask(taskID, userID=B)`，而任务 `inspector_id = A`
- **预期结果**: 返回明确错误（403 级）；`ac_inspect_record` **不新增**记录；`ac_inspect_task.status` **保持 `published`**；`read` 不变
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 15. 重复完成幂等
- **测试方法**: `TestInspectService_FinishTask_Idempotent`
- **输入**: 对同一任务连续两次 `FinishTask`
- **预期结果**: 第二次返回明确错误（任务已 `finished`）；`ac_inspect_record` 中该 `task_id` **仅 1 条**（不产生重复记录）
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 16. 任务状态流转完整性
- **测试方法**: `TestInspectService_FinishTask_StatusFlow`
- **输入**: 创建 → 完成 → 再查询
- **预期结果**: `status` 走 `published` → `finished`；`PageTasks(status="published")` 完成后**不再包含**该任务；`PageTasks(status="finished")` 包含（对应「处理后该巡检任务就会移除」）
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 17. 记录分页查询与过滤
- **测试方法**: `TestInspectService_PageRecords_Filters`
- **输入**: `PageInspectRecordReq{Page:1, PageSize:20}` + `region_id`/`task_name`/`inspector_id`/`handled_dt` 时间范围过滤
- **预期结果**: 返回 `PageInspectRecordResp`；各条件命中数正确；`items` 中 `result`/`result_image`/`handled_dt`/`status` 完整
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 18. 获取记录详情
- **测试方法**: `TestInspectService_GetRecord`
- **输入**: 记录 ID
- **预期结果**: 返回 `*model.InspectRecord`，**并逐字段核对**：`task_id`、`task_name`、`region_id`、`location`、`inspector_id`、`inspector`、`content`、`plan_dt`、`result`、`result_image`、`handled_dt`、`status`；`Preload Region` 后 `Region.Name` 非空
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 19. 巡检数据权限
- **测试方法**: `TestInspectService_PageTasks_DataScope`
- **输入**: 四种 `DataScope`
- **预期结果**: 任务与记录的可见行数均满足 `personal ≤ dept ≤ cross_dept ≤ all`
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`

### 20. 跨端闭环
- **测试方法**: `TestIT_InspectTaskClosure`
- **输入**: Web 端 `CreateTask` → 移动端 `AppService.PageInspectTasks(inspectorID)` → `AppService.FinishInspectTask` → Web 端 `PageRecords`
- **预期结果**: 移动端任务列表含该任务；完成后 Web 端记录列表出现对应记录，字段与移动端提交内容一致；Web 端任务列表不再包含该任务（Web 与 App 共用同一 Service 实现，结果必须一致）
- **覆盖文件**: `backend/tests/inspect/inspect_service_test.go`
