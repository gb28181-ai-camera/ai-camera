## 二、执行方式

### 2.1 Web 端（Playwright）

测试代码位于 `frontend/e2e/`，截图归档至 `frontend/e2e/screenshots/`。

```bash
# 1. 环境准备
cd backend && go run ./tests/testutil/resetdb/main.go
cd backend && go run ./tests/testutil/initdb/main.go

# 2. 启动后端（测试配置）
export CONFIG_PATH="config/config-test.yaml" && cd backend && go run ./cmd/server/main.go

# 3. 启动前端 dev server（Vite 代理 /web/*、/app/* 到 :8080）
cd frontend && npm run dev

# 4. 执行
cd frontend && npx playwright test                       # 全量
cd frontend && npx playwright test --reporter=list        # 带步骤输出
cd frontend && npx playwright test --ui                   # 交互调试
```

**冒烟子集**（`frontend/e2e/smoke/`）：

```bash
# 串行执行，spec 按文件名字母序运行
cd frontend && npx playwright test e2e/smoke --workers=1
```

> **注意 1**：冒烟测试必须 `--workers=1` 串行执行——用例间存在数据依赖（前一条创建的数据供后一条使用）。
>
> **注意 2**：执行顺序规范——必须先执行所有功能测试（`01a` ~ `10f`），
> 最后执行 `99-all-list-page.spec.ts`（全页面覆盖验证）。
> `99-` 前缀保证其排在最后；新增冒烟文件编号**必须小于 99**。
>
> **注意 3**：执行完成后必须关闭前后端服务，避免端口冲突影响下次执行。

### 2.2 移动端（Flutter）

```bash
cd app && flutter test          # 单元/Widget 测试
cd app && flutter analyze       # 静态检查，要求 0 error 0 warning
cd app && flutter run           # 真机/模拟器手工验证
```

## 三、E2E Modal class 规范（强制）

### 3.1 规则

- **禁止**使用通用 `.ant-modal` 选择器：`.ant-modal`、`.ant-modal .ant-modal-footer`、
  `page.locator('.ant-modal').last()`、`page.locator('.ant-modal-footer button.ant-btn-primary')`
- **必须**使用页面上已定义的 `e2e-xxx-modal` CSS class 精确定位

**理由**：当存在嵌套弹窗（如「处理风险」Modal 内打开「图片预览」、表单 Modal 内打开
「设备选择」SelectorModal）时，通用 `.ant-modal` 会匹配到错误的弹窗，导致测试不稳定
（偶发失败、断言到父弹窗的内容）。

### 3.2 正确与错误示例

```ts
// ✅ 正确：使用 e2e class 精确定位
await page.locator('.e2e-region-modal').getByLabel('区域名称').fill('厂区A')
await page.locator('.e2e-region-modal').getByRole('button', { name: '确定' }).click()

// ✅ 正确：SelectorModal 的 Modal 与触发按钮分别定位
await page.locator('.e2e-device-select-btn').click()          // 触发按钮
await page.locator('.e2e-device-select').getByText('D-001').click()  // 弹窗内选择

// ❌ 错误：通用选择器
await page.locator('.ant-modal').last().getByRole('button', { name: '确定' }).click()
await page.locator('.ant-modal-footer button.ant-btn-primary').click()
```

### 3.3 新增 Modal 的要求

任何新建的 Ant Design `<Modal>` 组件，**必须**添加 `className="e2e-xxx-modal"` 属性：

```tsx
<Modal
  className="e2e-risk-handle-modal"   // ← 必须
  title="处理风险"
  open={open}
  onOk={onOk}
  onCancel={onCancel}
>
  {/* ... */}
</Modal>
```

`SelectorModal` 已支持 `className` 传递——`<SelectorModal className="e2e-xxx">`
会同时把 class 应用到 Modal（`.e2e-xxx`）与触发按钮（`.e2e-xxx-btn`），
测试中可分别使用：

```tsx
<SelectorModal
  className="e2e-device-select"        // → Modal: .e2e-device-select，按钮: .e2e-device-select-btn
  open={open}
  onSelect={onSelect}
/>
```

## 四、典型链路写法

### 4.1 E2E-01 登录与首页

```ts
import { test, expect } from '@playwright/test'

test('E2E-01 登录并进入首页', async ({ page }) => {
  // 步骤 1：打开登录页
  await page.goto('/admin/')

  // 步骤 2：填写账号密码
  await page.getByLabel('用户名').fill('admin')
  await page.getByLabel('密码').fill('123456')

  // 步骤 3：提交
  await page.getByRole('button', { name: '登 录' }).click()

  // 步骤 4：断言跳转
  await expect(page).toHaveURL(/dashboard/)

  // 步骤 5：断言 token 已写入
  const token = await page.evaluate(() => localStorage.getItem('token'))
  expect(token).toBeTruthy()

  // 步骤 6：断言首页统计卡片渲染
  await expect(page.getByText('今日预警')).toBeVisible()
  await page.screenshot({ path: 'e2e/screenshots/e2e-01-dashboard.png' })
})
```

### 4.2 E2E-04 风险全流程（含 Modal 定位）

```ts
test('E2E-04 风险详情 → 处理风险 → 状态转已处理', async ({ page }) => {
  await login(page, 'admin', '123456')
  await page.goto('/admin/#/risk/monitor')

  // 定位表格第一行
  const row = page.locator('.ant-table-tbody tr').first()
  const riskId = await row.getAttribute('data-row-key')

  // 打开详情 —— 使用 e2e class，禁止 .ant-modal
  await row.getByRole('button', { name: '查看' }).click()
  const detail = page.locator('.e2e-risk-detail-modal')
  await expect(detail).toBeVisible()
  await expect(detail.getByText('检测准确')).toBeVisible()

  // 关闭详情，打开处理弹窗
  await detail.getByRole('button', { name: 'Close' }).click()
  await row.getByRole('button', { name: '处理' }).click()

  const handle = page.locator('.e2e-risk-handle-modal')
  await expect(handle).toBeVisible()

  // 填写处理结果（此处不应匹配到详情弹窗）
  await handle.getByLabel('处理结果').fill('已现场清理并复位')
  await handle.getByRole('button', { name: '确定' }).click()

  // 断言状态变更
  await expect(row.getByText('已处理')).toBeVisible()
  await page.screenshot({ path: 'e2e/screenshots/e2e-04-risk-handled.png' })
})
```

### 4.4 E2E-13 权限显隐

```ts
test('E2E-13 未授权菜单不显示、未授权按钮隐藏', async ({ page }) => {
  // 以仅授权「风险监控」的角色登录
  await login(page, 'risk_op', '123456')

  // 侧边栏：仅授权菜单可见
  await expect(page.getByRole('menuitem', { name: '风险统计' })).toBeVisible()
  await expect(page.getByRole('menuitem', { name: '系统管理' })).toHaveCount(0)

  // 按钮级权限（permission_code 驱动）
  await page.goto('/admin/#/risk/monitor')
  await expect(page.getByRole('button', { name: '处理' })).toBeVisible()
  await expect(page.getByRole('button', { name: '删除' })).toHaveCount(0)

  // 直接访问未授权路由 → 403 或重定向
  await page.goto('/admin/#/system/users')
  await expect(page.getByText('权限不足')).toBeVisible()
})
```
