## 3. Web 页面功能

### 3.1 国标设备 `/gb/device/list`

- **主要操作**：分页查询（设备名称 / 设备编号 / 国标编码 / 注册状态 / 区域）；查看详情；
  同步通道；订阅 / 取消订阅目录；生成激活凭证；删除设备（级联软删除其通道）。
- **列表字段**：设备名称、设备编号、国标编码、所属区域、在线状态、注册状态、通道数、最近注册时间。
- **权限码**：`gb:device:list`、`gb:device:sync-channel`、`gb:device:subscribe`、
  `gb:device:activation`、`gb:device:delete`。
- **关键接口**：`GET /web/gb/devices`、`GET /web/gb/devices/:id`、
  `POST /web/gb/devices/:id/sync-channel`、`POST|DELETE /web/gb/devices/:id/subscribe`、
  `POST /web/gb/devices/:id/activation`、`DELETE /web/gb/devices/:id`。
- **e2e class**：`e2e-gb-device-table`、`e2e-gb-device-detail-modal`、
  `e2e-gb-device-subscribe-modal`、`e2e-gb-device-activation-modal`。

### 3.2 国标通道 `/gb/device/channel`

- **主要操作**：分页查询（通道名称 / 国标通道编码 / 所属设备 / 区域 / 业务分组 / 在线状态）；
  编辑通道；设置区域；设置业务分组；重置通道；删除通道。
- **列表字段**：通道名称、国标通道编码、所属设备、所属区域、业务分组、在线状态、录像计划、同步时间。
- **权限码**：`gb:channel:list`、`gb:channel:update`、`gb:channel:region`、
  `gb:channel:group`、`gb:channel:reset`、`gb:channel:delete`。
- **关键接口**：`GET /web/gb/channels`、`GET /web/gb/channels/options`、
  `GET|PUT|DELETE /web/gb/channels/:id`、`PUT /web/gb/channels/:id/region`、
  `PUT /web/gb/channels/:id/group`、`POST /web/gb/channels/:id/reset`。
- **e2e class**：`e2e-gb-channel-table`、`e2e-gb-channel-edit-modal`、
  `e2e-gb-channel-region-modal`、`e2e-gb-channel-group-modal`。
- **说明**：「重置通道」清空用户自定义字段（名称、区域、分组、流 ID、录像计划、广播开关、备注、同步时间），
  **不会重新向设备查询目录**；重新拉取目录应使用设备页的「同步通道」。

### 3.3 设备激活 `/gb/device/activation`

- **主要操作**：查询设备国标接入信息；生成 / 查看激活凭证（国标编码、SIP 密码、服务器、域、二维码）。
- **权限码**：`gb:activation:list`、`gb:device:activation`。
- **关键接口**：`GET /web/gb/devices`、`POST /web/gb/devices/:id/activation`。
- **e2e class**：`e2e-gb-activation-table`、`e2e-gb-activation-modal`。
- **说明**：凭证生成幂等；已存在国标编码 / 密码时返回原值。

### 3.4 订阅记录 `/gb/device/subscribe`

- **主要操作**：分页查询（设备、订阅类型、状态）；新增订阅（catalog / alarm / mobile_position）；
  删除订阅。
- **列表字段**：设备名称、设备编码、订阅类型、状态、间隔（秒）、Call-ID、创建时间、到期时间。
- **权限码**：`gb:subscription:list`、`gb:subscription:create`、`gb:subscription:delete`。
- **关键接口**：`GET|POST /web/gb/subscribes`、`DELETE /web/gb/subscribes/:id`。
- **e2e class**：`e2e-gb-subscribe-table`、`e2e-gb-subscribe-create-modal`。

### 3.5 实时播放 `/gb/media/live`

- **主要操作**：选择设备 / 通道；播放 / 停止；云台方向与变焦 / 光圈 / 聚焦；
  预置位新增 / 调用 / 删除；巡航 / 扫描；抓图；语音广播 / 对讲；视频最大化。
- **权限码**：`gb:live:list`、`gb:live:play`、`gb:live:ptz`、`gb:live:snap`、
  `gb:live:broadcast`、`gb:live:talk`。
- **关键接口**：`POST /web/gb/play/:channelId`、`POST /web/gb/play/:channelId/stop`、
  `GET /web/gb/play/:channelId/status`、`POST /web/gb/play/:channelId/snapshot`；
  `POST /web/gb/ptz/:channelId`、预置位 / 巡航 / 扫描 / 雨刷端点；
  `POST /web/gb/voice/:channelId/broadcast|talk/start|stop`。
- **e2e class**：`e2e-gb-channel-tree`、`e2e-gb-snapshot-modal`。
- **播放器策略**：WebRTC(WHEP) 优先，失败自动回落 HTTP-FLV（`mpegts.js`），HLS 保底。
  播放器只接收地址参数，不自行调用后端接口。

### 3.6 录像回放 `/gb/media/playback`

- **主要操作**：选择通道与时间范围检索设备侧录像；开始回放；暂停 / 恢复 / 拖动 / 倍速；停止回放。
- **列表字段**：名称、类型、开始时间、结束时间、时长、文件路径。
- **权限码**：`gb:playback:list`、`gb:playback:play`、`gb:playback:control`。
- **关键接口**：`GET /web/gb/playback/records`、`POST /web/gb/playback`、
  `POST /web/gb/playback/control`、`POST /web/gb/playback/stop`。
- **e2e class**：本页暂无独立 Modal，未定义 `e2e-gb-*` class（以源码实测为准）。
- **说明**：回放控制走带内 SIP INFO + MANSRTSP；检索超时返回已收到的部分并标记 `timeout`。

### 3.7 录像下载 `/gb/media/download`

- **主要操作**：新建下载任务（通道 + 时间范围）；分页查看任务；取消下载。
- **列表字段**：通道、时间段、状态、进度、文件大小、创建时间、提示。
- **权限码**：`gb:record-download:list`、`gb:record-download:start`、`gb:record-download:cancel`。
- **关键接口**：`POST|GET /web/gb/playback/download`、`DELETE /web/gb/playback/download/:id`。
- **e2e class**：`e2e-gb-download-modal`。
- **已知限制**：任务只存在于进程内存，重启丢失；「文件大小」在后端未提供时展示为提示。

### 3.8 云端录像 `/gb/media/cloud-record`

- **主要操作**：按日期 / 通道筛选；播放；下载；收藏 / 取消收藏；删除索引。
- **列表字段**：通道、文件、开始时间、结束时间、时长、文件大小、收藏。
- **权限码**：`gb:cloud-record:list`、`gb:cloud-record:play`、`gb:cloud-record:download`、
  `gb:cloud-record:collect`、`gb:cloud-record:delete`。
- **关键接口**：`GET /web/gb/cloud-records/dates`、`GET|DELETE /web/gb/cloud-records`、
  `PUT /web/gb/cloud-records/collect`、`GET /web/gb/cloud-records/:id/play`、
  `GET /web/gb/cloud-records/:id/download`。
- **e2e class**：`e2e-gb-cloud-play-modal`。
- **已知限制**：当前 `on_record_mp4` 未写索引，新录像不会自动出现在列表；
  下载只支持单文件，`packaging=false`。

### 3.9 录像计划 `/gb/media/record-plan`

- **主要操作**：分页查询；新增 / 编辑计划（名称、抓图、备注、一周时间段）；删除；
  关联通道（多选）。
- **列表字段**：计划名称、状态、抓图、时间段数、绑定通道、备注、更新时间。
- **权限码**：`gb:record-plan:list`、`gb:record-plan:create`、`gb:record-plan:update`、
  `gb:record-plan:delete`、`gb:record-plan:bind`。
- **关键接口**：`GET|POST /web/gb/record-plans`、`GET|PUT|DELETE /web/gb/record-plans/:id`、
  `PUT /web/gb/record-plans/:id/channels`。
- **e2e class**：`e2e-gb-record-plan-modal`、`e2e-gb-record-plan-bind-modal`。
- **已知限制**：只做配置，不调度录制。

### 3.10 国标报警 `/gb/alarm/list`

- **主要操作**：按时间 / 类型 / 处理状态筛选；查看详情；处理；抓图；清空。
- **列表字段**：设备 / 通道名称、报警时间、报警类型、等级、处理状态、处理人。
  > 处理人列读取 `updated_by`，但当前 `GbAlarmItem` / `GbAlarmDetailResp` **未返回该字段**，
  > 实际显示为 `-`；后端写入的是 `ac_gb_alarm.updated_by`。属已知前后端字段缺口，
  > 修正方向是在响应结构体补 `updated_by` 并重新生成前端类型。
- **权限码**：`gb:alarm:list`、`gb:alarm:handle`、`gb:alarm:snap`、`gb:alarm:delete`。
- **关键接口**：`GET /web/gb/alarms`、`GET /web/gb/alarms/:id`、
  `POST /web/gb/alarms/:id/snapshot`、`PUT /web/gb/alarms/:id/handle`、`DELETE /web/gb/alarms`。
- **e2e class**：`e2e-gb-alarm-detail-modal`、`e2e-gb-alarm-handle-modal`、`e2e-gb-alarm-snap-modal`。

### 3.11 移动位置 `/gb/alarm/position`

- **主要操作**：查看最新位置；实时位置列表；按通道与时间查询历史；订阅位置上报。
- **列表字段**：设备名称、通道名称、国标通道编码、上报时间、经度、纬度、海拔、速度、方向。
- **权限码**：`gb:position:list`、`gb:position:subscribe`。
- **关键接口**：`GET /web/gb/positions/latest`、`GET /web/gb/positions/realtime`、
  `GET /web/gb/positions/history`、`POST /web/gb/positions/subscribe`。
- **e2e class**：`e2e-gb-position-subscribe-modal`。
- **说明**：本期以表格展示经纬度，无地图底图。

### 3.12 媒体节点 `/gb/ops/media-server`

- **主要操作**：节点列表；新增 / 编辑 / 删除；在线检查；查看节点信息（线程负载、录像配置）。
- **列表字段**：节点名称、`server_id`、类型、API 地址、在线状态、默认节点、最近心跳、录像保留、负载、线程。
- **权限码**：`gb:media-server:list`、`gb:media-server:create`、`gb:media-server:update`、
  `gb:media-server:delete`、`gb:media-server:check`。
- **关键接口**：`GET|POST /web/gb/media-servers`、`GET|PUT|DELETE /web/gb/media-servers/:id`、
  `GET /web/gb/media-servers/:id/check`、`GET /web/gb/media-servers/:id/info`。
- **e2e class**：`e2e-gb-media-server-modal`、`e2e-gb-media-server-check-modal`、
  `e2e-gb-media-server-info-modal`。
- **说明**：`GET /web/gb/media-servers` 是**简单列表**（`RGbMediaServerList`），不是分页。

### 3.13 拉流代理 `/gb/ops/stream-proxy`

- **主要操作**：分页查询；新增 / 编辑 / 删除；启动 / 停止拉流。
- **列表字段**：名称、应用名、流 ID、源地址、状态、启用、备注、更新时间。
- **权限码**：`gb:stream-proxy:list`、`gb:stream-proxy:create`、`gb:stream-proxy:update`、
  `gb:stream-proxy:delete`、`gb:stream-proxy:start`、`gb:stream-proxy:stop`。
- **关键接口**：`GET|POST /web/gb/stream-proxies`、`PUT|DELETE /web/gb/stream-proxies/:id`、
  `POST /web/gb/stream-proxies/:id/start|stop`。
- **e2e class**：`e2e-gb-stream-proxy-modal`。
- **说明**：启动才调用 ZLM `addStreamProxy`；编辑配置不会触发重连。

### 3.14 推流 `/gb/ops/stream-push`

- **主要操作**：分页查询；新增 / 编辑 / 删除；启用 / 停用；复制推流地址。
- **列表字段**：名称、应用名、流 ID、推流地址、状态、启用配置、启用时间、备注。
- **权限码**：`gb:stream-push:list`、`gb:stream-push:create`、`gb:stream-push:update`、
  `gb:stream-push:delete`、`gb:stream-push:start`、`gb:stream-push:stop`。
- **关键接口**：`GET|POST /web/gb/stream-pushes`、`PUT|DELETE /web/gb/stream-pushes/:id`、
  `POST /web/gb/stream-pushes/:id/start|stop`。
- **e2e class**：`e2e-gb-stream-push-modal`。
- **已知限制**：Start / Stop 只改状态与时间，不做真实推流。

### 3.15 信令日志 `/gb/ops/sip-log`

- **主要操作**：按设备编码 / SIP 方法 / 命令类型 / 结果 / 时间筛选；查看统计卡片；打开详情抽屉；复制报文。
- **列表字段**：时间、方向、方法、命令类型、SIP 状态码、结果、原因、设备编码、远端地址。
- **权限码**：`gb:sip-log:list`。
- **关键接口**：`GET /web/gb/sip-logs`、`GET /web/gb/sip-logs/:id`、`GET /web/gb/sip-logs/stats`。
- **e2e class**：`e2e-gb-sip-log-drawer`。
- **说明**：本模块唯一**不走 DataScope** 的列表（表无 `dept_id`）。

### 3.16 上级平台 `/gb/platform/list`

- **主要操作**：分页查询；新增 / 编辑 / 删除；设置推送分组；设置推送区域。
- **列表字段**：平台名称、平台编码、SIP 域、地址、用户名、传输协议、在线状态、启用状态、创建时间。
- **权限码**：`gb:platform:list`、`gb:platform:create`、`gb:platform:update`、
  `gb:platform:delete`、`gb:platform:groups`、`gb:platform:regions`。
- **关键接口**：`GET|POST /web/gb/platforms`、`GET|PUT|DELETE /web/gb/platforms/:id`、
  `PUT /web/gb/platforms/:id/groups`、`PUT /web/gb/platforms/:id/regions`。
- **e2e class**：`e2e-gb-platform-modal`、`e2e-gb-platform-groups-modal`、`e2e-gb-platform-regions-modal`。
- **已知限制**：仅配置，不发起真实级联注册 / 目录推送。

### 3.17 级联通道 `/gb/platform/channel`

- **主要操作**：选择上级平台；分页查看已推送通道；添加通道；定制通道编码 / 名称等；移除通道。
- **列表字段**：设备名称、设备编号、通道名称、国标编码、定制编码、定制名称、所属区域、业务分组、状态、更新时间。
- **权限码**：`gb:platform-channel:list`、`gb:platform-channel:add`、

## 6. 关键接口字段

字段级定义以契约 §15 为准，本节只列页面最常依赖的字段，**不重复整段**。

### 6.1 播放（契约 §15.1）

`POST /web/gb/play/:channelId` 请求 `{ protocol: "webrtc" | "flv" | "hls", stream_id? }`，
响应关键字段：

| 字段 | 说明 |
|:---|:---|
| `app` | 恒为 `rtp` |
| `stream` | `%08X(ssrc)` 大写 16 进制 |
| `ssrc` | 10 位十进制，供排障 |
| `http_base` | ZLM HTTP 基址，如 `http://10.0.0.5:8082` |
| `webrtc` / `flv` / `hls` | 三条完整播放 URL |
| `media_server_id` | 节点 `serverId` |
| `stream_id` | 会话标识，停止时回传 |

> 前端二选一：直接用整串 URL，或用 `http_base + app + stream` 自行拼接。
> `LivePlayer` 同时支持两种入参。

### 6.2 云台（契约 §15.2）

| 字段 | 取值 |
|:---|:---|
| `direction` | `up` / `down` / `left` / `right` / `up-left` / `up-right` / `down-left` / `down-right` / `stop` |
| `speed` | **1–8**（缺省 5） |
| `action` | `""` / `zoom-in|zoom-out|zoom-stop` / `iris-in|iris-out|iris-stop` / `focus-near|focus-far|focus-stop` |

预置位编号 1–255；巡航 / 扫描 `action` 为 `start` / `stop`，带 `group_id`。

### 6.3 回放控制（契约 §15.3）

`stream_id` + `action`（`pause` / `resume` / `seek` / `speed`）；
`seek` 时 `seek_time` 为 `2006-01-02T15:04:05`；`speed` 时 `scale` 为倍率（1.0 原速）。

### 6.4 语音会话（契约 §15.4）

`session_id`、`type`（`broadcast` / `talk`）、`mode`（恒 `half_duplex`）、
`agent_enabled`、`ssrc`、`audio_codec`（`G.711A`）、`start_dt`。

### 6.5 设备 / 通道列表的关联名称

列表不只返回 ID，必须返回名称字段（`CLAUDE.md` 后端开发规范）：

| 实体 | 关联名称字段 |
|:---|:---|
| 国标设备 | `region_name` |
| 国标通道 | `device_name`、`device_code`、`region_name`、`group_name`、`record_plan_name` |
| 云端录像 | `device_name`、`channel_name` |
| 国标报警 | `device_name`、`channel_name` |
| 移动位置 | `device_name`、`channel_name` |
| 级联通道 | 设备名称 / 编号、通道名称、区域名、分组名 |
| 媒体节点 | 节点名称（`name`） |

### 6.6 敏感字段

以下字段在**所有读接口**中返回 `****`；写接口收到空值或含 `****` 时保持原值：

`ac_device.sip_password`、`ac_gb_media_server.secret`、`ac_gb_platform.password`、
`ac_gb_channel.password`（以及语音 Agent 的 `*_api_key` / `pipecat_token`）。

## 8. 页面状态说明

| 场景 | 表现 |
|:---|:---|
| 设备未注册 / 离线 | 实时播放、云台、回放接口返回明确业务错误；页面提示设备离线 |
| 通道未同步 | 通道下拉为空；需先在设备页点「同步通道」 |
| 无可用媒体节点 | 播放返回「流媒体节点不可用，请检查默认节点配置」 |
| INVITE 成功但 5s 内无流 | 返回「设备未在限定时间内推送媒体流」，不挂死 HTTP |
| 信令服务未启动 | 播放 / 云台 / 回放返回「信令服务未启动」（分进程部署的已知限制，见需求文档 §8） |
| 同一通道已有语音会话 | 返回「该通道已有进行中的语音会话，请先停止」 |
| 语音 Agent 不可达 | 对讲降级为纯对讲，`agent_enabled=false`，不报错 |
| 云端录像无索引 | 列表为空；新录像需等待索引落库能力补齐 |
| 无权限 | 按钮由 `permCodes` 隐藏；接口层由 Casbin 返回 403 |
