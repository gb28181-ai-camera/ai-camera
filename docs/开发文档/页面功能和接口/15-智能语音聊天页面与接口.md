## 1. Web 管理端 `/voice/agent`

菜单：智能语音聊天 → 语音 Agent（`voice:agent:view`）。

| Tab | 能力 | 主要接口 |
|:--|:--|:--|
| 基础 | STT/LLM/TTS/VAD provider、控制面地址/令牌 | `GET/PUT /web/settings/voice-agent`、`/providers`、`/test`、`/apply` |
| WebSocket | ws_enabled/ws_path/fast_ack_text/device_wake_word；连接测试 | `POST /web/voice/ws-ticket` → `GET /web/voice/ws` |
| MCP | 工具列表、启用/风险等级/需确认、调用日志 | `GET /web/voice/mcp/tools`、`PUT /web/voice/mcp/tools/:id`、`GET /web/voice/mcp/logs` |
| 记忆 | 列表/搜索/删除/CSV 导出 | `GET /web/voice/memories`、`/export`、`DELETE /web/voice/memories/:id` |
| 观测 | Pipecat 地址/WS 开关/应用配置 | 暂无健康/会话端点 |

E2E class：`e2e-voice-agent-tabs`、`e2e-voice-connect-btn`、`e2e-voice-ws-log`、
`e2e-voice-mcp-tool-table`、`e2e-voice-memory-table`、`e2e-voice-mcp-tool-modal`、
`e2e-voice-memory-modal`。

## 2. Flutter App `/voice`

- 入口：首页「语音聊天」、国标实时播放页对讲旁。
- 半双工按住说话/点击开始；PCM16 16k 上行、24k 下行；字幕与 MCP 工具提示。
- 接口：`POST /app/voice/ws-ticket` → `GET /app/voice/ws?ticket=...`。
- 权限：`app:voice`（移动端菜单 109）。

## 3. 设备端

- AIChat 设备：`GET /device/voice/ws`，HTTP Basic 使用产品×AIChat 服务凭据。
- 协议支持 hello/listen/detect/abort/tts/mcp；Opus v1。
- 服务端工具通过 `/internal/mcp` 暴露；设备工具通过同一条 WS 的 `type=mcp`。

## 4. 数据与隐私

- 不存原始音频；逐字稿表默认不启用。
- 长期记忆按 user/device/dept/global 隔离，默认 180 天；可删除/导出。
- 内部 token、embedding key 读接口脱敏。
