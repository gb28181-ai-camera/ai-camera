## 1. 文档目的

本文档集面向「AI Camera — AI 智能监控平台」的前后端联调与验收，逐页描述：

- 页面承载的业务功能（含搜索条件、排序、批量操作、按钮行为、状态流转）；
- 页面调用的后端接口清单；
- 每个接口的请求参数与响应数据示例。

接口的**唯一权威来源**是 [后端开发/00-接口契约.md](../后端开发/00-接口契约.md)。本文档不改写、
不新增、不省略任何路由；如两者出现冲突，以契约文档为准并同步修正本文档。

页面结构与内容取自产品手册《AI摄像头操作手册 - 43-8101》，与手册章节一一对应。

## 3. 统一响应格式

### 3.1 响应包装

所有接口（含错误）统一返回 `{code, message, data}` 三段式：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | 业务状态码，`200` 表示成功 |
| `message` | string | 提示信息，成功时为 `success`，失败时为具体原因 |
| `data` | any | 业务载荷，可能为对象、数组或 `null` |

常用状态码：

| code | 含义 | 典型场景 |
|:----:|---|---|
| 200 | 成功 | 查询、新增、修改、删除成功 |
| 400 | 参数错误 | 必填项缺失、格式不合法 |
| 401 | 未认证 | Token 缺失或过期，前端跳转登录页 |
| 403 | 无权限 | Casbin 校验不通过或数据权限不足 |
| 404 | 资源不存在 | ID 对应的记录已被删除 |
| 500 | 服务异常 | 数据库或内部错误 |

### 3.2 分页结构

分页接口的 `data` 固定为 `{items, total, page, page_size}`：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "items": [],
    "total": 0,
    "page": 1,
    "page_size": 20
  }
}
```

统一查询参数：`page`（默认 1，最小 1）、`page_size`（默认 20，范围 1~200）。
分页响应类型必须为**类型化**的 `RPageXxx`，禁止裸用 `PageResp`。

### 3.3 简单列表与下拉选项

简单列表（无分页）的 `data` 直接为数组：

```json
{
  "code": 200,
  "message": "success",
  "data": []
}
```

`/options` 类下拉接口统一返回 `OptionItem` 数组：

```json
{
  "code": 200,
  "message": "success",
  "data": [
    { "id": 1, "name": "1号仓库北门", "code": "REG001" }
  ]
}
```

`code` 为可选字段，仅在实体本身具备编码时返回。

计数类接口（待处理数、未读数）的 `data` 为整数：

```json
{ "code": 200, "message": "success", "data": 12 }
```

### 3.4 关联名称规范

列表接口涉及多表关联时，**必须返回关联对象的名称字段**，不得只返回外键 ID。
后端通过 GORM `Preload` 实现，前端读取 `item.device.name`、`item.region.name`、
`item.risk_type.name` 等。前端**禁止**用 `as any` 绕过类型。

## 4. 认证与数据权限

| 层 | 机制 |
|---|---|
| 认证 | 登录后返回 JWT，请求头携带 `Authorization: Bearer <token>` |
| 鉴权 | Casbin RBAC，策略由「角色 → 菜单 → 菜单 API」三级推导 |
| 数据权限 | JWT 携带 `data_perm`，后端按 `dept_id` 施加行级过滤 |

角色可配置的数据权限取值：

| 取值 | 含义 |
|---|---|
| `all` | 全部数据 |
| `cross_dept` | 指定部门数据（由 `cross_dept_ids` 指定） |
| `dept` | 本部门及下级部门数据 |
| `personal` | 仅本人创建的数据 |

> **注意**：`ac_menu`、`ac_role` 等无 `dept_id` 列的表不做行级过滤。
> 「设备告警设置」「风险通知设置」只允许操作**当前登录用户**自己的数据。

## 5. 通用接口

除页面业务接口外，平台还提供以下与页面无关的公共接口，在此统一说明。

### 5.1 健康检查

**GET /health**

响应数据：

```json
{ "code": 200, "message": "success", "data": { "status": "ok" } }
```

### 5.2 文件上传

**POST /web/upload**

请求参数（`multipart/form-data`）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|:----:|---|
| `file` | file | 是 | 图片/文档文件 |

响应数据：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "url": "/uploads/2026/09/21/xxx.png",
    "file_name": "xxx.png",
    "file_size": 204800
  }
}
```

**POST /web/upload/audio**

请求参数（`multipart/form-data`）：字段名同为 `file`，仅接受音频文件（mp3/wav）。
响应结构同上，用于「语音配置管理」的播报音频上传。

### 5.3 设备上报接口（ApiKey 认证）

以下接口供设备/边缘网关调用，使用 `X-Api-Key` 请求头认证，不走 JWT。
ApiKey 在「个人中心 → API 密钥」中生成与吊销。

**POST /web/risks/report** — 设备上报 AI 风险

请求参数：

```json
{
  "device_code": "CAM-0001",
  "risk_type_code": "fire",
  "image_url": "/uploads/risk/20260921/a.jpg",
  "video_url": "/uploads/risk/20260921/a.mp4",
  "detect_score": 0.93,
  "occurred_dt": "2026-09-21 10:30:00",
  "location": "北门入口"
}
```

响应数据：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1001,
    "device_id": 5,
    "device_code": "CAM-0001",
    "risk_type_id": 3,
    "risk_level": "high",
    "status": "pending",
    "read": false,
    "occurred_dt": "2026-09-21T10:30:00+08:00"
  }
}
```

**POST /web/alarms/report** — 设备上报告警

请求参数：

```json
{
  "device_code": "CAM-0001",
  "alarm_type_code": "battery",
  "content": "设备电量低于 20%",
  "alarm_level": "high",
  "occurred_dt": "2026-09-21 10:31:00"
}
```

响应数据：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 2001,
    "device_id": 5,
    "device_code": "CAM-0001",
    "alarm_type_id": 2,
    "alarm_level": "high",
    "status": "pending",
    "read": false
  }
}
```

**POST /web/devices/:id/heartbeat** — 设备心跳上报

设备上报运行时快照（电量/电压/存储/在线状态），后端写入 `ac_device` 最新快照
并追加一条 `ac_device_history` 时序记录。

请求参数：

```json
{
  "status": "online",
  "battery": 86,
  "voltage": "3.92",
  "storage_total": 32768,
  "storage_free": 12040
}
```

响应数据：

```json
{ "code": 200, "message": "success", "data": true }
```
