## 2. 实时监控

### 2.1 页面功能

- **布局切换**：支持三种分屏布局——**单屏**（1 路）、**4 宫格**（2×2，4 路）、**9 宫格**（3×3，9 路）。
  切换布局时已选中的摄像头按顺序填充窗口，多余的窗口为空占位。
- **区域选择（必选）**：先选择所属区域（`region_id`），区域数据来自区域管理。
- **摄像头选择（必选）**：区域选定后再选择摄像头。**必须先选区域和摄像头，才会显示视频监控画面**；
  未选择时窗口显示占位提示。
- **视频播放**：每个窗口播放所选设备的实时视频流。视频地址取自设备的 `stream_url`（RTSP/HTTP-FLV），
  设备离线时无法播放并给出提示。
- **在线状态校验**：仅 `status = online` 的设备可以播放实时视频；离线设备在摄像头选择器中标记为不可用。
- **加入监控**：可通过「加入监控/移出监控」开关切换设备的 `monitor_enabled`，
  控制该设备是否出现在「设备监控」的实时视频列表中（与「设备管理」页的「设备监控」按钮等价）。
- **单窗口操作**：每个窗口支持全屏放大、静音、关闭（释放窗口）与快照，快照调用 `POST /web/upload` 保存图片。
- **数据权限**：区域与摄像头选项均按当前用户数据权限过滤，用户只能看到自己可见范围内的设备。

> **注意**：实时监控页**不产生业务记录**，仅读取设备与区域数据并播放视频流，
> 因此接口清单集中在「资源管理」与「基础信息」两组的查询端点上。

> **注意**：视频流为客户端直连设备（或流媒体网关），不经过后端转发；
> 后端只负责下发 `stream_url`。

### 2.2 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/web/basic/regions/options` | 区域下拉选项（选择区域） |
| GET | `/web/devices/options` | 设备下拉选项（选择摄像头） |
| GET | `/web/devices` | 设备分页列表（按区域过滤，取 `stream_url`） |
| GET | `/web/devices/:id` | 设备详情（单个窗口按需获取视频流地址） |
| PUT | `/web/devices/:id/monitor` | 加入/移出实时监控 |

### 2.3 接口数据格式

**GET /web/basic/regions/options**

请求参数：无。

响应数据：

```json
{
  "code": 200,
  "message": "success",
  "data": [
    { "id": 1, "name": "北门区域", "code": "REG001" },
    { "id": 2, "name": "南门区域", "code": "REG002" }
  ]
}
```

**GET /web/devices/options**

请求参数：

```json
{ "region_id": 1 }
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|:----:|---|
| `region_id` | int64 | 是 | 所选区域，实时监控必须先选区域 |

响应数据：

```json
{
  "code": 200,
  "message": "success",
  "data": [
    { "id": 5, "name": "北门摄像头", "code": "CAM-0001" },
    { "id": 6, "name": "北门摄像头2", "code": "CAM-0002" }
  ]
}
```

> **注意**：选项接口只返回 `id` / `name` / `code`，**不含**在线状态与视频流地址；
> 播放前需再调用 `GET /web/devices` 或 `GET /web/devices/:id` 获取 `status` 与 `stream_url`。

**GET /web/devices**

请求参数：

```json
{
  "page": 1,
  "page_size": 9,
  "region_id": 1,
  "status": "online"
}
```

> 单屏布局取 `page_size = 1`，4 宫格取 4，9 宫格取 9。

响应数据：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 5,
        "name": "北门摄像头",
        "device_code": "CAM-0001",
        "region_id": 1,
        "location": "北门入口左侧立杆",
        "status": "online",
        "battery": 86,
        "storage_free": 12040,
        "last_beat_dt": "2026-09-21T10:31:00+08:00",
        "monitor_enabled": true,
        "stream_url": "rtsp://192.168.1.51:554/live",
        "region": { "id": 1, "name": "北门区域", "code": "REG001" }
      }
    ],
    "total": 1,
    "page": 1,
    "page_size": 9
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `status` | string | `online` / `offline`，离线设备禁止播放 |
| `stream_url` | string | 实时视频流地址，供播放器直连 |
| `monitor_enabled` | bool | 是否已加入实时监控 |
| `region.name` | string | **所属区域名称**（关联名称，非 ID） |

**GET /web/devices/:id**

请求参数：路径参数 `id`（设备 ID）。

响应数据（`RDevice`）：单条设备对象，结构同列表条目，用于单窗口按需刷新 `stream_url` 与在线状态。

**PUT /web/devices/:id/monitor**

请求参数：

```json
{ "enabled": true }
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|:----:|---|
| `enabled` | bool | 是 | `true` 加入监控，`false` 移出监控 |

响应数据：

```json
{ "code": 200, "message": "success", "data": null }
```

### 2.4 页面状态说明

| 场景 | 表现 |
|---|---|
| 未选区域 | 摄像头选择器禁用并提示「请先选择区域」 |
| 已选区域未选摄像头 | 视频窗口显示占位图与提示「请选择摄像头」 |
| 设备离线 | 窗口显示「设备离线」遮罩；`status = offline` 时不发起拉流 |
| 流地址为空 | 窗口显示「未配置视频流地址」提示 |
| 切换布局 | 已选摄像头按序保留在窗口 1..N，超出部分释放 |
