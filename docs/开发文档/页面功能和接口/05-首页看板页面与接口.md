## 2. 首页

### 2.1 页面功能

- **今日预警 / 今日处理**：指标卡，分别展示当天新增的风险与告警记录总数（`today_alarm`）与当天已处理完成数（`today_handled`）。
- **本周预警 / 本周处理**：指标卡，统计范围为自然周（周一 00:00:00 至当前时刻）。
- **本月预警 / 本月处理**：指标卡，统计范围为自然月。
- **设备统计**：指标卡，展示设备总数、在线数量、离线数量（`device.total` / `device.online` / `device.offline`）。
- **风险类型分析**：图表，按风险类型汇总记录数，用于展示各类型的占比；
  渲染时读取 `risk_type_stats[].name`（风险类型名称）与 `risk_type_stats[].level`（等级，决定配色）。
- **风险处理统计**：图表，展示未处理数（`pending`）、已处理数（`handled`）与处理率（`handled_rate`）。
- **区域风险统计**：图表，按区域汇总风险数，读取 `region_risk_stats[].region_name` 作为横轴标签。
- **风险分析**：折线/柱状趋势图，按日期展示风险发生数与处理数（`risk_trend`）。
- **告警分析**：折线/柱状趋势图，按日期展示告警发生数与处理数（`alarm_trend`）。
- **待办角标**：侧边栏「AI风险」「设备告警」菜单展示未处理数量角标，数据分别来自
  `GET /web/risks/pending-count` 与 `GET /web/alarms/pending-count`。
- **数据权限**：所有统计结果按当前登录用户的数据权限（`data_perm`）过滤，用户只能看到自己可见范围内的数据。
- **跳转**：点击各指标卡/图表区块可跳转到对应的明细页（风险监控 / 设备告警 / 设备管理）。

> **注意**：首页所有指标均由单个聚合接口 `GET /web/stats/dashboard` 一次返回，
> 避免首屏发起多次请求；待办角标为独立端点，便于轮询刷新。

> **注意**：统计类接口的 `data` 载荷由 `response.DashboardResp` 定义（`internal/dto/response/stats.go`），
> 字段为 snake_case。前端必须使用生成的强类型访问，禁止 `as any`。

### 2.2 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/web/stats/dashboard` | 首页看板聚合数据 |
| GET | `/web/risks/pending-count` | 未处理风险数（待办角标） |
| GET | `/web/alarms/pending-count` | 未处理告警数（待办角标） |

### 2.3 接口数据格式

**GET /web/stats/dashboard**

请求参数：无（统计范围由后端按服务器当前时间推导，数据权限取自 Token）。

响应数据（`RDashboard`）：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "today_alarm": 12,
    "today_handled": 9,
    "week_alarm": 68,
    "week_handled": 55,
    "month_alarm": 240,
    "month_handled": 210,
    "device": {
      "total": 120,
      "online": 98,
      "offline": 22
    },
    "risk_type_stats": [
      { "risk_type_id": 3, "name": "烟火识别", "code": "fire", "level": "high", "count": 30 },
      { "risk_type_id": 4, "name": "未戴安全帽", "code": "no_helmet", "level": "medium", "count": 18 }
    ],
    "risk_handle_stats": {
      "pending": 25,
      "handled": 215,
      "handled_rate": 89.6
    },
    "region_risk_stats": [
      { "region_id": 1, "region_name": "北门区域", "count": 40 },
      { "region_id": 2, "region_name": "南门区域", "count": 22 }
    ],
    "risk_trend": [
      { "date": "2026-09-19", "count": 15, "handled": 13 },
      { "date": "2026-09-20", "count": 22, "handled": 18 },
      { "date": "2026-09-21", "count": 12, "handled": 9 }
    ],
    "alarm_trend": [
      { "date": "2026-09-19", "count": 4, "handled": 4 },
      { "date": "2026-09-20", "count": 6, "handled": 5 },
      { "date": "2026-09-21", "count": 3, "handled": 2 }
    ]
  }
}
```

字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| `today_alarm` | int64 | 今日风险 + 告警新增总数 |
| `today_handled` | int64 | 今日已处理完成数 |
| `week_alarm` / `week_handled` | int64 | 本周新增 / 已处理 |
| `month_alarm` / `month_handled` | int64 | 本月新增 / 已处理 |
| `device.total` / `device.online` / `device.offline` | int64 | 设备统计 |
| `risk_type_stats[].name` | string | **风险类型名称**（关联名称，非 ID） |
| `risk_type_stats[].level` | string | 等级 `high` / `medium` / `low` |
| `risk_handle_stats.handled_rate` | float64 | 处理率，百分比数值（保留一位小数） |
| `region_risk_stats[].region_name` | string | **区域名称**（关联名称，非 ID） |

> **注意**：`risk_type_stats` 与 `region_risk_stats` 体现「返回关联名称而非仅 ID」规范；
> `risk_type_id` / `region_id` 仅作为点击跳转的参数保留。

**GET /web/risks/pending-count**

请求参数：无。

响应数据（`RCount`）：

```json
{ "code": 200, "message": "success", "data": 25 }
```

**GET /web/alarms/pending-count**

请求参数：无。

响应数据（`RCount`）：

```json
{ "code": 200, "message": "success", "data": 7 }
```

> **注意**：两个 `pending-count` 接口的统计口径为 `status = "pending"`（未处理），
> 与「消息通知」的已读状态（`read`）无关。详见 `07` 与 `08` 文档。
