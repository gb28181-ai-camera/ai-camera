# 基础信息 - 页面功能与接口

> 版本: v0.1.0
> 最后更新: 2026-09-21

## 1. 页面列表

| 序号 | 页面名称 | 路由 | 类型 | 说明 |
|:----:|---------|------|:----:|------|
| 1 | 区域管理 | `/settings/region` | 列表页 | 区域是设备/风险/告警/巡检的核心归属维度 |
| 2 | 风险类型管理 | `/settings/risk-type` | 列表页 | 风险类型与风险等级，驱动风险分级与配色 |
| 3 | 告警类型管理 | `/settings/alarm-type` | 列表页 | 内置离线/电量/流量告警，可扩展 |

> **注意**：基础信息是平台的**根数据**。按操作手册的日常流程，应依次完成
> 「新建区域 → 新增设备并选择区域 → 配置风险类型/固件/模型」，之后才能在风险监控中看到数据。

## 2. 区域管理

### 2.1 页面功能

- **列表字段**：区域名称、区域编码、备注、排序、状态、创建时间。
- **搜索条件**：区域名称关键字（`keyword`）、状态（`active`）。
- **新增区域**：点「新增」添加区域，填写区域名称、区域编码、排序、备注、状态。
- **编辑区域**：点「编辑」修改区域内容；点「确定」提示保存成功即生效，点「取消」不修改。
- **删除区域**：点「删除」并确认后删除该条数据；点「取消」则取消删除。
- **下拉数据源**：区域选项（`GET /web/basic/regions/options`）供设备管理、物联网卡管理、语音配置、巡检任务、风险/告警筛选等页面使用。
- **数据权限**：列表按 `dept_id` 施加行级过滤。

> **注意**：区域被设备引用后不建议删除；删除前应先确认该区域下已无设备、物联网卡与巡检任务。

### 2.2 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/web/basic/regions` | 区域分页列表 |
| GET | `/web/basic/regions/options` | 区域下拉选项 |
| GET | `/web/basic/regions/:id` | 区域详情 |
| POST | `/web/basic/regions` | 新增区域 |
| PUT | `/web/basic/regions/:id` | 编辑区域 |
| DELETE | `/web/basic/regions/:id` | 删除区域 |

### 2.3 接口数据格式

**GET /web/basic/regions**

请求参数：

```json
{
  "page": 1,
  "page_size": 20,
  "keyword": "北门",
  "active": true
}
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|:----:|---|
| `page` | int | 否 | 页码，默认 1 |
| `page_size` | int | 否 | 每页条数，默认 20，最大 200 |
| `keyword` | string | 否 | 匹配 `name` 或 `code` |
| `active` | bool | 否 | 启用状态 |

响应数据：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 1,
        "active": true,
        "sequence": 10,
        "name": "北门区域",
        "code": "REG001",
        "remark": "厂区北门及周边",
        "dept_id": 2,
        "created_by": "admin",
        "created_dt": "2026-09-01T08:00:00+08:00",
        "updated_by": "admin",
        "updated_dt": "2026-09-10T09:00:00+08:00"
      }
    ],
    "total": 1,
    "page": 1,
    "page_size": 20
  }
}
```

**GET /web/basic/regions/options**

请求参数：无（内部按当前用户数据权限过滤）。

响应数据：

```json
{
  "code": 200,
  "message": "success",
  "data": [
    { "id": 1, "name": "北门区域", "code": "REG001" },
    { "id": 2, "name": "南门区域", "code": "REG002" }
  ]
}
```

**GET /web/basic/regions/:id**

请求参数：路径参数 `id`（int64）。

响应数据（`RRegion`）：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "active": true,
    "sequence": 10,
    "name": "北门区域",
    "code": "REG001",
    "remark": "厂区北门及周边",
    "dept_id": 2,
    "created_dt": "2026-09-01T08:00:00+08:00"
  }
}
```

**POST /web/basic/regions**

请求参数：

```json
{
  "name": "北门区域",
  "code": "REG001",
  "sequence": 10,
  "remark": "厂区北门及周边",
  "active": true

```

响应数据：返回新建的区域对象（结构同详情）。

**PUT /web/basic/regions/:id**

请求参数：同新增（可只提交需修改的字段）。

响应数据：

```json

```

**DELETE /web/basic/regions/:id**

请求参数：路径参数 `id`。

响应数据：

```json
{ "code": 200, "message": "success", "data": null }
```

## 3. 风险类型管理

### 3.1 页面功能

- **列表字段**：风险类型（`name`）、风险编码（`code`）、风险等级（`level`）、描述、状态、排序、创建时间。
- **搜索条件**：风险类型关键字（`keyword`）、风险等级（`level`）、状态（`active`）。
- **新增风险类型**：点「新增」填写风险类型名称、风险编码、风险等级、描述等信息。
- **编辑风险类型**：点「编辑」修改风险内容；点「确定」保存成功即生效，点「取消」不修改。
- **删除风险类型**：点「删除」并确认后删除；点「取消」则取消删除。
- **风险等级**：取值 `high`（高）/ `medium`（中）/ `low`（低），决定风险列表与首页/大屏的分级统计与告警配色。
- **下游联动**：风险类型是「语音配置管理」的语音类型、「风险通知设置」的通知维度、设备 AI 上报（`risk_type_code`）的匹配依据。

> **注意**：风险类型被风险记录引用后不建议删除，删除会导致历史记录的风险类型名称无法展示。

### 3.2 接口列表

|------|------|------|
| GET | `/web/basic/risk-types` | 风险类型分页列表 |
| GET | `/web/basic/risk-types/options` | 风险类型下拉选项 |
| GET | `/web/basic/risk-types/:id` | 风险类型详情 |
| POST | `/web/basic/risk-types` | 新增风险类型 |
| PUT | `/web/basic/risk-types/:id` | 编辑风险类型 |

## 4. 告警类型管理

### 4.1 页面功能

- **列表字段**：告警名称、告警编码、告警等级、描述、状态、排序、创建时间。
- **搜索条件**：告警名称关键字（`keyword`）、告警等级（`level`）、状态（`active`）。
- **内置告警类型**：平台内置三类告警，种子数据同时写入，编码固定不可改：
  - `offline` — 离线告警（设备心跳超时）
  - `battery` — 电量告警（电量低于阈值）
  - `traffic` — 流量告警（物联网卡剩余流量低于阈值）
- **自定义扩展**：可新增自定义告警类型，供设备通过 `POST /web/alarms/report` 上报。
- **编辑告警类型**：点「编辑」修改告警名称、等级、描述。
- **删除告警类型**：点「删除」并确认后删除；内置类型不建议删除。
- **下游联动**：告警类型是「设备告警设置」的配置维度，也是设备上报（`alarm_type_code`）的匹配依据。

### 4.2 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/web/basic/alarm-types` | 告警类型分页列表 |

| GET | `/web/basic/alarm-types/:id` | 告警类型详情 |
| POST | `/web/basic/alarm-types` | 新增告警类型 |
| PUT | `/web/basic/alarm-types/:id` | 编辑告警类型 |

## 5. 等级取值对照

风险类型与告警类型的 `level` 字段取值一致：

| 取值 | 中文 | 前端表现 |
|---|---|---|
| `high` | 高 | 红色标签，首页/大屏高危统计 |
| `medium` | 中 | 橙色标签，默认值 |
| `low` | 低 | 蓝色标签 |

> **注意**：`level` 在创建风险/告警记录时会**冗余**写入 `risk_level` / `alarm_level`，
> 保证历史记录在类型等级被修改后仍保留当时的等级快照。
