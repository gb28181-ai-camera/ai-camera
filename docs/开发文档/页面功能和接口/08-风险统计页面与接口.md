## 2. 风险监控

### 2.1 页面功能

- **数据来源**：风险监控数据来源于设备拍摄并上报的风险数据，包含风险类型、风险图片、设备名称、设备编号、
  所属区域、发生时间、检测准确、消息通知、状态等。
- **搜索条件**：风险类型（`risk_type_id`）、所属区域（`region_id`）、发生时间范围（`start_dt` ~ `end_dt`）、
  状态（`status`）、设备名称（`keyword`）、设备编号（`device_code`）、风险等级、检测准确。
- **点选筛选**：点击列表中「风险类型」，可直接筛选出该类型的所有数据；「设备名称」与「设备编号」筛选方法相同。
- **查看**：点击「查看」查看风险监控详细信息，且该消息通知**由未读转为已读**，同时可修改检测是否准确。
- **处理风险**：
  - 「检测准确」点「**否**」→ 该条数据**直接转为已处理状态**，且消息通知转为已读；
  - 「检测准确」点「**是**」→ 消息通知转为已读，可继续对该数据进行处理；
    点击「处理」按钮填写处理结果及处理图片，处理后状态**由未处理转为已处理**。
- **检测准确修改**：对风险图片进行查看，确认检测物体是否准确后可修改监控检测准确性；点击「无」即可改判为误报。
- **查看录像**：点击录像按钮查看该风险的视频录像。
- **跳转设备监控**：点击设备跳转按钮，可跳转至「设备监控」模块的设备详情中，
  方便快速查询该设备名称的设备监控数据（跳转携带 `device_id`）。
- **查看实时监控画面**：点击实时监控按钮，查看该设备当前的实时监控画面。
- **删除**：点击「删除」并确认删除后，可对该条数据进行删除。
- **刷新频率**：可设置风险监控页面刷新频率，分别可设置为 **10 秒 / 30 秒 / 60 秒**。
- **数据权限**：列表按 `dept_id` 施加行级过滤。

> **注意**：本页与「AI风险」页共用 `/web/risks` 全部端点，差异仅在页面默认筛选与跳转入口。

## 3. 设备监控

### 3.1 页面功能

- **列表字段**：设备名称、设备编号、所属区域、设备位置、电量、存储容量、在线-离线时间、运行状态、实时视频、视频录像。
- **搜索条件**：运行状态（`status`）、所属区域（`region_id`）、设备名称（`keyword`）、设备编号（`device_code`）。
- **排序**：点击「设备编号」列头，可按设备编号进行正序或倒序排序。
- **查看实时视频**：点击「查看实时视频」，播放该设备的实时监控画面（**需设备在线**，`status = online`）。
- **查看录像**：点击「查看录像」，播放该设备的历史录像（需设备在线或存在录像文件）。
- **跳转风险监控**：点击列表中「设备名称」，跳转至「风险监控」模块并筛选出该设备名称的所有风险监控数据
  （跳转携带 `device_id`，目标页调用 `GET /web/risks?device_id=…`）。
- **运行指标**：电量（`battery`，百分比）、电压（`voltage`）、存储容量（`storage_total` / `storage_free`，MB）、
  最近上线时间（`online_dt`）、最近离线时间（`offline_dt`）、最近心跳时间（`last_beat_dt`）。
- **加入监控**：通过 `PUT /web/devices/:id/monitor` 控制设备是否出现在本页的实时视频列表中
  （与「设备管理」页的「设备监控」按钮等价）。
- **数据权限**：列表按 `dept_id` 施加行级过滤。

> **注意**：本页的「实时视频」按钮在设备离线时禁用；`stream_url` 为空时提示「未配置视频流地址」。

| GET | `/web/basic/regions/options` | 所属区域下拉选项 |
| GET | `/web/risks` | 跳转风险监控时按设备筛选风险 |

## 4. GIS 查看

### 4.1 页面功能

- **地图打点**：在 GIS 地图上按设备的 `latitude` / `longitude` 渲染设备图标；
  缺少坐标的设备不在地图上显示，并在列表中以「未定位」标记。
- **悬浮信息**：鼠标移至图标上可查看该设备的相关信息（设备名称、设备编号、所属区域、设备位置、
  运行状态、电量、最近心跳时间）。
- **查看风险**：点击图标气泡中的「查看风险」，跳转至「风险监控」模块并筛选该设备的风险信息
  （跳转携带 `device_id`）。
- **区域过滤**：可先选择区域（`region_id`）再渲染地图，减少打点数量。
- **状态着色**：在线设备与离线设备使用不同图标颜色，便于一眼识别。

### 4.2 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/web/devices` | 设备分页列表（含经纬度与状态） |
| GET | `/web/devices/:id` | 设备详情（点击气泡时按需获取） |
| GET | `/web/basic/regions/options` | 区域下拉选项 |
| GET | `/web/risks` | 跳转风险监控时按设备筛选风险 |

### 4.3 接口数据格式

**GET /web/devices**

请求参数：


## 5. 设备历史记录

### 5.1 页面功能

- **列表字段**：设备名称、设备编号、流量卡号、所属区域、设备位置、电量、电压、剩余存储容量、
  在线-离线时间、运行状态、历史曲线。
- **搜索条件**：运行状态（`status`）、所属区域（`region_id`）、设备名称/编号（`keyword` / `device_code`）、
  采样时间范围（`start_dt` ~ `end_dt`）。
- **查看图表**：点击「查看图表」可查看**近 3 日**的运行状态统计、电量统计、存储容量统计、
  状态与电量统计、电压与电量统计等图表信息（`GET /web/devices/:id/history-chart?days=3`）。
- **查看历史运行状态**：**需先选择区域并点击查询**，之后才可点击「查看历史运行状态」按钮，
  查看设备**一周**的历史运行状态信息（`days=7`）。
- **流量卡号**：列表中的 `iot_card_no` 为采样时刻该设备使用的物联网卡号（冗余快照），
  便于换卡后仍能追溯当时使用的卡。
- **数据来源**：历史数据由设备心跳上报时同步写入 `ac_device_history`（时序采样），
  设备表仅保留最新快照。

### 5.2 接口列表

| 方法 | 路径 | 说明 |

| GET | `/web/devices/history` | 设备历史记录分页列表 |
| GET | `/web/devices/:id/history-chart` | 设备历史曲线数据（近 3 日 / 一周） |
| GET | `/web/devices/options` | 设备下拉选项 |
| GET | `/web/basic/regions/options` | 区域下拉选项 |

## 6. 设备告警

### 6.1 页面功能

- **列表字段**：告警类型、所属区域、设备名称、设备编号、设备位置、告警内容、告警等级、
  状态、消息通知、告警时间、处理人、处理时间。
- **搜索条件**：告警类型（`alarm_type_id`）、所属区域（`region_id`）、设备名称/编号（`keyword` / `device_code`）、
  操作时间范围（`start_dt` ~ `end_dt`）、状态（`status`）。
- **查看**：点击「查看」查看设备告警的详细信息，且该消息通知**由未读转为已读**（`read = true`，记录 `read_dt`）。
- **处理**：点击「处理」，填写处理结果（`handle_result`）及处理图片（`handle_image`）
  可对该告警信息进行处理，处理后状态**由未处理转为已处理**。
- **删除**：点击「删除」并确认后删除该条数据。
- **告警来源**：内置离线告警、电量告警、流量告警三类，也支持设备通过
  `POST /web/alarms/report` 上报自定义告警类型。
- **未处理角标**：`GET /web/alarms/pending-count` 提供未处理告警数。

## 7. 物联网卡监控

### 7.1 页面功能

- **列表字段**：物联网卡名称、物联网卡号（`card_no`）、设备编号、所属区域、所属设备、流量总额、
  剩余流量、已使用流量、统计时间、到期时间、状态。
- **搜索条件**：所属区域（`region_id`）、物联网卡名称/卡号关键字（`keyword`）、所属设备（`device_id`）、
  状态（`status`）。
- **流量口径**：`traffic_total`（流量总额）、`traffic_used`（已使用流量）、`traffic_left`（剩余流量），
  单位均为 MB；`stat_dt` 为运营商最近一次统计时间。
- **状态标识**：`normal` 正常 / `arrears` 欠费 / `expired` 到期 / `disabled` 停用。
- **流量告警联动**：剩余流量低于「设备告警设置」中流量告警阈值（`threshold`）时，平台生成流量告警记录，
  可在「设备告警」页处理。
- **跳转设备监控**：可从所属设备跳转到「设备监控」查看该设备的运行数据。
- **关联名称**：列表返回 `region.name` 与 `device.name`，不展示裸 ID。

> **注意**：本页为**只读监控**视图。物联网卡的增删改在「资源管理 → 物联网卡管理」中完成，
> 两者共用同一组 `/web/devices/iot-cards` 端点。

### 7.2 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/web/devices/iot-cards` | 物联网卡分页列表 |
| GET | `/web/devices/iot-cards/options` | 物联网卡下拉选项 |
| GET | `/web/basic/regions/options` | 所属区域下拉选项 |
| GET | `/web/devices/options` | 所属设备下拉选项 |

## 8. 状态与等级取值对照

| 维度 | 取值 | 说明 |
|---|---|---|
| 处理状态（风险/告警） | `pending` | 未处理 |
| 处理状态（风险/告警） | `handled` | 已处理 |
| 检测准确（风险） | `yes` / `no` / 空 | 准确 / 误报 / 待确认 |
| 设备状态 | `online` / `offline` | 在线 / 离线 |
| 物联网卡状态 | `normal` / `arrears` / `expired` / `disabled` | 正常 / 欠费 / 到期 / 停用 |
| 等级 | `high` / `medium` / `low` | 高 / 中 / 低 |
