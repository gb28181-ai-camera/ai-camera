|:----:|---------|------|:----:|------|

## 2. 登录

### 2.1 页面功能

- **账号密码登录**：输入登录名（`user_name`）与密码（`password`），两项均为必填。登录名对应 `ac_user.user_name`。
- **登录校验**：账号不存在、密码错误、账号被禁用（`active = false`）三种情况均返回失败提示，不进入平台。
- **登录成功**：返回 JWT Token 与用户基础信息，前端写入 Zustand `authStore` 并持久化到本地存储；后续请求头统一携带 `Authorization: Bearer <token>`。
- **菜单加载**：登录成功后前端调用 `GET /web/profile/menus` 拉取当前用户可见菜单树，驱动侧边栏渲染与按钮级权限标识。
- **权限标识**：菜单树中 `type = button` 的节点携带 `permission_code`，前端据此控制页面按钮显隐。
- **最后登录时间**：登录成功时后端更新 `ac_user.last_login`。
- **退出登录**：前端清除本地 Token 与用户信息并跳回 `/login`，无后端接口。

> **注意**：管理后台登录接口为 `POST /web/auth/login`，移动端为 `POST /app/auth/login`，
> 两者请求体一致但返回的权限集合可能不同（移动端按 `platform = mobile` 过滤菜单）。

### 2.2 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/web/auth/login` | 管理后台登录 |
| GET | `/web/profile/menus` | 获取当前用户菜单树（登录后立即调用） |

### 2.3 接口数据格式

**POST /web/auth/login**

请求参数：

```json
{
  "user_name": "admin",
  "password": "admin123"
}
```

响应数据：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user_id": 1,
    "name": "系统管理员",
    "dept_id": 1,
    "data_perm": "all",
    "cross_dept_ids": "",
    "permissions": ["system:user:create", "settings:device:update"]
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `token` | string | JWT，HS256 签名，claims 携带 `user_id` / `user_name` / `data_perm` / `company_id` |
| `user_id` | int64 | 用户 ID |
| `name` | string | 显示名 |
| `dept_id` | int64 \| null | 所属部门 |
| `data_perm` | string | 数据权限范围：`all` / `cross_dept` / `dept` / `personal` |
| `cross_dept_ids` | string | 跨部门授权部门 ID，逗号分隔 |
| `permissions` | string[] | 按钮级权限标识集合 |

登录失败响应：

```json
{ "code": 401, "message": "用户名或密码错误", "data": null }
```

```json
{ "code": 403, "message": "账号已被禁用", "data": null }
```

## 3. 个人中心

### 3.1 页面功能

- **查看个人资料**：展示姓名、登录名、邮箱、手机号、头像、所属部门、岗位、拥有角色、最后登录时间。
- **修改个人资料**：可修改姓名、邮箱、手机号、头像、备注；登录名（`user_name`）与所属部门不可自行修改，需由管理员在「用户管理」中调整。
- **头像上传**：调用 `POST /web/upload` 上传图片，回填 `avatar` 字段。
- **修改密码**：需输入原密码与新密码，原密码校验失败则拒绝修改；修改成功后需重新登录。
- **API 密钥管理**：为设备回调场景生成开放接口密钥。列表中仅展示密钥名称、前缀（`key_prefix`）与最后使用时间，**明文密钥只在生成时返回一次**，之后不可再次查看。
- **API 密钥吊销**：删除后该密钥立即失效，设备上报接口返回 401。

> **注意**：API 密钥用于 `POST /web/risks/report`、`POST /web/alarms/report`、
> `POST /web/devices/:id/heartbeat` 三个设备上报接口，请求时以 `X-Api-Key` 头传递。

### 3.2 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/web/profile` | 获取当前登录用户资料 |
| PUT | `/web/profile` | 修改当前登录用户资料 |
| PUT | `/web/profile/password` | 修改当前登录用户密码 |
| GET | `/web/profile/menus` | 获取当前用户菜单树 |
| GET | `/web/profile/api-keys` | API 密钥列表 |
| POST | `/web/profile/api-keys` | 生成 API 密钥 |
| DELETE | `/web/profile/api-keys/:id` | 删除 API 密钥 |

### 3.3 接口数据格式

**GET /web/profile**

请求参数：无。

响应数据（`RUser`）：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "active": true,
    "name": "系统管理员",
    "user_name": "admin",
    "email": "admin@example.com",
    "phone": "13800000000",
    "avatar": "/uploads/avatar/admin.png",
    "dept_id": 1,
    "post_id": 3,
    "is_admin": true,
    "last_login": "2026-09-21T09:12:33+08:00",
    "remark": "平台初始管理员",
    "dept": { "id": 1, "name": "总部", "code": "HQ" },
    "post": { "id": 3, "name": "系统管理员", "code": "sys_admin" },
    "roles": [
      { "id": 1, "name": "超级管理员", "code": "super_admin", "data_permission": "all" }
    ],
    "created_dt": "2026-01-01T00:00:00+08:00",
    "updated_dt": "2026-09-21T09:12:33+08:00"
  }
}
```

> **注意**：`password_hash` 的 json tag 为 `-`，任何接口都不会返回密码哈希。

**PUT /web/profile**

请求参数：

```json
{
  "name": "系统管理员",
  "email": "admin@example.com",
  "phone": "13800000000",
  "avatar": "/uploads/avatar/admin.png",
  "remark": "平台初始管理员"
}
```

响应数据：

```json
{ "code": 200, "message": "success", "data": null }
```

**PUT /web/profile/password**

请求参数：

```json
{
  "old_password": "admin123",
  "new_password": "Admin@2026"
}
```

响应数据：

```json
{ "code": 200, "message": "success", "data": null }
```

原密码错误：

```json
{ "code": 400, "message": "原密码不正确", "data": null }
```

**GET /web/profile/menus**

见「2.3 接口数据格式 → GET /web/profile/menus」。

**GET /web/profile/api-keys**

请求参数：无。

响应数据（`RApiKeyList`，`data` 为数组）：

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1,
      "user_id": 1,
      "name": "北门摄像头网关",
      "key_prefix": "ak_7f3c",
      "active": true,
      "last_used_dt": "2026-09-21T10:31:02+08:00",
      "created_dt": "2026-09-01T08:00:00+08:00"
    }
  ]
}
```

> **注意**：`key_hash` 的 json tag 为 `-`，列表接口不返回；仅返回 `key_prefix` 供识别。

**POST /web/profile/api-keys**

请求参数：

```json
{ "name": "北门摄像头网关" }
```

响应数据（`RGenerateApiKey`，返回一次性明文密钥）：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "name": "北门摄像头网关",
    "key_prefix": "ak_7f3c",
    "api_key": "ak_7f3c9d2e1b8a4c6f0e5d3a2b1c4f6e8d"
  }
}
```

> **注意**：`api_key` 明文仅在本次响应中返回，请立即保存。后续列表中不可再获取。

**DELETE /web/profile/api-keys/:id**

请求参数：路径参数 `id`（int64），密钥 ID。

响应数据：

```json
{ "code": 200, "message": "success", "data": null }
```

> **注意**：只能删除属于当前登录用户的密钥，删除他人密钥返回 404。
