## 2. 风险统计分析

### 2.1 页面功能

- **时间范围筛选**：默认展示近 7 天，可切换今日 / 本周 / 本月 / 自定义时间段（`start_dt` ~ `end_dt`）。
- **总览指标**：时间段内的风险总数、未处理数、已处理数与处理率。
- **按风险类型统计**：柱状/饼图，读取 `by_type[].name`（风险类型名称）与 `by_type[].level`（决定配色）。
- **按区域统计**：柱状图，读取 `by_region[].region_name`（区域名称）作为横轴标签。
- **按等级统计**：环形图，高/中/低三个等级的数量分布（`by_level`）。
- **按设备统计**：排行榜，读取 `by_device[].device_name` 与 `by_device[].device_code`。
- **趋势分析**：折线图，按日期展示风险发生数与处理数（`trend`）。
- **时段分布**：柱状图，按 0~23 小时统计风险发生时段（`by_hour`），用于发现高发时段。
- **数据导出**：当前筛选条件下的统计结果可导出为 Excel（前端基于同一接口结果生成，不额外调用接口）。
- **数据权限**：所有维度均按当前用户数据权限过滤。

> **注意**：统计接口的 `data` 载荷由 `response.RiskStatsResp` 定义，
> 前端必须使用生成的强类型访问，禁止 `as any`。

### 2.2 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/web/stats/risk` | 风险统计分析数据 |
| GET | `/web/basic/risk-types/options` | 风险类型下拉选项（筛选用） |
| GET | `/web/basic/regions/options` | 区域下拉选项（筛选用） |

### 2.3 接口数据格式

**GET /web/stats/risk**

请求参数：

```json
{
  "start_dt": "2026-09-15 00:00:00",
  "end_dt": "2026-09-21 23:59:59"
}
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|:----:|---|
| `start_dt` | string | 否 | 统计开始时间，缺省为近 7 天起点 |
| `end_dt` | string | 否 | 统计结束时间，缺省为当前时间 |

响应数据（`RRiskStats`）：

| `by_device[].device_name` / `device_code` | string | **设备名称与编号**（关联名称，非 ID） |
| `trend[].date` | string | 日期，格式 `YYYY-MM-DD` |
| `by_hour[].hour` | int | 小时，取值 0~23 |

## 3. 设备告警分析

### 3.1 页面功能

- **时间范围筛选**：默认展示近 7 天，可切换今日 / 本周 / 本月 / 自定义时间段。
- **总览指标**：时间段内的告警总数、未处理数、已处理数与处理率。
- **按告警类型统计**：柱状/饼图，读取 `by_type[].name`（告警类型名称，如离线告警/电量告警/流量告警）。
- **按区域统计**：柱状图，读取 `by_region[].region_name`。
- **按等级统计**：环形图，高/中/低分布。
- **按设备统计**：排行榜，读取 `by_device[].device_name` 与 `by_device[].device_code`，定位告警高发设备。
- **趋势分析**：折线图，按日期展示告警发生数与处理数。
- **数据导出**：当前筛选条件下的统计结果可导出为 Excel。
- **数据权限**：按当前用户数据权限过滤。

### 3.2 接口列表

## 4. 可视化大屏

### 4.1 页面功能

- **风险实时告警**：滚动列表，展示最新产生的风险记录（风险类型名称、设备名称、区域名称、发生时间、等级）。
- **设备状态告警**：滚动列表，展示最新产生的设备告警记录。
- **风险统计**：环形/柱状图，展示风险总数与未处理/已处理分布。
- **设备告警统计**：环形/柱状图，展示告警总数与未处理/已处理分布。
- **设备监控**：视频墙，展示 `monitor_enabled = true` 的设备实时画面与在线状态。
- **流量监控**：列表/条形图，展示各物联网卡的流量总额、已用与剩余。
- **设备总数 / 在线数量 / 离线数量**：顶部三个大号指标卡。
- **自动轮播与刷新**：大屏每 30 秒自动刷新一次数据；未处理的告警条目高亮闪烁提示。
- **全屏展示**：页面按 16:9 设计，支持浏览器全屏（F11）无滚动展示，适配指挥中心大屏。

> **注意**：`/screen` 为独立入口，不套用管理后台的侧边栏与顶栏布局。
> 大屏只读，不提供任何写操作。

### 4.2 接口列表

| GET | `/web/stats/device-status` | 设备状态统计（总数/在线/离线/监控墙） |
