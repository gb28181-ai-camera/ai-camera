## 2. TypeScript规范

### 2.1 类型定义优先

`tsconfig.json` 开启 `strict: true` + `noFallthroughCasesInSwitch: true`，路径别名 `@/*` 与 `~/*` 均指向 `./src/*`；`build:admin` 脚本前置 `tsc --noEmit`。

- 接口出入参类型**一律取自** `api/generated/definitions/*`（`RiskRecord`、`PageRiskReq`、`CreateUserReq`）；
- 视图层专属类型（分页基参、弹窗状态、图表配置）放 `src/admin/types/business.ts`，**不重复定义接口结构**。

```typescript
// src/admin/types/business.ts（片段）
export type ChartOption = EChartsOption

/** 分页表格查询基参数 */
export interface PageQuery {
  page: number
  page_size: number
}

/** 视频播放器状态（风险录像 / 设备实时视频共用） */
export interface VideoState {
  open: boolean
  url: string
  title?: string
  /** 是否为直播流，仅影响弹窗文案 */
  live?: boolean
}

/** 关闭状态的视频弹窗常量，用于初始化 state */
export const CLOSED_VIDEO: VideoState = { open: false, url: '' }
```

### 2.2 组件Props类型

每个公共组件导出独立 `XxxProps` 接口，字段带 JSDoc；受控组件的 `value` / `onChange` 必须类型全写；泛型组件用 `extends Record<string, any>` 约束行类型：

```typescript
// src/admin/components/ImageUpload.tsx（片段）

  maxCount?: number
  multiple?: boolean
  disabled?: boolean
  accept?: string
  listType?: UploadProps['listType']
  className?: string

// src/admin/components/SelectorModal.tsx（片段）
export interface SelectorModalProps<T extends Record<string, any>> {
  className?: string
  title: string
  columns: ColumnsType<T>
  fetchData: (params: SelectorFetchParams) => Promise<SelectorFetchResult<T>>
  rowKey: string
  mode?: 'single' | 'multiple'
  onOk: (selected: T[]) => void

```

### 2.3 禁止any（硬规则）

> **禁止**使用 `as any`、`data as any` 等强制类型转换来访问后端返回数据。必须通过 Swagger 生成的控制器返回类型（如 `RRegionList`、`RPageUser`）来严格约束数据访问。如果类型不匹配，应当修正后端 Swagger 注解并重新生成前端类型，而非在前端绕过类型检查。

可执行判据（以下命令必须无输出，`src/test/**` 除外）：

```bash
rg -n "as any" src --glob '!src/test/**'
```

- 后端可能不返回的字段用可选链 + 兜底：`res.data?.items ?? []`、`item.name ?? '-'`；
- 类型不匹配时**改后端 Swagger 注解 → 重新生成**，不要在前端包 `as`。

## 3. React组件规范

### 3.1 函数组件

统一函数组件 + Hooks，**禁止 Class 组件**。组件内顺序固定：`useState` → store 订阅 → `useCallback`/`useMemo` → `useEffect` → `handleXxx` → `columns` → `return`。

### 3.2 Hooks抽取逻辑

- 取数逻辑包进 `useCallback`，筛选/分页状态进依赖数组，由 `useEffect(() => { fetchData() }, [fetchData])` 自动重取；
- 一次性字典（岗位/角色/区域选项）放 `useEffect(..., [])`；
- 定时刷新必须在清理函数里 `window.clearInterval`；
- 异步 `setState` 前用 `let alive = true` + 清理置 `false` 防卸载后更新（见 `OptionSelect.tsx`、`DeviceSelect.tsx`）。

```typescript
// src/admin/pages/system/UserList.tsx（片段）
const fetchData = useCallback(async () => {
  setLoading(true)
  try {
    const keyword = String(search.keyword ?? '')
    const res = await UserController.pageUsers(page, pageSize, keyword || undefined, deptId, activeFilter)
    if (res.code === 200) {
      setData(res.data?.items ?? [])
      setTotal(res.data?.total ?? 0)
    } else {
      message.error(res.message || '获取用户列表失败')
    }
  } finally {
    setLoading(false)
  }
}, [page, pageSize, search, deptId, activeFilter])

useEffect(() => { fetchData() }, [fetchData])
```

```typescript
// src/admin/pages/risk/RiskMonitorList.tsx（片段）—— 定时刷新必须清理
useEffect(() => {
  if (refreshSec <= 0) return
  const timer = window.setInterval(() => { void fetchData() }, refreshSec * 1000)
  return () => { window.clearInterval(timer) }
}, [refreshSec, fetchData])
```

## 4. 状态管理（Zustand）

### 4.1 authStore结构

`src/admin/store/authStore.ts` 是全工程**唯一**全局 store：

| 字段 | 类型 | 持久化 | 说明 |
|:-----|:-----|:------:|:-----|
| `token` | `string \| null` | ✅ `localStorage['token']` | JWT，请求拦截器读取 |
| `user` | `AuthUser \| null` | ✅ `localStorage['user_info']` | 用户基本信息（登录返回的非 token 部分） |
| `permissions` | `string[]` | ❌ 内存 | 登录接口返回的 `permissions` |
| `permCodes` | `string[]` | ✅ `localStorage['perm_codes']` | 菜单树递归提取的按钮级权限码 |
| `menus` | `Menu[]` | ❌ 内存 | 后端菜单树，驱动侧边栏 |

动作：`setToken` / `setUser` / `setPermissions` / `setPermCodes` / `setMenus` / `logout` / `isAuthenticated`。

```typescript
// src/admin/store/authStore.ts（片段）
export const useAuthStore = create<AuthState>((set, get) => ({
  token: readStorage(TOKEN_KEY),
  user: readJSON<AuthUser | null>(USER_KEY, null),
  permissions: [],
  permCodes: readPermCodes(),
  menus: [],

  setToken: (token: string) => { writeStorage(TOKEN_KEY, token); set({ token }) },

  setMenus: (menus: Menu[]) => {
    const list = Array.isArray(menus) ? menus : []
    const permCodes = extractPermCodes(list)
    writeStorage(PERM_CODES_KEY, JSON.stringify(permCodes))
    set({ menus: list, permCodes })
  },

  logout: () => {
    removeStorage(TOKEN_KEY); removeStorage(PERM_CODES_KEY); removeStorage(USER_KEY)
    set({ token: null, user: null, permissions: [], permCodes: [], menus: [] })
  },

  isAuthenticated: () => Boolean(get().token),
}))
```

> **注意**：store 初始化时**同步**从 `localStorage` 读取 `token`/`user`/`permCodes`，React 挂载前即恢复登录态，无需额外 bootstrap effect。

### 4.2 手动localStorage持久化

本项目**不使用** `persist` 中间件（原因与边界见 [02-Zustand状态管理规范.md](./02-Zustand状态管理规范.md) 第 3 节）。所有读写经容错包装，隐私模式/存储被禁用时返回兜底值：

```typescript
// src/admin/store/authStore.ts（片段）
/** localStorage 读取（容错：隐私模式 / 存储被禁用时返回兜底值） */
function readStorage(key: string): string | null {
  try {
    return localStorage.getItem(key)
  } catch {
    return null
  }
}
```

### 4.3 权限标识提取（permCodes）

菜单树既驱动侧边栏也驱动按钮权限。`setMenus` 调 `extractPermCodes` 递归收集全部 `permission_code` 并去重：

```typescript
// src/admin/store/authStore.ts（片段）
export function extractPermCodes(menus?: Menu[] | null): string[] {
  const codes = new Set<string>()
  const walk = (list?: Menu[] | null) => {
    if (!Array.isArray(list)) return
    for (const menu of list) {
      if (!menu) continue
      const code = menu.permission_code
      if (typeof code === 'string' && code.trim()) codes.add(code.trim())
      if (Array.isArray(menu.children) && menu.children.length > 0) walk(menu.children)
    }
  }
  walk(menus)
  return Array.from(codes)
}
```

页面侧有两种消费语义，按场景选择：

```typescript
// ① 列表页：permCodes 为空视为「权限未加载」，放行全部按钮，避免整页被锁死
const permCodes = useAuthStore((s) => s.permCodes)
const can = (code: string) => permCodes.length === 0 || permCodes.includes(code)
const canCreate = can('system:config:create')

// ② 风险监控：严格判定，未授权即隐藏
const canHandle = permCodes.includes('risk:handle')
```

### 4.4 订阅粒度

只订阅用到的字段；整包取 store 会导致任意字段变化都重渲染：

```typescript
const token = useAuthStore((state) => state.token)   // ✅ 选择器订阅
const { token } = useAuthStore()                     // ❌ 全量订阅
```

## 5. API请求规范

### 5.1 必须使用生成的Controller（严禁手写request()）

> **所有 API 调用必须通过 `frontend/src/admin/api/generated/` 中的 Controller 静态方法**（如 `DeviceController.pageDevices()`）。
>
> **严禁手动编写 API 请求代码**：禁止 `import request from '../../api/request'` 后手动拼接 URL 调用 API（如 `request('/web/xxx', { method: 'PUT' })`）。

```typescript
// ✅ 正确
const res = await ConfigController.updateConfig(String(editing.id), values)

// ❌ 错误
import request from '../../api/request'
const res = await request('/web/system/configs/1', { method: 'PUT', data: values })
```

生成物结构（每个 Controller 导出 `XxxPath` 常量 + 静态方法，标题注释即 `@Summary`）：

```typescript
// src/admin/api/generated/ConfigController.ts（片段）
export class ConfigController {
    static listConfigsPath: string = "/web/system/configs";
    /// 系统参数列表（无分页）
    static async listConfigs(keyword?: string, headers?: any): Promise<RSystemConfigList> {
      return request(`/web/system/configs?keyword=${keyword ?? "" }`, {
        baseURL: import.meta.env.VITE_API_BASE,
        method: "GET",
        headers,
      });
    }

    static deleteConfigByIdPath: string = "/web/system/configs/{id}";
    /// 删除系统参数
    static async deleteConfigById(id: string, headers?: any): Promise<BaseResponse> {
      return request(`/web/system/configs/${id}`, {
        baseURL: import.meta.env.VITE_API_BASE, method: "DELETE", headers,
      });
    }
}
```

**API 变更流程（不可跳步）**：后端 handler 改 Swagger 注解 → `cd backend && bash scripts/gen-swagger.sh` → 启动后端（:8080）暴露 `/web/api-docs.json` → `cd frontend && bash scripts/api-gen.sh` → 更新页面代码。

### 5.2 request.ts拦截器

`src/admin/api/request.ts` 是全工程唯一 Axios 实例：

```typescript
// src/admin/api/request.ts（全文）
import axios from 'axios'
import { message } from 'antd'

const request = axios.create({
  baseURL: import.meta.env.VITE_API_BASE || '',
  timeout: 30000,
  headers: { 'Content-Type': 'application/json' },
})

// 请求拦截器 - 注入 Token（从 localStorage 读取，保证 React 挂载前也可用）
request.interceptors.request.use((config) => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器 - 统一错误处理
request.interceptors.response.use(
  (res) => res.data, // 拆包：调用方拿到 { code, message, data }
  (err) => {
    if (err.response?.status === 401) {
      localStorage.removeItem('token')
      // 保留 vite base 前缀（如 /admin/），避免跳转到不存在的 /login
      window.location.href = `${import.meta.env.BASE_URL || '/'}login`
    } else {
      message.error(err.response?.data?.message || '请求失败')
    }
    return Promise.reject(err)
  }
)

export default request
```

| 约定 | 说明 |
|:-----|:-----|
| 拆包 | 拦截器返回 `res.data`，Controller 的 `Promise<RPageUser>` 直接就是 `{code, message, data}` |
| token 来源 | 直接读 `localStorage`，**不读 store**，避免拦截器依赖 React 上下文 |
| 401 | `window.location.href` 硬跳转，保留 `import.meta.env.BASE_URL` 前缀（`/admin/`） |
| 超时 | 30 秒 |
| 业务码 | **不在拦截器里判 `code`**，由页面自行判断，因为存在「创建成功返回 201」等语义 |

### 5.3 统一错误处理与401跳转

页面必须处理三层失败：HTTP 异常（catch）、业务码非 200、网络异常：

```typescript
// src/admin/pages/system/ConfigList.tsx（片段）
const handleSave = async () => {
  const values = await form.validateFields()
  setSaving(true)
  try {
    if (editing) {
      const res = await ConfigController.updateConfig(String(editing.id), values)
      if (res.code === 200) { message.success('更新成功'); setModalOpen(false); fetchData() }
      else message.error(res.message || '更新失败')
    } else {
      const res = await ConfigController.createConfig(values)
      // 创建接口必须兼容 201
      if (res.code === 200 || res.code === 201) { message.success('创建成功'); setModalOpen(false); fetchData() }
      else message.error(res.message || '创建失败')
    }
  } catch {
    message.error('保存失败，请检查网络后重试')
  } finally {
    setSaving(false)
  }
}
```

响应格式与读取方式：

| 后端类型 | 结构 | 前端读取 |
|:---------|:-----|:---------|
| `RXxxList` | `Data []model.Xxx` | `res.data ?? []` |
| `RPageXxx` | `Data PageXxxResp{Items, Total, Page, PageSize}` | `res.data?.items ?? []` / `res.data?.total ?? 0` |
| `RXxx` | `Data model.Xxx` | `res.data` |

Upload 类接口需显式声明 multipart，否则 Axios 会把 `FormData` 转成 JSON：

```typescript
// src/admin/components/ImageUpload.tsx（片段）
const res = await Common.uploadFile(formData, { 'Content-Type': 'multipart/form-data' })
const url = res?.data?.url ?? res?.data?.path ?? ''
```

### 6.1 列表页统一骨架

```tsx
import { useCallback, useEffect, useState } from 'react'
import { Button, Col, Form, Input, Modal, Popconfirm, Row, Switch, Table, message } from 'antd'
import type { ColumnsType } from 'antd/es/table'
import { DeleteOutlined, EditOutlined, PlusOutlined } from '@ant-design/icons'
import PageContainer from '../../components/PageContainer'
import SearchBar from '../../components/SearchBar'
import ActionButtons from '../../components/ActionButtons'
import { XXXController } from '../../api/generated/XXXController'
import { useAuthStore } from '../../store/authStore'
import type { Xxx } from '../../api/generated/definitions/Xxx'

/** 表单值（只列表单字段，不带关联对象） */
interface XxxFormValues { name: string; dept_id?: number; active?: boolean }

export default function XxxList() {
  // ① useState 清单：列表 / 分页 / 搜索 / 弹窗 / 保存中
  const [data, setData] = useState<Xxx[]>([])
  const [loading, setLoading] = useState(false)
  const [total, setTotal] = useState(0)
  const [page, setPage] = useState(1)
  const [pageSize, setPageSize] = useState(20)
  const [search, setSearch] = useState<Record<string, unknown>>({})
  const [modalOpen, setModalOpen] = useState(false)
  const [editing, setEditing] = useState<Xxx | null>(null)
  const [saving, setSaving] = useState(false)
  const [form] = Form.useForm<XxxFormValues>()

  // ② 按钮级权限：permCodes 为空视为未加载，放行
  const permCodes = useAuthStore((s) => s.permCodes)
  const can = (code: string) => permCodes.length === 0 || permCodes.includes(code)
  const canCreate = can('xxx:create')
  const canUpdate = can('xxx:update')
  const canDelete = can('xxx:delete')

  // ③ fetchData：依赖数组含全部分页 + 筛选状态
  const fetchData = useCallback(async () => {
    setLoading(true)
    try {
      const keyword = String(search.keyword ?? '')
      const res = await XXXController.pageXxxs(page, pageSize, keyword || undefined)
      if (res.code === 200) {
        setData(res.data?.items ?? [])
        setTotal(res.data?.total ?? 0)
      } else {
        message.error(res.message || '获取列表失败')
      }
    } finally {
      setLoading(false)
    }
  }, [page, pageSize, search])
  useEffect(() => { fetchData() }, [fetchData])

  // ④ 搜索 / 重置（重置必须回第 1 页）
  const handleSearch = (values: Record<string, unknown>) => { setSearch(values); setPage(1) }
  const handleReset = () => { setSearch({}); setPage(1) }

  // ⑤ 新建 / 编辑（关联字段只取 ID，不带关联对象）
  const openCreate = () => { setEditing(null); form.resetFields(); setModalOpen(true) }
  const openEdit = (record: Xxx) => {
    setEditing(record)
    form.setFieldsValue({ name: record.name, dept_id: record.dept_id ?? undefined, active: record.active !== false })
    setModalOpen(true)
  }

  // ⑥ handleSave：创建兼容 201；catch 兜底网络异常
  const handleSave = async () => {
    const values = await form.validateFields()
    setSaving(true)
    try {
      if (editing) {
        const res = await XXXController.updateXxx(String(editing.id), values)
        if (res.code === 200) { message.success('更新成功'); setModalOpen(false); fetchData() }
        else message.error(res.message || '更新失败')
      } else {
        const res = await XXXController.createXxx(values)
        if (res.code === 200 || res.code === 201) { message.success('创建成功'); setModalOpen(false); fetchData() }
        else message.error(res.message || '创建失败')
      }
    } catch {
      message.error('保存失败，请检查网络后重试')
    } finally {
      setSaving(false)
    }
  }

  // ⑦ 启停 / 删除
  const handleToggleActive = async (record: Xxx, checked: boolean) => {
    const res = checked
      ? await XXXController.enableXxx(String(record.id))
      : await XXXController.disableXxx(String(record.id))
    if (res.code === 200) message.success(checked ? '已启用' : '已停用')
    else message.error(res.message || '操作失败')
    fetchData()
  }
  const handleDelete = async (record: Xxx) => {
    const res = await XXXController.deleteXxxById(String(record.id))
    if (res.code === 200) { message.success('删除成功'); fetchData() }
    else message.error(res.message || '删除失败')
  }

  // ⑧ 列定义（关联表必须展示名称字段，空值统一 '-'）
  const columns: ColumnsType<Xxx> = [
    { title: '名称', dataIndex: 'name', key: 'name', width: 160 },
    { title: '部门', key: 'dept', width: 120, render: (_, record) => record.dept?.name ?? '-' },
    {
      title: '状态', key: 'active', width: 100,
      render: (_, record) => (
        <Switch checked={record.active !== false} checkedChildren="启用" unCheckedChildren="停用"
          disabled={!canUpdate} onChange={(checked) => handleToggleActive(record, checked)} />
      ),
    },
    {
      title: '操作', key: 'action', width: 160, fixed: 'right' as const,
      render: (_, record) => (
        <ActionButtons>
          {canUpdate && <Button type="link" size="small" icon={<EditOutlined />} onClick={() => openEdit(record)}>编辑</Button>}
          {canDelete && (
            <Popconfirm title="确定删除?" onConfirm={() => handleDelete(record)}>
              <Button type="link" size="small" danger icon={<DeleteOutlined />}>删除</Button>
            </Popconfirm>
          )}
        </ActionButtons>
      ),
    },
  ]

  // ⑨ 渲染：PageContainer 包 SearchBar + Table + Modal
  return (
    <PageContainer title="XX 管理" subTitle="一句话说明该页承载的业务"
      extra={canCreate ? <Button type="primary" icon={<PlusOutlined />} onClick={openCreate}>新建</Button> : undefined}>
      <SearchBar fields={[{ name: 'keyword', label: '名称', placeholder: '请输入名称' }]}
        onSearch={handleSearch} onReset={handleReset} loading={loading} />

      <Table rowKey="id" size="small" scroll={{ x: 'max-content' }} columns={columns}
        dataSource={data} loading={loading}
        pagination={{
          current: page, pageSize, total, showSizeChanger: true,
          showTotal: (t) => `共 ${t} 条`,
          onChange: (p, ps) => { setPage(p); setPageSize(ps) },
        }} />

      <Modal className="e2e-xxx-modal" title={editing ? '编辑' : '新建'} open={modalOpen}
        onOk={handleSave} onCancel={() => setModalOpen(false)} confirmLoading={saving} width={720}>
        <Form form={form} layout="vertical">
          <Row gutter={16}>
            <Col span={12}>
              <Form.Item name="name" label="名称" rules={[{ required: true, message: '请输入名称' }]}>
                <Input placeholder="请输入名称" />
              </Form.Item>
            </Col>
          </Row>
        </Form>
      </Modal>
    </PageContainer>
  )
}
```

**非分页列表**（如系统参数）：接口无分页时 `Table` 传 `pagination={false}`，关键字在客户端过滤：

```typescript

const keyword = String(search.keyword ?? '').trim().toLowerCase()
const filteredData = useMemo(() => {
  if (!keyword) return data
  return data.filter((item) => [item.name, item.key, item.group_name]
    .some((field) => String(field ?? '').toLowerCase().includes(keyword)))
}, [data, keyword])
```

`SearchBar` 仅支持 `input` 与 `select` 两种控件，**不支持日期区间、树选择器**：

```tsx
// src/admin/pages/risk/RiskMonitorList.tsx（片段）

    { name: 'keyword', label: '设备名称', placeholder: '请输入设备名称' },
```

### 6.3 弹窗表单（layout=vertical + Row/Col两列）

统一 `Form layout="vertical"` + `Row gutter={16}` 两列（`Col span={12}`），跨列字段用 `Col span={24}`：

```tsx
// src/admin/pages/system/ConfigList.tsx（片段）
<Modal className="e2e-config-modal" title={editing ? '编辑参数' : '新建参数'} open={modalOpen}
  onOk={handleSave} onCancel={() => setModalOpen(false)} confirmLoading={saving} width={720}>
  <Form form={form} layout="vertical">
    <Row gutter={16}>
      <Col span={12}>
        <Form.Item name="name" label="参数名称" rules={[{ required: true, message: '请输入参数名称' }]}>
          <Input placeholder="如：设备心跳超时(秒)" />
        </Form.Item>
      </Col>
      <Col span={12}>
        <Form.Item name="key" label="参数键" rules={[{ required: true, message: '请输入参数键' }]}>
          <Input placeholder="如：device.heartbeat.timeout" />
        </Form.Item>
      </Col>
      <Col span={12}>
        <Form.Item name="active" label="状态" valuePropName="checked">
          <Switch checkedChildren="启用" unCheckedChildren="停用" />
        </Form.Item>
      </Col>
      <Col span={24}>
        <Form.Item name="value" label="参数值"><Input.TextArea rows={2} placeholder="请输入参数值" /></Form.Item>
      </Col>
    </Row>
  </Form>
</Modal>
```

| 场景 | 写法 |
|:-----|:-----|
| 必填 | `rules={[{ required: true, message: '请输入xxx' }]}` |
| 邮箱 | `rules={[{ type: 'email', message: '邮箱格式不正确' }]}` |
| 开关 | `<Form.Item valuePropName="checked">` |
| 编辑态不可改 | `<Input disabled={Boolean(editing)} />` |
| 关联对象回填 | 只取 ID：`dept_id: record.dept_id ?? undefined` |
| 两次密码一致 | `dependencies={['new_password']}` + 自定义 `validator` |

```tsx
// 两次密码一致性校验（src/admin/pages/system/UserList.tsx 片段）
<Form.Item name="confirm_password" label="确认新密码" dependencies={['new_password']}
  rules={[
    { required: true, message: '请再次输入新密码' },
    ({ getFieldValue }) => ({
      validator(_, value) {
        if (!value || getFieldValue('new_password') === value) return Promise.resolve()
        return Promise.reject(new Error('两次输入的密码不一致'))
      },
    }),
  ]}>
  <Input.Password placeholder="请再次输入新密码" />
</Form.Item>
```

> **注意**：每个 `<Modal>` 必须带 `className="e2e-xxx-modal"`，见第 11 节。

### 6.4 操作列（ActionButtons + Popconfirm）

- 操作列必须 `fixed: 'right'`，宽度按按钮数量给（2 个约 160，3~4 个约 220，5 个以上约 320）；
- 所有按钮包在 `<ActionButtons>` 内（自动换行，防撑破列宽）；
- **删除必须 `Popconfirm` 二次确认**，危险按钮加 `danger`；
- 权限控制的按钮直接条件渲染（不渲染即不可见）。示例见 6.1 的 `columns`。

### 6.5 分页表格约定

| 项 | 约定 |
|:---|:-----|
| `rowKey` | 一律 `"id"` |
| `size` | 一律 `"small"` |
| `scroll` | 一律 `{{ x: 'max-content' }}` |
| 序号列 | 不展示 |
| `pagination` | 受控（`current` / `pageSize` 来自 state），默认 20 条，`showSizeChanger: true` |
| `showTotal` | `(t) => \`共 ${t} 条\`` |
| `onChange` | `(p, ps) => { setPage(p); setPageSize(ps) }` |
| 关联字段 | `dataIndex: ['region', 'name']` 或 `render: (_, r) => r.dept?.name ?? '-'` |
| 空值 | 统一 `'-'`（`formatDT` / `emptyText` 已内置） |

```typescript
export const httpResponse = {
  /** 成功（code 200） */
  success: (data: unknown = null, message = 'ok') =>
    HttpResponse.json({ code: 200, message, data }),
  /** 分页成功（data.items / data.total） */
  page: (items: unknown[] = [], total?: number, message = 'ok') =>
    HttpResponse.json({
      code: 200, message,
      data: { items, total: total ?? items.length, page: 1, page_size: 20 },
    }),
  /** 业务错误（HTTP 200 + 非 200 的 code） */
  error: (message = '请求失败', code = 500) =>
    HttpResponse.json({ code, message, data: null }),
  /** 未登录（HTTP 401，触发前端跳转登录） */
  unauthorized: (message = '未登录或登录已过期') =>
    HttpResponse.json({ code: 401, message, data: null }, { status: 401 }),
}

// 端点注册示例
http.get(`${API_BASE}/web/profile/menus`, () => httpResponse.success(mockMenus)),
http.get(`${API_BASE}/web/system/users`, () => httpResponse.page([mockUser], 1)),
```

## 13. 性能优化

| 手段 | 落地位置 | 判据 |
|:-----|:---------|:-----|
| 路由级懒加载 | `App.tsx` 的 `ROUTES` 全量 `lazy()` | 首屏 JS 只含 Login + MainLayout + Dashboard |
| 编译期常量消除 | `__IS_ELECTRON__` 由各 vite `define` 注入 | 未选中的 Router 分支被 tree-shaking 移除，无运行时开销 |
| 请求去重 | 取数统一走 `useCallback` + 依赖数组 | 筛选条件不变时不重复请求 |
| 定时刷新可控 | `REFRESH_INTERVAL_OPTIONS`（不自动刷新 / 10 / 30 / 60 秒） | 用户可关闭自动刷新；`useEffect` 清理定时器防泄漏 |
| 大屏刷新间隔 | `ScreenPage.tsx` 的 `REFRESH_MS = 30_000` + `Promise.all` | 30 秒一次，三份数据并发拉取 |
| 表格重排抑制 | `Table` 一律 `size="small"` + `scroll={{ x: 'max-content' }}` | 列宽固定，避免重排 |
| 上传走定制请求 | `ImageUpload` 用 `customRequest`；`AudioUpload` 用 `beforeUpload` + `Upload.LIST_IGNORE` | 阻止 antd 默认上传行为，避免重复请求 |
| 菜单渲染缓存 | `MainLayout.tsx` 的 `menuItems` / `selectedKeys` 用 `useMemo` | 仅在 `menus` / `pathname` 变化时重算 |
| 图表配置复用 | `types/business.ts` 的 `pieOption` / `barOption` / `lineOption` | 配置集中定义，避免逐页重复构造 |
| 桌面端资源 | `forge.config.ts` 的 `asar: true` | 打包为单 asar，减少文件句柄 |

```typescript
// src/admin/pages/stats/ScreenPage.tsx（片段）—— 页面级并发的正确写法
const fetchData = useCallback(async () => {
  setLoading(true)
  try {
    const [screenRes, trendRes, deviceRes] = await Promise.all([
      StatsController.screen(),
      StatsController.riskStats({
        start_dt: dayjs().subtract(6, 'day').startOf('day').format('YYYY-MM-DD HH:mm:ss'),
        end_dt: dayjs().endOf('day').format('YYYY-MM-DD HH:mm:ss'),
      }),
      DeviceController.pageDevices(1, 8),
    ])
    setData(screenRes.data ?? null)
    setTrend(trendRes.data?.trend ?? [])
    setDevices(deviceRes.data?.items ?? [])
  } catch {
    /* 大屏为只读看板，失败时保留上一次数据 */
  } finally {
    setLoading(false)
  }
}, [])
```

> **注意**：只读看板类页面（大屏、实时监控）失败时**保留上一次数据**避免闪烁；列表类页面则必须清空并提示，避免展示过期数据。
