# 巡检中心模块

> 版本: v0.1.0
> 最后更新: 2026-09-21
> 需求来源: AI摄像头操作手册 第 6 节（巡检任务管理 / 巡检记录）

## 1. 模块概述

巡检中心模块是平台**「人工防线」**的载体。AI 摄像头能识别预设的风险类型，但无法覆盖
全部现场隐患——设备死角、临时作业面、需要动手确认的隐患（线缆破损、消防通道堆物、
标识缺失），仍需人到现场核查。

巡检中心把这些工作**任务化、责任化、留痕化**：

```
   管理员派单                    巡检员执行                  结果归档
┌──────────────┐          ┌──────────────────┐      ┌──────────────────┐
│ 巡检任务管理  │ ───────▶ │ 移动端 App        │ ───▶ │ 巡检记录         │
│ 新增任务并    │  发布     │ 查看待办 → 现场   │ 提交 │ 自动生成已处理   │
│ 指派巡检人    │          │ 巡检 → 填结果与图 │      │ 的巡检记录       │
└──────────────┘          └──────────────────┘      └──────────────────┘
        │                          │                        │
        │                          │                        │
   status=published          status=finished          ac_inspect_record
   出现在巡检人账号中         任务从任务列表移除        保留任务快照字段
```

核心机制：

- **任务发布即通知**：任务发布后，巡检消息通知会出现在**被指派的巡检人员账号**中。
- **处理即移除**：巡检人处理完任务后，**该巡检任务就会移除**（从任务列表消失），
  **并产生一条巡检记录**。
- **快照可追溯**：巡检记录保留任务名称、区域、位置、巡检人、内容等**快照字段**，
  即使原任务被后续修改或删除，记录仍可独立查看。

> **注意**：任务「移除」在数据层是 `status` 由 `published` 变为 `finished`（仍可被
> 管理员在列表中按状态筛选查看），而非物理删除。这样既满足「列表干净」的体验，
> 又保留了完整的任务生命周期轨迹。

## 2. 角色与权限

| 角色 | 可执行操作 |
|:---|:---|
| 系统管理员 | 巡检任务的增删改查、查看任务详情、查看巡检记录 |
| 区域管理员 | 同上（受数据权限约束，只能对本区域设备/区域派单） |
| 安全员 | 创建与编辑巡检任务；查看巡检记录 |
| 设备运维员 | 创建与编辑巡检任务；查看巡检记录 |
| 巡检员 | **移动端**：查看指派给本人的巡检任务、查看任务详情、提交巡检结果与结果图 |

权限码：

| 权限码 | 说明 |
|:---|:---|
| `inspectTask:list` | 查看巡检任务列表与详情 |
| `inspectTask:create` | 新增巡检任务并指派巡检人 |
| `inspectTask:update` | 编辑巡检任务内容 |
| `inspectTask:delete` | 删除巡检任务 |
| `inspectRecord:list` | 查看巡检记录列表与详情 |
| `inspectTask:finish` | 移动端：完成任务并提交结果（巡检员） |

> **注意**：巡检员在 PC 端**只有只读权限**，实际的巡检处理在**移动端 App** 完成
> （「由该巡检人员使用账号登录到管理平台中进行巡检任务处理」）。

### 3.2 ac_inspect_task - 巡检任务

```sql
CREATE TABLE ac_inspect_task (
    id              BIGSERIAL PRIMARY KEY,
    deleted_at      TIMESTAMPTZ,
    created_by      VARCHAR(50),
    created_dt      TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    updated_by      VARCHAR(50),
    updated_dt      TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,

    active          BOOLEAN DEFAULT TRUE,                  -- 是否启用
    name            VARCHAR(255) NOT NULL,                 -- 任务名称
    region_id       BIGINT,                                -- 所属区域
    location        VARCHAR(255),                          -- 巡检位置
    inspector_id    BIGINT NOT NULL,                       -- 巡检人用户ID
    content         TEXT,                                  -- 巡检内容
    plan_dt         TIMESTAMPTZ,                           -- 巡检时间
    status          VARCHAR(20) DEFAULT 'published',       -- pending/published/finished/canceled
    read            BOOLEAN DEFAULT FALSE,                 -- 消息通知是否已读
    remark          VARCHAR(500),                          -- 备注

    dept_id         BIGINT                                 -- 所属部门(数据权限)
);
CREATE INDEX idx_ac_inspect_task_region_id ON ac_inspect_task (region_id);
CREATE INDEX idx_ac_inspect_task_inspector_id ON ac_inspect_task (inspector_id);
CREATE INDEX idx_ac_inspect_task_plan_dt ON ac_inspect_task (plan_dt);
CREATE INDEX idx_ac_inspect_task_status ON ac_inspect_task (status);
CREATE INDEX idx_ac_inspect_task_dept_id ON ac_inspect_task (dept_id);
CREATE INDEX idx_ac_inspect_task_deleted_at ON ac_inspect_task (deleted_at);

COMMENT ON TABLE ac_inspect_task IS '巡检任务';
COMMENT ON COLUMN ac_inspect_task.name IS '任务名称';
COMMENT ON COLUMN ac_inspect_task.location IS '巡检位置';
COMMENT ON COLUMN ac_inspect_task.inspector_id IS '巡检人用户ID';
COMMENT ON COLUMN ac_inspect_task.content IS '巡检内容';
COMMENT ON COLUMN ac_inspect_task.plan_dt IS '巡检时间';
COMMENT ON COLUMN ac_inspect_task.status IS 'pending/published/finished/canceled';
COMMENT ON COLUMN ac_inspect_task.read IS '消息通知是否已读';
```

巡检任务状态常量：

| 常量 | 值 | 含义 |
|:---|:---|:---|
| `InspectStatusPending` | `pending` | 待发布 |
| `InspectStatusPublished` | `published` | 已发布（待巡检）——**表默认值** |
| `InspectStatusFinished` | `finished` | 已完成（已转巡检记录） |
| `InspectStatusCanceled` | `canceled` | 已取消 |

## 4. 功能需求

### 4.1 巡检任务管理

**操作说明**（手册 6.1 节）：

- 通过创建巡检任务并指派相关区域巡检人员进行巡检处理，列表中包括任务名称、所属区域、巡检位置、巡检人、巡检内容、巡检时间、状态等相关内容。
- 操作说明：
  - 点击查看，可查看巡检任务的详细信息，且该消息通知由未读转为已读状态；
  - 点击编辑，可对巡检任务内容进行修改；
  - 点击删除，并确认删除后，可对该条数据进行删除；
  - 输入所属区域、任务名称、巡检人、巡检时间等条件进行搜索；
  - 巡检任务创建：点击新增，新增巡检任务并选择巡检人员，巡检任务发布后由该巡检人员使用账号登录到管理平台中进行巡检任务处理，处理后该巡检任务就会移除，并产生一条巡检记录。

**业务规则**：

**（1）点击「查看」**

- 打开巡检任务详情，展示任务名称、所属区域、巡检位置、巡检人、巡检内容、巡检时间、
  状态、备注等。
- **同时把该条的消息通知由未读转为已读**（`read=true`）。

**（2）点击「编辑」**

- 可对巡检任务内容进行修改：任务名称、所属区域、巡检位置、巡检人、巡检内容、
  巡检时间、备注。
- 修改后点「确定」保存；点「取消」不保存。
- **已被处理（`status=finished`）的任务不应再允许编辑**——记录已生成，修改任务会
  造成任务与记录不一致（记录中的快照不会随之更新）。

**（3）点击「删除」**

- 弹出确认框；**点击「确定」**后删除该条数据（软删除），**点击「取消」**则不删除。
- 已生成巡检记录的任务，其记录**保持独立存在**（快照字段已冗余），不受任务删除影响。

**（4）搜索**

支持以下条件组合搜索：所属区域、任务名称、巡检人、巡检时间（区间）。

**（5）新增巡检任务（核心流程）**

```
   点击「新增」
        │
        ▼
   填写任务信息：
     任务名称    *必填
     所属区域    ← 下拉来自区域管理（ac_region）
     巡检位置
     巡检人      ← 下拉来自用户管理（ac_user），*必填
     巡检内容    （巡检项描述，如「检查东门摄像头外观与线缆」）
     巡检时间    （计划巡检时间 plan_dt）
     备注
        │
        ▼
   保存 → status = published
        │
        ├──▶ 生成巡检通知到「被指派的巡检人」账号
        │     （ac_notification: category=inspect, ref_type=task, ref_id=task_id）
        │     该巡检人登录后在「系统通知」中看到未读红点
        │
        └──▶ 巡检人使用账号登录管理平台（移动端 App）
                  │
                  ▼
             查看指派给本人的巡检任务 → 现场巡检
                  │
                  ▼
             提交：处理结果 + 处理结果图
                  │
                  ▼
             ┌────────────────────────────────────┐
             │ ① ac_inspect_task.status=finished  │  任务从列表「移除」
             │ ② 生成一条 ac_inspect_record       │  出现在「巡检记录」
             │ ③ handled_dt = 当前时间            │
             └────────────────────────────────────┘
```

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 任务名称 | — | `ac_inspect_task.name` |
| 所属区域 | — | `ac_region.name` |
| 巡检位置 | — | `ac_inspect_task.location` |
| 巡检人 | 巡检人姓名 | `ac_user.name`（经 `inspector_id`） |
| 巡检内容 | — | `ac_inspect_task.content` |
| 巡检时间 | 计划时间 | `ac_inspect_task.plan_dt` |
| 状态 | 待发布/已发布/已完成/已取消 | `ac_inspect_task.status` |
| 消息通知 | 未读/已读 | `ac_inspect_task.read` |
| 备注 | — | `ac_inspect_task.remark` |
| 创建时间 | — | `ac_inspect_task.created_dt` |
| 操作 | 查看、编辑、删除 | — |

**搜索条件**（手册明确列举，全部必须实现）：

1. 所属区域（`region_id`）
2. 任务名称（模糊）
3. 巡检人（`inspector_id`）
4. 巡检时间（`plan_dt` 区间）

**排序**：按巡检时间（`plan_dt`）倒序；同时间按创建时间倒序。

### 4.2 巡检记录

**操作说明**（手册 6.2 节）：

- 列表中包括任务名称、所属区域、巡检位置、巡检人、巡检内容、巡检时间、处理结果图、处理时间、处理结果、状态等相关内容。被指派的巡检人员处理完巡检任务后，巡检记录模块中才会产生已处理的巡检记录。
- 点击查看，可查看巡检记录的详情信息或处理图片；
- 输入所属区域、任务名称、巡检人、处理时间等条件进行搜索。

**业务规则**：

**（1）记录的生成时机（关键约束）**

- **只有被指派的巡检人员处理完巡检任务后，巡检记录模块中才会产生已处理的巡检记录。**
- 即：任务存在但未被处理时，巡检记录列表中**没有**对应记录。
- 生成的记录 **`status` 直接为「已处理」**（模型默认值 `finished`），因为只有处理完成
  才会产生记录，不存在「未处理的巡检记录」这一状态。
- 记录**不可编辑、不可删除**——它是现场作业的原始留证。

**（2）点击「查看」**

- 可查看巡检记录的详情信息**或处理图片**（点击缩略图查看大图）。

**（3）搜索**

支持以下条件组合搜索：所属区域、任务名称、巡检人、处理时间（区间）。

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 任务名称 | 快照 | `ac_inspect_record.task_name` |
| 所属区域 | 快照 | `ac_region.name`（经 `region_id`） |
| 巡检位置 | 快照 | `ac_inspect_record.location` |
| 巡检人 | 快照（巡检人姓名） | `ac_inspect_record.inspector` |
| 巡检内容 | 快照 | `ac_inspect_record.content` |
| 巡检时间 | 快照（计划时间） | `ac_inspect_record.plan_dt` |
| 处理结果图 | 可点击查看大图 | `ac_inspect_record.result_image` |
| 处理时间 | — | `ac_inspect_record.handled_dt` |
| 处理结果 | — | `ac_inspect_record.result` |
| 状态 | 已处理 | `ac_inspect_record.status` |
| 操作 | 查看 | — |

**搜索条件**（手册明确列举，全部必须实现）：

1. 所属区域（`region_id`）
2. 任务名称（模糊，快照字段）
3. 巡检人（`inspector_id`，快照字段）
4. 处理时间（`handled_dt` 区间）

**排序**：按处理时间（`handled_dt`）倒序。

### 4.3 移动端巡检处理

**业务规则**：

- 巡检人使用**自己的账号**登录移动端 App。
- 「我的待办」/「巡检任务」列表**只展示指派给当前登录用户的任务**
  （`inspector_id = 当前用户ID` 且 `status = published`）。
- 打开任务详情 → 查看巡检内容与巡检位置 → 现场执行 → 填写：

| 字段 | 必填 | 说明 |
|:---|:---:|:---|
| 处理结果 | 是 | 现场情况描述、发现的问题与处置措施 |
| 处理结果图 | 否 | 现场照片，通过 `POST /web/upload` 上传后取 URL |

- 提交后调用 `PUT /app/inspect-tasks/:id/finish`，服务端在**同一事务**中：
  1. 校验任务存在且 `inspector_id` 为当前用户，`status` 为 `published`；
  2. 写入 `ac_inspect_record`（含全部快照字段，`status=finished`，`handled_dt=now`）；
  3. 更新 `ac_inspect_task.status = finished`。

## 5. 状态机

### 5.1 巡检任务状态流转

```
        ┌──────────────────────────────┐
        │   status = pending           │
        │   待发布（草稿）             │
        └──────────────┬───────────────┘
                       │ 发布（派单给巡检人）
                       ▼
        ┌──────────────────────────────┐
        │   status = published         │  ← 表默认值
        │   已发布（待巡检）           │
        │   ● 出现在巡检人 App 待办    │
        │   ● 生成巡检通知（未读红点） │
        │   ● 可编辑 / 可删除          │
        └──────┬─────────────┬─────────┘
               │             │
    巡检人提交 │             │ 管理员取消
   （App 端）  │             │
               ▼             ▼
  ┌────────────────────┐  ┌──────────────────────┐
  │ status = finished  │  │ status = canceled    │
  │ 已完成             │  │ 已取消               │
  │                    │  └──────────────────────┘
  │ ① 任务从「待处理」 │
  │    列表移除        │
  │ ② 生成 1 条         │
  │    ac_inspect_record│
  │ ③ 不可再编辑/处理  │
  └────────────────────┘
```

### 5.2 巡检记录生成时序

```
   管理员                 平台                   巡检人(App)
     │                     │                         │
     │ 新增巡检任务         │                         │
     ├────────────────────▶│                         │
     │                     │ ① ac_inspect_task       │
     │                     │    status=published     │
     │                     │ ② ac_notification       │
     │                     │    category=inspect     │
     │                     │    user_id=inspector_id │
     │                     ├────────────────────────▶│ 看到未读红点
     │                     │                         │
     │                     │                         │ 打开详情 → 现场巡检
     │                     │                         │ 填处理结果 + 结果图
     │                     │  ③ FinishInspectTask    │
     │                     │◀────────────────────────┤
     │                     │                         │
     │                     │ ┌─────────────────────┐ │
     │                     │ │ 事务：               │ │
     │                     │ │ 写 ac_inspect_record │ │
     │                     │ │ task.status=finished │ │
     │                     │ └─────────────────────┘ │
     │                     │                         │
     │ 查看「巡检记录」     │                         │
     ├────────────────────▶│ 记录已生成（已处理）    │
     │                     │                         │
     │ 查看「巡检任务管理」 │                         │
     ├────────────────────▶│ 该任务已移除（finished）│
```

### 5.3 「任务移除 + 记录生成」的等价关系

```
   任意时刻，对同一 task_id：

   若 ac_inspect_task.status ≠ finished
        → 巡检任务管理列表中可见
        → 巡检记录中查不到对应记录

   若 ac_inspect_task.status = finished
        → 巡检任务管理列表默认视图中不显示（已移除）
        → 巡检记录中恰好有 1 条 task_id 相同的记录

   恒等式：COUNT(inspect_record WHERE task_id = T)
         = 1  ⟺  task(T).status = finished
```
