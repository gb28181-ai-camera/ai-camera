## 1. 产品定位

AI 摄像头管理平台是一套面向**现场安全与合规监管**的物联网视频智能分析系统。平台接入部署
在工地、厂区、仓库、园区等现场的 AI 摄像头设备，由设备端完成风险识别（如未戴安全帽、
明火、人员闯入、区域入侵等），将识别结果（风险图片、录像、置信度）上报至平台；平台侧
完成风险汇聚、人工复核、处理闭环，并对设备自身的运行状态（在线/离线、电量、电压、存储、
物联网卡流量）进行监控与告警。

产品的核心价值是把**「设备看得见」**转变为**「风险管得住」**：

- **风险闭环**：从 AI 识别 → 人工确认检测准确性 → 填写处理结果与处理图片 → 归档，全链路留痕。
- **设备可运维**：设备在线状态、电量、存储、流量、固件与模型版本统一管理，支持远程升级。
- **责任人可追溯**：风险、告警、巡检均落到具体人员，消息通知带未读红点。
- **现场可巡检**：除 AI 自动识别外，补充人工巡检任务的派发与结果回传。

平台同时提供 **PC 管理后台（Web）** 与 **移动端（App）** 两个入口，共享同一套后端服务与业务数据。

## 3. 系统边界

### 3.1 在范围内

- 设备台账与运行状态管理（含物联网卡、语音配置、设备模式）。
- AI 风险记录的接收、复核、处理、归档与统计。
- 设备告警（离线 / 电量 / 流量）的接收、处理与统计。
- 实时视频监控（单屏 / 4 宫格 / 9 宫格）、GIS 地图定位、设备历史记录回放。
- 巡检任务的创建、派发、移动端处理与巡检记录归档。
- 固件与 AI 模型的版本管理，设备的现在升级 / 定时升级 / 批量升级。
- 三方平台集成：个推（App 推送）、腾讯云短信。
- 系统管理：用户 / 角色 / 菜单 / 部门 / 岗位 / 操作日志 / 系统通知。

### 3.2 不在范围内（由设备端或其他系统承担）

| 事项 | 承担方 |
|:---|:---|
| 视频流的采集、编码、推流 | 设备固件 |
| AI 风险识别算法与推理 | 设备端模型（平台只做模型文件版本管理） |
| 物联网卡开卡、续费、停机 | 运营商 / 物联网卡管理平台 |
| 短信通道本身的资质与计费 | 腾讯云 |
| 个推推送通道的可达性 | 个推 |

## 7. 日常操作流程

以下为操作手册开篇的**日常操作流程**原文，本平台的上手路径以此为准：

> **第一步：新建区域。**
> **第二步：新增设备，并选择区域。**
> **第三步：配置风险。**
> 新增固件与模型，可在设备升级管理中对设备进行固件及模型升级。
> **第四步：添加完后，可在风险监控中查看对应的风险信息。**
> **风险处理：对检测准确结果点"否"时，该条数据将会转为已处理状态；**
> **对检测准确结果点"是"时，消息通知会转为已读状态，可对该数据进行处理。点击处理按钮，填写处理结果及处理图片，处理后状态由未处理转为已处理。**

### 7.1 展开说明

**第一步：新建区域**

入口：「系统设置 → 基础信息管理 → 区域管理」。区域是平台的核心归属维度——设备、风险、
告警、巡检、物联网卡、语音配置全部支持按区域筛选，因此必须最先建立。填写区域名称与备注
即可；区域还支持「区域编码」用于外部系统对接。

**第二步：新增设备，并选择区域**

入口：「系统设置 → 资源管理 → 设备管理」。点击「新增」，填写设备名称、设备编号、设备位置
（经纬度用于 GIS 查看）、信息上传间隔等，并从下拉中选择：

- **所属区域** — 数据来自「区域管理」；
- **设备工作模式** — 数据来自「设备模式管理」（充电模式 / 全开模式 / 省电模式）；
- **物联网卡** — 数据来自「物联网卡管理」。

设备新增后，列表中可直接**点击设备模式**切换模式、点击**设备监控**按钮把该设备加入
「实时监控 → 设备监控」、点击**同步时间**让设备与服务器时间对齐。

**第三步：配置风险**

包含两部分工作：

1. **配置风险类型**：「基础信息管理 → 风险类型管理」维护风险类型、风险编码、风险等级
   （high / medium / low）、描述。风险等级用于首页与大屏的分级统计与配色。
2. **新增固件与模型，可在设备升级管理中对设备进行固件及模型升级**：先在
   「升级管理 → 固件类型管理 / 固件管理 / 模型管理」录入版本文件，再在
   「升级管理 → 设备升级管理 → 升级设备」选择目标设备下发升级。升级方式有三条路径：
   - **现在升级** — 立即下发，升级成功后「升级记录」增加一条记录；
   - **定时升级** — 生成一条「升级计划」任务，可点击「取消升级」取消；
   - **批量升级** — 勾选一条或多条设备后统一升级。

   若该风险类型需要现场语音播报，还需在「资源管理 → 语音配置管理」为其配置播报音频。

**第四步：添加完后，可在风险监控中查看对应的风险信息**

入口：「风险统计 → 风险监控」。列表展示设备拍摄上报的风险数据，包含风险类型、风险图片、
设备名称、设备编号、所属区域、发生时间、检测准确、消息通知、状态等。页面支持设置
**刷新频率**（10 秒 / 30 秒 / 60 秒）。

**风险处理（核心分支）**

| 操作 | 检测准确点「否」 | 检测准确点「是」 |
|:---|:---|:---|
| 数据状态 | **直接转为已处理状态** | 仍为未处理，等待处理 |
| 消息通知 | **转为已读状态** | **转为已读状态** |
| 后续动作 | 无需填写处理内容，流程结束 | 可点击「处理」按钮，填写处理结果及处理图片 |
| 处理后状态 | — | 由**未处理**转为**已处理** |

> **注意**：两条分支都要求「消息通知转为已读」，区别在于点「否」是误报，直接归档；
> 点「是」是真实风险，必须补充处理结果与处理图片才算闭环。

## 8. 全局状态与常量约定

### 8.1 处理状态（风险 / 告警）

| 值 | 含义 | 可执行操作 |
|:---|:---|:---|
| `pending` | 未处理 | 查看、复核检测准确性、处理、删除 |
| `handled` | 已处理 | 查看、删除 |

### 8.2 检测准确性

| 值 | 含义 | 副作用 |
|:---|:---|:---|
| `yes` | AI 检测准确 | `read=true`，仍需人工处理 |
| `no` | AI 检测不准确（误报） | `read=true`，`status` 直接置 `handled` |

### 8.3 设备运行状态

| 值 | 含义 |
|:---|:---|
| `online` | 在线 |
| `offline` | 离线 |

### 8.4 等级（风险 / 告警）

| 值 | 含义 |
|:---|:---|
| `high` | 高 |
| `medium` | 中（默认） |
| `low` | 低 |

### 8.5 通知类型与频率

| 通知类型 | 说明 |
|:---|:---|
| `app` | APP 推送（个推，默认） |
| `sms` | 短信（腾讯云） |
| `inner` | 站内通知 |

| 频率值（分钟） | 含义 |
|:---:|:---|
| 0 | 实时（默认） |
| 60 | 每小时 |
| 1440 | 每天 |

| 类别 | 要求 |
