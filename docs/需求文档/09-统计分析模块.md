# 统计分析模块

> 版本: v0.1.0
> 最后更新: 2026-09-21
> 需求来源: AI摄像头操作手册 第 7 节（风险统计分析 / 设备告警分析 / 可视化大屏）

## 1. 模块概述

统计分析模块把平台积累的风险与告警数据转化为**可决策的信息**，回答三个管理问题：

| 页面 | 问题 | 视角 |
|:---|:---|:---|
| 风险统计分析 | 「这段时间风险形势如何？哪类风险最多？处理得及时吗？」 | 时间维度切片 |
| 设备告警分析 | 「这段时间设备健康状况如何？哪类告警最多？哪些区域设备最不稳？」 | 时间维度切片 |
| 可视化大屏 | 「此刻整个现场是什么状况？」 | **实时**全景 |

分析维度覆盖：**风险类型、风险等级、所属区域、设备、时间趋势、处理状态**，
以及设备侧的**在线/离线、告警类型、流量消耗**。

> **本模块自身不持有数据表**。它是 04（风险）、06（告警）、03（设备）、05（设备历史）
> 等模块数据的**只读聚合层**，所有指标通过聚合查询实时计算。

## 2. 角色与权限

| 角色 | 可执行操作 |
|:---|:---|
| 系统管理员 | 查看风险统计分析、设备告警分析、可视化大屏 |
| 区域管理员 | 同上（受数据权限约束，统计口径限于授权区域） |
| 安全员 | 查看风险统计分析、设备告警分析与大屏（用于撰写安全周报） |
| 设备运维员 | 查看设备告警分析、大屏（关注设备健康与流量） |
| 决策层 | 主要使用可视化大屏（大屏展示常用账号） |
| 巡检员 | 无权限 |

权限码：

| 权限码 | 说明 |
|:---|:---|
| `stats:risk` | 风险统计分析 |
| `stats:alarm` | 设备告警分析 |
| `stats:screen` | 可视化大屏 |
| `stats:traffic` | 流量监控统计 |
| `stats:deviceStatus` | 设备状态统计 |

> **注意**：所有统计类接口**同样受数据权限约束**（`utils.NewDataScope(c)`）。
> 同一个统计页面，不同角色的用户看到的数值不同——这是设计预期，不是缺陷。
> 可视化大屏通常建议绑定「全部数据」权限的展示账号。

## 3. 数据模型

### 3.1 本模块不新建表

统计分析模块是**零表模块**。其数据来源：

```
   ┌────────────────────────────────────────────────────────────────────┐
   │                     统计分析的四个数据源                            │
   ├────────────────────────────────────────────────────────────────────┤
   │                                                                    │
   │  ① ac_risk_record        风险记录（04 模块）                       │
   │     ├─ risk_type_id  ──▶ ac_risk_type.name / level  按类型、等级    │
   │     ├─ region_id     ──▶ ac_region.name             按区域         │
   │     ├─ device_id     ──▶ ac_device.name             按设备         │
   │     ├─ occurred_dt                                  时间趋势       │
   │     ├─ status        pending / handled              处理率         │
   │     ├─ handled_dt                                   处理时效       │
   │     └─ detect_accurate  yes / no                    误报率         │
   │                                                                    │
   │  ② ac_alarm_record       告警记录（06 模块）                       │
   │     ├─ alarm_type_id ──▶ ac_alarm_type.name         按告警类型     │
   │     ├─ region_id     ──▶ ac_region.name             按区域         │
   │     ├─ device_id     ──▶ ac_device.name             按设备         │
   │     ├─ alarm_level   high / medium / low            按等级         │
   │     ├─ occurred_dt                                  时间趋势       │
   │     └─ status        pending / handled              处理率         │
   │                                                                    │
   │  ③ ac_device            设备台账（03 模块）                        │
   │     ├─ status        online / offline               在线/离线数量   │
   │     ├─ region_id     ──▶ ac_region.name             区域设备分布   │
   │     ├─ battery                                      电量分布       │
   │     ├─ storage_free                                 存储余量       │
   │     └─ monitor_enabled                              监控覆盖率     │
   │                                                                    │
   │  ④ ac_iot_card          物联网卡（03 模块）                        │
   │     ├─ traffic_total / traffic_used / traffic_left   流量监控      │
   │     ├─ device_id     ──▶ ac_device.name             按设备流量     │
   │     ├─ region_id     ──▶ ac_region.name             按区域流量     │
   │     └─ stat_dt / expire_dt                          统计/到期时间  │
   │                                                                    │
   └────────────────────────────────────────────────────────────────────┘
                                     │
                                     ▼
                        ┌────────────────────────┐
                        │  StatsService 聚合查询 │
                        │  /web/stats/*          │
                        └────────────────────────┘
```

### 3.2 聚合字段口径

| 指标 | 口径 | 来源 |
|:---|:---|:---|
| 风险总数 | `COUNT(*)` 按 `occurred_dt` 落在区间内 | `ac_risk_record` |
| 未处理风险 | `COUNT(*) WHERE status='pending'` | `ac_risk_record` |
| 已处理风险 | `COUNT(*) WHERE status='handled'` | `ac_risk_record` |
| 风险处理率 | 已处理 / 总数 | 计算值 |
| 误报数 | `COUNT(*) WHERE detect_accurate='no'` | `ac_risk_record` |
| 误报率 | 误报数 / 已确认数 | 计算值 |
| 平均处理时长 | `AVG(handled_dt - occurred_dt)` | `ac_risk_record` |
| 告警总数 | `COUNT(*)` 按 `occurred_dt` 落在区间内 | `ac_alarm_record` |
| 设备总数 | `COUNT(*)` | `ac_device` |
| 在线数量 | `COUNT(*) WHERE status='online'` | `ac_device` |
| 离线数量 | `COUNT(*) WHERE status='offline'` | `ac_device` |
| 在线率 | 在线数量 / 设备总数 | 计算值 |
| 流量总额 / 已用 / 剩余 | `SUM(traffic_total / used / left)` | `ac_iot_card` |

> **注意**：所有聚合统计**必须排除软删除数据**（`deleted_at IS NULL`），
> 且**必须施加数据权限过滤**（`dept_id` 维度的 `DataScope`）。

## 4. 功能需求

### 4.1 风险统计分析

**操作说明**（手册 7.1 节）：

- 可查看该时间段风险统计信息。

**业务规则**：

- 页面顶部提供**时间段选择器**（起止日期），切换后所有图表随之刷新。
- 默认时间段建议为**本月**（`month`），可选本周 / 本月 / 自定义区间。
- 统计维度：

| 统计项 | 说明 | 可视化建议 |
|:---|:---|:---|
| 风险总数 | 区间内风险总量 | 数值卡片 |
| 待处理 / 已处理 | 处理状态分布 | 环形图 / 饼图 |
| 处理率 | 已处理占比 | 仪表盘 / 进度条 |
| 风险类型分布 | 按 `ac_risk_type.name` 聚合 | 柱状图 / 排行榜 |
| 风险等级分布 | 按 `risk_level`（high/medium/low）聚合 | 堆叠柱状图（红/橙/黄配色） |
| 区域分布 | 按 `ac_region.name` 聚合 | 横向柱状图 / 地图 |
| 设备分布 | 按 `ac_device.name` 聚合 | 排行榜（TOP N） |
| 时间趋势 | 按日 / 周 / 月分组 `occurred_dt` | 折线图 |
| 检测准确性 | `detect_accurate` 的 yes / no 占比（误报率） | 环形图 |
| 处理时效 | `AVG(handled_dt - occurred_dt)` | 数值卡片 |

**列表字段**（明细表，可选）：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 风险类型 | 聚合名称 | `ac_risk_type.name` |
| 风险等级 | high/medium/low | `ac_risk_record.risk_level` |
| 所属区域 | 聚合名称 | `ac_region.name` |
| 风险数量 | 该维度下的计数 | `COUNT(*)` |
| 已处理数量 | `status='handled'` | `COUNT(*)` |
| 未处理数量 | `status='pending'` | `COUNT(*)` |
| 处理率 | 已处理 / 总数 | 计算值 |

**搜索条件**：时间段（`start_dt` / `end_dt`，**必填**）；扩展支持所属区域、风险类型、
风险等级。

**排序**：明细表按风险数量倒序（排行榜语义）。

### 4.3 可视化大屏

**操作说明**（手册 7.3 节）：

- AI摄像头大屏中可直观查看风险实时告警、设备状态告警、风险统计、设备告警统计、设备监控、流量监控、设备总数、在线数量及离线数量相关信息。

**业务规则**：

- 大屏为**全屏可视化展示页**，用于指挥中心 / 监控室大屏投放，深色主题、自动轮询刷新。
- 手册明确要求大屏包含以下**九个板块**，缺一不可：

| # | 板块 | 内容 | 数据来源 |
|:--:|:---|:---|:---|
| 1 | **风险实时告警** | 最新风险滚动列表：风险图片、风险类型、设备名称、区域、发生时间 | `ac_risk_record` + `ac_risk_type` + `ac_device` + `ac_region` |
| 2 | **设备状态告警** | 最新设备告警滚动列表：告警类型、设备、区域、告警时间 | `ac_alarm_record` + `ac_alarm_type` + `ac_device` |
| 3 | **风险统计** | 风险类型分布、风险等级分布、风险趋势 | `ac_risk_record` 聚合 |
| 4 | **设备告警统计** | 告警类型分布、告警趋势 | `ac_alarm_record` 聚合 |
| 5 | **设备监控** | 监控画面/设备状态列表（取 `monitor_enabled=true` 的设备） | `ac_device` |
| 6 | **流量监控** | 物联网卡流量使用情况：总流量、已用、剩余、消耗趋势 | `ac_iot_card` 聚合 |
| 7 | **设备总数** | 平台设备总量 | `COUNT(ac_device)` |
| 8 | **在线数量** | 在线设备数 | `COUNT WHERE status='online'` |
| 9 | **离线数量** | 离线设备数 | `COUNT WHERE status='offline'` |

- **刷新策略**：实时告警类板块高频刷新（建议 10~30 秒），统计类板块低频刷新
  （建议 60 秒~5 分钟），避免大屏持续高负载查询。
- **无操作自动保持**：大屏页面不因长时间无操作而退出登录（需单独配置会话策略）。
- 所有数值同样受数据权限约束；大屏账号建议配置「全部数据」权限。

**列表字段**：

**风险实时告警**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 风险图片 | 缩略图 | `ac_risk_record.image_url` |
| 风险类型 | — | `ac_risk_type.name` |
| 风险等级 | 用于配色 | `ac_risk_record.risk_level` |
| 设备名称 | — | `ac_device.name` |
| 所属区域 | — | `ac_region.name` |
| 发生时间 | — | `ac_risk_record.occurred_dt` |

**设备状态告警**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 告警类型 | 离线/电量/流量 | `ac_alarm_type.name` |
| 告警等级 | — | `ac_alarm_record.alarm_level` |
| 设备名称 | — | `ac_device.name` |
| 所属区域 | — | `ac_region.name` |
| 告警时间 | — | `ac_alarm_record.occurred_dt` |

**流量监控**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 物联网卡名称 | — | `ac_iot_card.name` |
| 卡号 | — | `ac_iot_card.card_no` |
| 所属设备 | — | `ac_device.name` |
| 流量总额 | MB | `ac_iot_card.traffic_total` |
| 已使用流量 | MB | `ac_iot_card.traffic_used` |
| 剩余流量 | MB | `ac_iot_card.traffic_left` |

**搜索条件**：无（大屏为全局展示）；扩展支持按区域切换。

**排序**：实时告警按时间倒序（最新在最上）；排行榜按数量倒序。

### 4.4 流量监控与设备状态统计（大屏支撑接口）

**业务规则**：

- `GET /web/stats/traffic` 提供流量监控聚合：全平台流量总额 / 已用 / 剩余、
  按区域或设备的流量排行、流量消耗趋势。
- `GET /web/stats/device-status` 提供设备状态聚合：设备总数、在线数量、离线数量、
  在线率，以及按区域的在线/离线分布。
- 这两个接口同时服务于**首页看板**的「设备统计」卡片（见 `10-首页与告警设置模块.md`）。

## 5. 状态机

### 5.1 统计分析模块无独立状态机

本模块为**只读聚合层**，不持有业务表，因此没有自身的状态流转。但它**观测**其它模块的
状态机，并把状态分布作为统计口径：

```
   ac_risk_record.status
   ┌──────────┐  人工处理   ┌──────────┐
   │ pending  │ ─────────▶ │ handled  │
   │ 未处理   │            │ 已处理   │
   └──────────┘            └──────────┘
        │                       │
        └───────┬───────────────┘
                ▼
        风险统计口径：
          pending 数 → 「待处理」卡片 / 处理率分母
          handled 数 → 「已处理」卡片 / 处理率分子

   ac_alarm_record.status
   ┌──────────┐  人工处理   ┌──────────┐
   │ pending  │ ─────────▶ │ handled  │
   └──────────┘            └──────────┘
        │                       │
        └───────┬───────────────┘
                ▼
        告警统计口径：同上

   ac_device.status
   ┌──────────┐   心跳恢复   ┌──────────┐
   │ offline  │ ◀─────────▶ │ online   │
   └──────────┘   心跳超时   └──────────┘
        │                       │
        └───────┬───────────────┘
                ▼
        大屏口径：离线数量 / 在线数量 / 设备总数
```

### 5.2 大屏数据刷新时序

```
   大屏打开
      │
      ▼
   ┌──────────────────────────────────────────────┐
   │ t=0：全量拉取 GET /web/stats/screen           │
   │      风险实时告警 / 设备状态告警 / 风险统计    │
   │      / 设备告警统计 / 设备监控 / 流量监控      │
   │      / 设备总数 / 在线数量 / 离线数量          │
   └──────────────────┬───────────────────────────┘
                      │
        ┌─────────────┴─────────────┐
        ▼                           ▼
   每 10~30 秒                  每 60 秒~5 分钟
   刷新实时告警类板块            刷新统计类板块
   （风险实时告警、              （风险统计、设备告警统计、
     设备状态告警、              流量监控、设备总数、
     在线/离线数量）             在线数量、离线数量）
        │                           │
        └─────────────┬─────────────┘
                      ▼
              页面关闭 / 切换 → 停止轮询，释放请求
```

## 8. 初始数据建议

```sql
-- 本模块不新建表，无需初始化 DDL 数据。
-- 以下为验证统计口径的参考 SQL（可直接用于联调对数）。

-- ① 风险统计分析：时间段内按风险类型聚合
SELECT rt.name              AS risk_type,
       rr.risk_level        AS level,
       COUNT(*)             AS total,
       COUNT(*) FILTER (WHERE rr.status = 'handled') AS handled,
       COUNT(*) FILTER (WHERE rr.status = 'pending') AS pending
  FROM ac_risk_record rr
  JOIN ac_risk_type rt ON rt.id = rr.risk_type_id
 WHERE rr.deleted_at IS NULL
   AND rr.occurred_dt BETWEEN :start_dt AND :end_dt
 GROUP BY rt.name, rr.risk_level
 ORDER BY total DESC;

-- ② 风险统计：按日趋势 + 误报率
SELECT date_trunc('day', rr.occurred_dt)::date AS day,
       COUNT(*)                                AS total,
       COUNT(*) FILTER (WHERE rr.detect_accurate = 'no')  AS false_positive,
       ROUND(100.0 * COUNT(*) FILTER (WHERE rr.detect_accurate = 'no')
             / NULLIF(COUNT(*) FILTER (WHERE rr.detect_accurate IS NOT NULL), 0), 2)
                                               AS fp_rate_pct,
       ROUND(AVG(EXTRACT(EPOCH FROM (rr.handled_dt - rr.occurred_dt)) / 60)
             FILTER (WHERE rr.handled_dt IS NOT NULL), 1) AS avg_handle_minutes
  FROM ac_risk_record rr
 WHERE rr.deleted_at IS NULL
   AND rr.occurred_dt BETWEEN :start_dt AND :end_dt
 GROUP BY 1
 ORDER BY 1;

-- ③ 设备告警分析：按告警类型聚合
SELECT at.name                AS alarm_type,
       ar.alarm_level         AS level,
       ar.region_id,
       COUNT(*)               AS total,
       COUNT(*) FILTER (WHERE ar.status = 'handled') AS handled
  FROM ac_alarm_record ar
  JOIN ac_alarm_type at ON at.id = ar.alarm_type_id
 WHERE ar.deleted_at IS NULL
   AND ar.occurred_dt BETWEEN :start_dt AND :end_dt
 GROUP BY at.name, ar.alarm_level, ar.region_id
 ORDER BY total DESC;

-- ④ 大屏：设备总数 / 在线数量 / 离线数量
SELECT COUNT(*)                                        AS device_total,
       COUNT(*) FILTER (WHERE status = 'online')       AS online_count,
       COUNT(*) FILTER (WHERE status = 'offline')      AS offline_count,
       ROUND(100.0 * COUNT(*) FILTER (WHERE status = 'online')
             / NULLIF(COUNT(*), 0), 1)                 AS online_rate_pct
  FROM ac_device
 WHERE deleted_at IS NULL;

-- ⑤ 大屏：流量监控汇总
SELECT COUNT(*)                    AS card_count,
       SUM(traffic_total)          AS traffic_total_mb,
       SUM(traffic_used)           AS traffic_used_mb,
       SUM(traffic_left)           AS traffic_left_mb,
       COUNT(*) FILTER (WHERE traffic_left < 200) AS low_traffic_cards
  FROM ac_iot_card
 WHERE deleted_at IS NULL;

-- ⑥ 大屏：风险实时告警（最新 10 条）
SELECT rr.id, rr.image_url, rt.name AS risk_type, rr.risk_level,
       d.name AS device_name, r.name AS region_name, rr.occurred_dt
  FROM ac_risk_record rr
  JOIN ac_risk_type rt ON rt.id = rr.risk_type_id
  JOIN ac_device    d  ON d.id  = rr.device_id
  LEFT JOIN ac_region r ON r.id = rr.region_id
 WHERE rr.deleted_at IS NULL
 ORDER BY rr.occurred_dt DESC
 LIMIT 10;

-- ⑦ 大屏：设备状态告警（最新 10 条）
SELECT ar.id, at.name AS alarm_type, ar.alarm_level,
       d.name AS device_name, r.name AS region_name, ar.occurred_dt
  FROM ac_alarm_record ar
  JOIN ac_alarm_type at ON at.id = ar.alarm_type_id
  JOIN ac_device    d   ON d.id  = ar.device_id
  LEFT JOIN ac_region r ON r.id  = ar.region_id
 WHERE ar.deleted_at IS NULL
 ORDER BY ar.occurred_dt DESC
 LIMIT 10;
```
