# 实时监控模块

> 版本: v0.1.0
> 最后更新: 2026-09-21
> 需求来源: AI摄像头操作手册 第 2 节（实时监控）

## 1. 模块概述

实时监控模块是平台的**「现场之眼」**。管理人员无需到达现场，即可在浏览器中同时观看一路或
多路摄像头画面，用于：

- **突发事件的实时确认**：收到风险通知后，立即调出该点位的实时画面判断现场是否需要处置；
- **多点位并行值守**：用 4 宫格 / 9 宫格同时盯守多个关键点位（如多个出入口、危化品库、
  高处作业面）；
- **处置过程的实时跟踪**：安全员到现场处理期间，通过实时画面确认处理到位。

模块提供三种布局：**单屏、4 宫格、9 宫格**。

> **本模块自身不持有数据表**。它是对「资源管理 → 设备管理」中已启用监控的设备
> （`ac_device.monitor_enabled = true`）所持有的 `stream_url` 进行**播放与分屏编排**，
> 属于**纯前端编排 + 后端提供流地址**的模块。

## 2. 角色与权限

| 角色 | 可执行操作 |
|:---|:---|
| 系统管理员 | 进入实时监控、单屏/4宫格/9宫格切换、选择区域与摄像头、全屏、抓拍 |
| 区域管理员 | 同上（受数据权限约束——只能选择授权区域内的摄像头） |
| 安全员 | 同上；从风险/告警详情跳入实时监控查看指定点位 |
| 设备运维员 | 同上（用于远程查看设备成像效果，判断故障） |
| 巡检员 | 无权限（移动端不提供多屏监控，仅在风险详情中播放单路实时视频） |

权限码：

| 权限码 | 说明 |
|:---|:---|
| `monitor:live` | 进入实时监控页面 |
| `monitor:grid1` | 单屏布局 |
| `monitor:grid4` | 4 宫格布局 |
| `monitor:grid9` | 9 宫格布局 |

## 4. 功能需求

### 4.1 实时监控

**操作说明**（手册第 2 节）：

- 可单屏、4宫格、9宫格显示视频监控，需选择区域和摄像头后才会显示视频监控。

**业务规则**：

**（1）布局切换：单屏 / 4宫格 / 9宫格**

- 页面顶部提供布局切换控件，三种模式对应 **1 路 / 4 路 / 9 路**画面。
- 切换布局时，已选中的摄像头**按顺序填入新增的窗口**；从 9 宫格切回 4 宫格时，
  第 5~9 路被移除（应在切换前二次确认或自动保留前 4 路）。

| 布局 | 窗口数 | 适用场景 |
|:---:|:---:|:---|
| 单屏 | 1 | 重点盯守单一高风险点位 |
| 4 宫格 | 4 | 小型厂区出入口、4 个关键作业面 |
| 9 宫格 | 9 | 中大型厂区全景值守 |

**（2）必须先选择区域和摄像头**

- **「需选择区域和摄像头后才会显示视频监控」**——这是本模块最核心的交互约束。
- 页面初始状态下所有窗口均为**空白占位**（显示「请选择区域和摄像头」提示），
  **不会自动播放任何画面**。
- 选择流程（两级联动）：

```
   ① 选择「区域」
        │  下拉数据来源：ac_region（受数据权限过滤）
        │  仅列出 active = true 的区域
        ▼
   ② 选择「摄像头」（可多选）
        │  下拉数据来源：ac_device
        │  过滤条件：region_id = 选中区域
        │            AND monitor_enabled = true   ← 只有加入监控的设备才可选
        │            AND 在调用者的数据权限范围内
        ▼
   ③ 选中的摄像头按选择顺序填入 1..N 号窗口
        │
        ▼
   ④ 逐窗口建立播放会话（读取 stream_url）
```

- 摄像头下拉中建议展示「设备名称 + 设备编号 + 运行状态」，离线设备置灰或标注「离线」。

**（3）画面播放**

- 每个窗口读取对应设备的 `stream_url` 建立播放。
- **设备在线（`status = online`）才可播放**。离线设备窗口显示「设备离线」占位，
  并在副标题提示最近离线时间（`offline_dt`）或最近心跳（`last_beat_dt`）。
- 播放失败（流地址不可达 / 协议不支持）时，窗口显示错误提示与「重试」按钮，
  不上抛全局报错，避免影响其它窗口。

**（4）窗口上的操作**

| 操作 | 说明 |
|:---|:---|
| 切换摄像头 | 单个窗口可单独更换摄像头，不影响其它窗口 |
| 关闭窗口 | 清空该窗口，停止播放该路 |
| 全屏 | 对单个窗口全屏放大（再次触发退出全屏） |
| 抓拍 | 截取当前帧并下载/上传留证（图片走 `POST /web/upload`） |
| 查看风险 | 跳转至风险监控模块，按该设备筛选（与设备监控页行为一致） |

**（5）与其它模块的联动**

| 入口 | 行为 |
|:---|:---|
| 风险监控 → 「查看实时监控画面」 | 直接以单屏打开该风险所属设备的实时画面 |
| 设备管理 → 「设备监控」按钮 | 把该设备加入 / 移出实时监控的可选列表 |
| 设备监控页 → 「查看实时视频」 | 打开该设备的实时画面 |
| AI监控页 | 选择区域和摄像头后显示视频监控与风险信息（同源播放能力） |

**列表字段**（摄像头选择列表）：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 设备名称 | 窗口标题 | `ac_device.name` |
| 设备编号 | — | `ac_device.device_code` |
| 所属区域 | — | `ac_region.name` |
| 设备位置 | 窗口副标题 | `ac_device.location` |
| 运行状态 | 在线/离线（决定可否播放） | `ac_device.status` |
| 是否加入监控 | 只有已加入的设备可选 | `ac_device.monitor_enabled` |
| 视频流地址 | 播放源 | `ac_device.stream_url` |

**搜索条件**：所属区域（`region_id`，**必选**）、摄像头（设备，多选）。

**排序**：摄像头下拉按设备编号升序，便于按编号定位。

### 4.2 播放资源与并发

**业务规则**：

- 单浏览器标签页最多同时播放 **9 路**（9 宫格上限）。建议后端对单用户并发拉流数做限制，
  超出时返回友好提示。
- 单路播放建议使用**低延迟协议**（WebRTC / HTTP-FLV）；若设备只支持 RTSP，
  需经流媒体网关转协议后播放，前端不得直接播放 RTSP。
- 窗口在**不可见**（切到后台标签页）时应暂停拉流，减少带宽与解码压力。
- 关闭页面或切换布局时，必须**显式释放播放器实例**，避免流会话泄漏占用设备上行带宽。

## 5. 状态机

### 5.1 窗口播放状态

```
   ┌──────────────────┐
   │   空白占位        │  ← 初始状态：未选择区域和摄像头
   │ 「请选择区域和    │
   │   摄像头」        │
   └────────┬─────────┘
            │ 选择区域 + 摄像头
            ▼
   ┌──────────────────┐
   │   连接中          │  ← 正在建立播放会话
   └────────┬─────────┘
            │
     ┌──────┴───────┬──────────────────┐
     │              │                  │
   成功           设备离线          流地址不可达
     │              │                  │
     ▼              ▼                  ▼
┌─────────┐  ┌─────────────┐  ┌─────────────────┐
│  播放中  │  │  离线占位    │  │   播放失败       │
│  正常   │  │  显示最近    │  │  显示错误 +      │
│  可全屏  │  │  离线时间    │  │  「重试」按钮    │
│  可抓拍  │  └──────┬──────┘  └────────┬────────┘
└────┬────┘         │                  │
     │              │ 设备恢复心跳      │ 点击重试
     │              └──────────────────┘
     │  关闭窗口 / 更换摄像头 / 切换布局
     ▼
┌──────────────────┐
│   释放播放器      │  → 回到「空白占位」
│   释放流会话      │
└──────────────────┘
```

### 5.2 设备可选性判定

```
   ac_device 记录
        │
        ├── monitor_enabled = false ──▶ 不出现在摄像头下拉中
        │                              （需先在「设备管理」点击「设备监控」）
        │
        └── monitor_enabled = true
                 │
                 ├── 不在数据权限范围内 ──▶ 不出现（行级过滤）
                 │
                 └── 在数据权限范围内
                          │
                          ├── status = offline ──▶ 出现但置灰，标注「离线」
                          │
                          └── status = online  ──▶ 出现且可选，可正常播放
```

## 7. API 接口

### 7.1 实时监控所需接口

| 方法 | 路由 | 说明 |
|:---|:---|:---|
| GET | `/web/devices` | 设备列表（按 `region_id` + `monitor_enabled` 过滤得到可选摄像头） |
| GET | `/web/devices/options` | 设备下拉选项（选择区域后联动） |
| GET | `/web/devices/:id` | 设备详情（获取 `stream_url`、`status`、`last_beat_dt`） |
| PUT | `/web/devices/:id/monitor` | 加入 / 移出实时监控（切换 `monitor_enabled`） |

### 7.2 区域与联动

| 方法 | 路由 | 说明 |
|:---|:---|:---|
| GET | `/web/basic/regions/options` | 区域下拉选项（「选择区域」数据来源） |
| GET | `/web/risks` | 风险监控跳转实时监控时定位设备 |
| POST | `/web/upload` | 抓拍图片上传 |

### 7.3 移动端

| 方法 | 路由 | 说明 |
|:---|:---|:---|
| GET | `/app/devices/:id` | 移动端设备详情（单路实时视频，不提供多屏） |

> **说明**：实时视频流本身不由后端 REST 接口传输，而是由设备 / 流媒体网关按
> `stream_url` 提供。后端只负责返回流地址与鉴权信息。若需防盗链，可在
> `stream_url` 中携带短时效签名参数，由 `GET /web/devices/:id` 动态生成。
