# 设备监控模块

> 版本: v0.1.0
> 最后更新: 2026-09-21
> 需求来源: AI摄像头操作手册 第 5.2 节（设备监控 / GIS查看 / 设备历史记录）

## 1. 模块概述

设备监控模块回答一个运维问题：**「现场那一百台设备，此刻都是什么状态？」**

风险监控模块关注「设备看到了什么」，设备监控模块关注「设备自己还好不好」。它由三个页面
组成，构成从**当前快照 → 地理分布 → 历史趋势**的完整观测链：

| 页面 | 观测维度 | 数据来源 |
|:---|:---|:---|
| 设备监控 | **当前时刻**的设备健康快照 + 实时视频/录像入口 | `ac_device` |
| GIS查看 | **空间维度**的设备地理分布 | `ac_device.latitude` / `longitude` |
| 设备历史记录 | **时间维度**的运行曲线与历史状态回放 | `ac_device_history` |

设备监控页面展示设备名称、设备编号、所属区域、设备位置、**电量**、**存储容量**、
**在线-离线时间**、**运行状态**、**实时视频**、**视频录像**；设备历史记录在此之上进一步
加入**电压**、**流量卡号**、**剩余存储容量**与**历史曲线**。

> **注意**：实时视频与录像**均需设备在线**（`status=online`）时才可播放。设备离线时按钮
> 置灰并提示「设备离线，无法查看」。

### 3.2 ac_device_history - 设备运行历史（时序）

```sql
CREATE TABLE ac_device_history (
    id              BIGSERIAL PRIMARY KEY,
    deleted_at      TIMESTAMPTZ,
    created_by      VARCHAR(50),
    created_dt      TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    updated_by      VARCHAR(50),
    updated_dt      TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,

    device_id       BIGINT NOT NULL,                       -- 设备ID
    device_code     VARCHAR(100),                          -- 设备编号(冗余)
    iot_card_no     VARCHAR(100),                          -- 流量卡号(冗余)
    region_id       BIGINT,                                -- 所属区域
    location        VARCHAR(255),                          -- 设备位置(冗余)
    status          VARCHAR(20),                           -- 运行状态 online/offline
    battery         INTEGER,                               -- 电量百分比
    voltage         VARCHAR(32),                           -- 电压
    storage_free    BIGINT,                                -- 剩余存储容量(MB)
    sampled_dt      TIMESTAMPTZ,                           -- 采样时间

    dept_id         BIGINT                                 -- 所属部门(数据权限)
);
CREATE INDEX idx_ac_device_history_device_dt ON ac_device_history (device_id, sampled_dt);
CREATE INDEX idx_ac_device_history_dept_id ON ac_device_history (dept_id);
CREATE INDEX idx_ac_device_history_deleted_at ON ac_device_history (deleted_at);

COMMENT ON TABLE ac_device_history IS '设备运行历史（时序采样）。支撑「设备历史记录」页的近3日曲线与一周运行状态回放';
COMMENT ON COLUMN ac_device_history.device_code IS '设备编号(冗余)';
COMMENT ON COLUMN ac_device_history.iot_card_no IS '流量卡号(冗余)';
COMMENT ON COLUMN ac_device_history.location IS '设备位置(冗余)';
COMMENT ON COLUMN ac_device_history.status IS '运行状态 online/offline';
COMMENT ON COLUMN ac_device_history.storage_free IS '剩余存储容量(MB)';
COMMENT ON COLUMN ac_device_history.sampled_dt IS '采样时间';
```

> **注意**：本表是**追加写入的时序表**，不做修改。写入时机为设备心跳上报
> （`POST /web/devices/:id/heartbeat`）：平台在更新 `ac_device` 的**最新快照**字段
> （`status` / `battery` / `voltage` / `storage_free` / `online_dt` / `offline_dt` /
> `last_beat_dt`）之外，同步插入一条 `ac_device_history` 采样记录。
> 二者分工：`ac_device` 供列表展示当前值，`ac_device_history` 供曲线与回放。

## 4. 功能需求

### 4.1 设备监控

**操作说明**（手册 5.2 节·设备监控）：

- 设备监控中可查看设备监控信息，包括设备名称、设备编号、所属区域、设备位置、电量、存储容量、在线-离线时间、运行状态、实时视频、视频录像等相关内容。
- 操作说明：
  - 点击查看实时视频/查看录像，可查看该设备的实时视频/视频录像（需设备在线时）；
  - 选择运行状态、所属区域、设备名称、设备编号等条件进行搜索；
  - 点击列表中设备名称，并跳转至风险监控模块中，可筛选出该设备名称的所有风险监控数据。
  - 排序：点击设备编号，可根据设备编号进行正序或倒序排序。

**业务规则**：

- **「查看实时视频」**：播放 `ac_device.stream_url` 的实时流。
- **「查看录像」**：播放该设备的历史录像。
- **两者均需设备在线时可用**——即 `status = online`。设备离线时按钮置灰，提示
  「设备离线，无法查看」。判断依据为最新的 `last_beat_dt` 是否在心跳超时阈值内。
- **「点击设备名称」**：跳转至**风险监控模块**，并自动把该设备名称填入筛选条件，
  筛出该设备的所有风险监控数据。等价于风险监控列表的 `device_id` 筛选。
- **排序：点击设备编号列头**可在**正序 / 倒序**间切换。

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 设备名称 | **可点击跳转风险监控并按此设备筛选** | `ac_device.name` |
| 设备编号 | **点击可正序/倒序排序** | `ac_device.device_code` |
| 所属区域 | — | `ac_region.name` |
| 设备位置 | — | `ac_device.location` |
| 电量 | 百分比 | `ac_device.battery` |
| 存储容量 | 总容量 / 剩余容量（MB） | `ac_device.storage_total` / `ac_device.storage_free` |
| 在线-离线时间 | 最近上线 / 最近离线时间 | `ac_device.online_dt` / `ac_device.offline_dt` |
| 运行状态 | 在线 / 离线 | `ac_device.status` |
| 实时视频 | 「查看实时视频」按钮（需在线） | `ac_device.stream_url` |
| 视频录像 | 「查看录像」按钮（需在线） | — |
| 操作 | 查看实时视频、查看录像 | — |

**搜索条件**（手册明确列举，全部必须实现）：

1. 运行状态（`status`）
2. 所属区域（`region_id`）
3. 设备名称（模糊）
4. 设备编号（模糊）

**排序**：**点击设备编号列头正序 / 倒序**（默认升序）。

> **说明**：本页展示范围受 `ac_device.monitor_enabled` 影响——只有被标记「设备监控」的
> 设备才会出现在**实时监控 → 设备监控画面**中（见 `07-实时监控模块.md`）；而本页的设备
> 监控列表默认展示权限范围内的全部设备，可通过搜索与排序定位目标设备。

### 4.2 GIS 查看

**操作说明**（手册 5.2 节·GIS查看）：

- 可在GIS地图中查看设备的相关位置，鼠标移至图标上可查看该设备的相关信息。点击查看风险，跳转至风险监控模块中，可查看该设备的风险信息。

**业务规则**：

- 地图按设备的 `latitude` / `longitude` 渲染图标；坐标为空或非法的设备不在地图上显示。
- **鼠标移至图标上**弹出该设备的相关信息卡片，建议包含：设备名称、设备编号、所属区域、
  设备位置、运行状态、电量、最近心跳时间。
- 卡片上提供「**查看风险**」按钮 → **跳转至风险监控模块**，筛出该设备的风险信息。
- 图标按设备运行状态区分样式（在线 / 离线使用不同颜色），便于一眼看出哪些点位掉线。

**列表字段**（地图信息卡片）：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 设备名称 | — | `ac_device.name` |
| 设备编号 | — | `ac_device.device_code` |
| 所属区域 | — | `ac_region.name` |
| 设备位置 | — | `ac_device.location` |
| 运行状态 | 在线 / 离线 | `ac_device.status` |
| 电量 | 百分比 | `ac_device.battery` |
| 最近心跳 | — | `ac_device.last_beat_dt` |
| 操作 | 查看风险（跳转风险监控） | — |

**搜索条件**：所属区域（`region_id`）、运行状态（`status`）、设备名称（模糊）。

**排序**：不适用（地图渲染）。

### 4.3 设备历史记录

**操作说明**（手册 5.2 节·设备历史记录）：

- 设备历史记录中可查看设备历史记录信息，包括设备名称、设备编号、流量卡号、所属区域、设备位置、电量、电压、剩余存储容量、在线-离线时间、运行状态、历史曲线等相关内容。
- 操作说明：
  - 选择运行状态、所属区域、设备名称、设备编号等条件进行搜索；
  - 查看图表：可查看近3日的运行状态统计、电量统计、存储容量统计、状态与电量统计、电压与电量统计等图表信息。
  - 查看历史运行状态：需先选择区域，并点击查询，再可点击"查看历史运行状态"按钮，可查看设备一周的历史运行状态信息。

**业务规则**：

**（1）「查看图表」—— 近 3 日统计图**

点击「查看图表」后可查看以下**五类图表**（数据来自 `ac_device_history` 近 3 天采样）：

| 图表 | 说明 | 使用字段 |
|:---|:---|:---|
| 运行状态统计 | 近 3 日在线的时长/占比分布 | `status`, `sampled_dt` |
| 电量统计 | 近 3 日电量变化曲线 | `battery`, `sampled_dt` |
| 存储容量统计 | 近 3 日剩余存储容量变化曲线 | `storage_free`, `sampled_dt` |
| 状态与电量统计 | 状态与电量的双轴/叠加图 | `status`, `battery` |
| 电压与电量统计 | 电压与电量的双轴/叠加图 | `voltage`, `battery` |

接口：`GET /web/devices/:id/history-chart`（默认 `days=3`）。

**（2）「查看历史运行状态」—— 一周回放**

- **前置条件（必须严格遵守）**：**需先选择区域，并点击「查询」，再可点击「查看历史运行
  状态」按钮**。即未选择区域或未执行查询时，该按钮不可用。
- 满足前置条件后点击，可查看**设备一周（7 天）的历史运行状态**信息。
- 服务端按区域 + 设备维度，扫描 `ac_device_history` 近 7 天的 `status` 采样，
  以时间轴方式回放在线/离线段。

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 设备名称 | — | `ac_device.name` |
| 设备编号 | — | `ac_device_history.device_code` |
| 流量卡号 | 设备当前绑定的物联网卡号 | `ac_device_history.iot_card_no` |
| 所属区域 | — | `ac_region.name` |
| 设备位置 | — | `ac_device_history.location` |
| 电量 | 采样时刻电量百分比 | `ac_device_history.battery` |
| 电压 | 采样时刻电压 | `ac_device_history.voltage` |
| 剩余存储容量 | MB | `ac_device_history.storage_free` |
| 在线-离线时间 | 上线 / 离线时刻 | `ac_device.online_dt` / `ac_device.offline_dt` |
| 运行状态 | 采样时刻状态 | `ac_device_history.status` |
| 采样时间 | — | `ac_device_history.sampled_dt` |
| 历史曲线 | 「查看图表」入口 | — |
| 操作 | 查看图表、查看历史运行状态 | — |

**搜索条件**（手册明确列举，全部必须实现）：

1. 运行状态（`status`）
2. 所属区域（`region_id`）
3. 设备名称（模糊）
4. 设备编号（模糊）

**排序**：按采样时间（`sampled_dt`）倒序；同一设备内按时间升序绘制曲线。

### 4.4 设备心跳上报（设备端）

**业务规则**：

- 设备通过 `POST /web/devices/:id/heartbeat`（**ApiKey 鉴权**）上报运行指标。
- 平台收到心跳后**并行做两件事**：

```
   设备心跳（status / battery / voltage / storage_free / 卡号等）
        │
        ├──▶ ① 更新 ac_device（最新快照，供列表展示）
        │      status        := 上报状态
        │      battery       := 上报电量
        │      voltage       := 上报电压
        │      storage_free  := 上报剩余存储
        │      last_beat_dt  := now
        │      online_dt     := now（若由离线转为在线）
        │      offline_dt    := now（若由在线转为离线）
        │
        └──▶ ② 插入 ac_device_history（时序采样，供曲线回放）
               device_id / device_code / iot_card_no / region_id / location
               status / battery / voltage / storage_free / sampled_dt := now
```

- **状态翻转时**：由在线转离线，或设备超过心跳间隔未上报，则按「离线告警」生成
  `ac_alarm_record`（见 `06-设备告警模块.md`）。
- 电量低于阈值生成「电量告警」；物联网卡剩余流量低于阈值生成「流量告警」。
  阈值在「设备告警设置」中按告警类型配置。

## 5. 状态机

### 5.1 设备在线/离线（与告警联动）

```
                设备心跳上报成功
                        │
                        ▼
        ┌───────────────────────────────┐
        │         status = online       │
        │  online_dt := now             │
        │  last_beat_dt := now          │
        │  实时视频 / 录像 可用         │
        └───────────────┬───────────────┘
                        │
        超过心跳间隔未上报（或设备主动离线）
                        │
                        ▼
        ┌───────────────────────────────┐
        │         status = offline      │
        │  offline_dt := now            │
        │  实时视频 / 录像 置灰不可用   │
        └───────────────┬───────────────┘
                        │
                        ├──▶ 生成 ac_alarm_record（告警类型 = offline 离线告警）
                        │    → 按「设备告警设置」推送通知
                        │
                        └──▶ 设备恢复心跳 → 回到 online
```

### 5.2 历史运行状态回放流程

```
   ① 选择「区域」                    ← 必选，未选择则「查看历史运行状态」不可点
        │
        ▼
   ② 点击「查询」                    ← 必须先执行查询
        │
        ▼
   ③ 「查看历史运行状态」按钮由灰变亮
        │
        ▼
   ④ 点击按钮 → 查询 ac_device_history
      过滤条件：region_id = 选中区域
                sampled_dt >= now() - 7 天
      按 device_id 分组，按 sampled_dt 升序
        │
        ▼
   ⑤ 时间轴回放展示每台设备一周的 在线/离线 段
```

### 5.3 历史图表数据流（近 3 日）

```
   选择设备
      │
      ▼
   GET /web/devices/:id/history-chart?days=3
      │
      ▼
   查询 ac_device_history
     WHERE device_id = :id
       AND sampled_dt >= now() - INTERVAL '3 days'
     ORDER BY sampled_dt ASC
      │
      ▼
   聚合为五类图表序列：
     ① 运行状态统计（status 分段统计）
     ② 电量统计（battery 时序）
     ③ 存储容量统计（storage_free 时序）
     ④ 状态与电量统计（status + battery 叠加）
     ⑤ 电压与电量统计（voltage + battery 叠加）
```

## 7. API 接口

### 7.1 设备监控与历史记录（前缀 `/web/devices`）

| 方法 | 路由 | 说明 |
|:---|:---|:---|
| GET | `/web/devices` | 设备监控列表（运行状态/区域/名称/编号筛选，设备编号排序） |
| GET | `/web/devices/:id` | 设备详情（GIS 卡片、设备监控详情、跳转目标） |
| GET | `/web/devices/history` | 设备历史记录分页列表 |
| GET | `/web/devices/:id/history-chart` | 历史图表数据（近 3 日五类统计，`days` 参数） |
| POST | `/web/devices/:id/heartbeat` | 设备心跳上报（**ApiKey 鉴权**，写快照 + 时序） |

### 7.2 关联调用（其它模块提供）

| 方法 | 路由 | 说明 |
|:---|:---|:---|
| GET | `/web/risks` | 「点击设备名称」「查看风险」跳转的目标（按 `device_id` 筛选） |
| GET | `/web/stats/device-status` | 设备在线/离线数量统计（大屏、首页设备统计） |
| GET | `/web/devices/options` | 设备下拉选项（图表页选择设备） |

### 7.3 移动端

| 方法 | 路由 | 说明 |
|:---|:---|:---|
| GET | `/app/devices` | 移动端设备列表 |
| GET | `/app/devices/:id` | 移动端设备详情 |

> **注意**：静态子路径 `/history` 必须注册在 `/:id` 之前，否则 `history` 会被当作设备 ID
> 匹配。本模块 Handler 为 `deviceH`（`internal/api/handler/web/device_handler.go`），
> Swagger Tag 为 `Device`；分页响应必须使用类型化的 `RPageDevice` / `RPageDeviceHistory`，
> 图表响应使用 `RDeviceHistoryChart`。
