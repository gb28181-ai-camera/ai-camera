# 资源管理模块

> 版本: v0.1.0
> 最后更新: 2026-09-21
> 需求来源: AI摄像头操作手册 第 8.1 节

## 1. 模块概述

资源管理模块维护平台的**物理资产台账**，是 AI 风险数据产生的源头：

- **设备管理**：AI 摄像头设备主数据。每台设备归属一个区域、绑定一张物联网卡、运行一个
  固件与 AI 模型版本、处于某种工作模式与设备模式。设备台账上直接提供「同步时间」「设备监控」
  「切换设备模式」三个快捷操作。
- **语音配置管理**：为风险类型配置现场播报音频，设备识别到风险时播放对应音频（如
  「请佩戴安全帽」）。
- **物联网卡管理**：管理设备所用的 4G/5G 物联网卡，跟踪流量总额、已用、剩余与到期时间。
- **物联网卡更换记录**：物联网卡在设备间更换的审计流水，保留设备与区域的**冗余快照**，
  使得设备改名或迁移后历史仍可追溯。
- **设备模式管理**：设备工作模式字典（当前内置充电模式、全开模式、省电模式）。

> **注意**：设备的运行时指标（电量、电压、存储、在线时间）由设备心跳上报写入 `ac_device`
> 作为**最新快照**，同时写入 `ac_device_history` 作为**时序历史**。前者供列表展示，后者供
> 「设备历史记录」曲线回放（见 `05-设备监控模块.md`）。

## 2. 角色与权限

| 角色 | 可执行操作 |
|:---|:---|
| 系统管理员 | 设备/语音配置/物联网卡/更换记录/设备模式的全部增删改查、同步时间、切换模式、切换监控 |
| 区域管理员 | 同上（受数据权限约束，仅本部门及授权部门数据） |

### 3.2 ac_device - 设备

```sql
CREATE TABLE ac_device (
    id              BIGSERIAL PRIMARY KEY,
    deleted_at      TIMESTAMPTZ,
    created_by      VARCHAR(50),
    created_dt      TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    updated_by      VARCHAR(50),
    updated_dt      TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,

    active          BOOLEAN DEFAULT TRUE,                  -- 是否启用
    name            VARCHAR(255) NOT NULL,                 -- 设备名称
    device_code     VARCHAR(100) NOT NULL,                 -- 设备编号
    region_id       BIGINT,                                -- 所属区域
    location        VARCHAR(255),                          -- 设备位置
    latitude        VARCHAR(32),                           -- 纬度(GIS)
    longitude       VARCHAR(32),                           -- 经度(GIS)

    -- 版本与模式
    firmware_id     BIGINT,                                -- 当前固件ID
    firmware_ver    VARCHAR(50),                           -- 当前固件版本(冗余便于列表展示)
    model_id        BIGINT,                                -- 当前AI模型ID
    model_ver       VARCHAR(50),                           -- 当前模型版本
    system_ver      VARCHAR(50),                           -- 系统版本
    work_mode       VARCHAR(50),                           -- 设备工作模式
    device_mode     VARCHAR(50),                           -- 设备模式(充电/全开/省电)
    info_interval   INTEGER DEFAULT 60,                     -- 信息上传间隔(秒)

    -- 物联网卡
    iot_card_id     BIGINT,                                -- 物联网卡ID

    -- 运行时状态（设备心跳/平台探测更新）
    status          VARCHAR(20) DEFAULT 'offline',         -- 运行状态 online/offline
    battery         INTEGER,                               -- 电量百分比
    voltage         VARCHAR(32),                           -- 电压
    storage_total   BIGINT,                                -- 存储总容量(MB)
    storage_free    BIGINT,                                -- 剩余存储容量(MB)
    online_dt       TIMESTAMPTZ,                           -- 最近上线时间
    offline_dt      TIMESTAMPTZ,                           -- 最近离线时间
    last_beat_dt    TIMESTAMPTZ,                           -- 最近心跳时间

    -- 实时监控
    monitor_enabled BOOLEAN DEFAULT FALSE,                 -- 是否加入实时监控
    stream_url      VARCHAR(500),                          -- 实时视频流地址
    remark          VARCHAR(500),                          -- 备注

    dept_id         BIGINT                                 -- 所属部门(数据权限)
);
CREATE UNIQUE INDEX idx_ac_device_code ON ac_device (device_code);
CREATE INDEX idx_ac_device_region_id ON ac_device (region_id);
CREATE INDEX idx_ac_device_dept_id ON ac_device (dept_id);
CREATE INDEX idx_ac_device_deleted_at ON ac_device (deleted_at);

COMMENT ON TABLE ac_device IS 'AI 摄像头设备';
COMMENT ON COLUMN ac_device.device_code IS '设备编号';
COMMENT ON COLUMN ac_device.firmware_ver IS '当前固件版本(冗余便于列表展示)';
COMMENT ON COLUMN ac_device.device_mode IS '设备模式(充电/全开/省电)';
COMMENT ON COLUMN ac_device.info_interval IS '信息上传间隔(秒)';
COMMENT ON COLUMN ac_device.status IS '运行状态 online/offline';
COMMENT ON COLUMN ac_device.monitor_enabled IS '是否加入实时监控';
```

## 4. 功能需求

### 4.1 设备管理

**操作说明**（手册 8.1.1）：

- 设备管理中可查看所有设备的相关信息，包括设备名称、设备编号、所属区域、设备位置、模型、系统版本、设备工作模式、设备模式、信息间隔、状态、设备监控等相关内容。
- 排序：点击设备编号，可根据设备编号进行正序或倒序排序。
- 点击编辑，可对其内容进行修改；
- 点击删除，并确认删除后，可对该条数据进行删除；
- 选择状态、所属区域、设备名称、设备编号、设备模式等条件进行搜索；
- 点击新增，可新增设备信息，其中所属区域、设备工作模式、物联网卡中数据分别与区域管理、设备模式管理、物联网卡管理中数据相关联；
- 点击列表中设备模式，可切换设备模式；
- 点击设备监控按钮，此设备会在实时监控-设备监控中展示。
- 同步时间：点击同步时间，可同步设备与服务器时间。

**业务规则**：

- **「同步时间」**：点击后由平台向设备下发对时指令，使**设备时间与服务器时间一致**。
  设备时间偏移会导致风险记录的「发生时间」错乱，因此新装设备应首先执行同步时间。
  接口：`PUT /web/devices/:id/sync-time`。
- **「设备监控」按钮**：点击后置 `monitor_enabled=true`，该设备随即出现在
  「实时监控 → 设备监控」画面中；再次点击可移出（`monitor_enabled=false`）。
  接口：`PUT /web/devices/:id/monitor`。
- **「点击设备模式可切换」**：列表中设备模式列本身可点击，弹出模式选择后即时切换设备
  工作模式，**无需进入编辑页**。接口：`PUT /web/devices/:id/mode`。
- **新增表单联动**：
  - 所属区域 ← 区域管理（`ac_region`）；
  - 设备工作模式 ← 设备模式管理（`ac_device_mode`）；
  - 物联网卡 ← 物联网卡管理（`ac_iot_card`）。
- **设备编号全局唯一**（唯一索引 `idx_ac_device_code`），重复时提示已存在。
- 删除为软删除（`deleted_at`），确认后执行；点取消不删除。
- 设备一旦产生风险/告警/历史数据，建议改为禁用而非删除。

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 设备名称 | — | `ac_device.name` |
| 设备编号 | 可点击排序 | `ac_device.device_code` |
| 所属区域 | 关联区域名称 | `ac_region.name` |
| 设备位置 | — | `ac_device.location` |
| 模型 | 当前 AI 模型名称 | `ac_ai_model.name`（经 `model_id`） |
| 系统版本 | — | `ac_device.system_ver` |
| 设备工作模式 | — | `ac_device.work_mode` |
| 设备模式 | 可点击切换 | `ac_device.device_mode` |
| 信息间隔 | 信息上传间隔（秒） | `ac_device.info_interval` |
| 状态 | 在线/离线 | `ac_device.status` |
| 设备监控 | 加入监控按钮 | `ac_device.monitor_enabled` |
| 操作 | 编辑、删除、同步时间、设备监控 | — |

**搜索条件**：状态（`status`）、所属区域（`region_id`）、设备名称（模糊）、设备编号
（模糊）、设备模式（`device_mode`）。

**排序**：**点击设备编号列头可正序 / 倒序排序**（默认按设备编号升序）。

### 4.2 语音配置管理

**操作说明**（手册 8.1.2）：

- 语音配置管理中可配置风险类型的播报音频，包括语音名称、语音类型、所属区域、应用设备、播报音频等相关内容。
- 点击下载文件，可下载音频文件；
- 点击试听，可试听该风险配置的音频；
- 点击修改，可对其内容进行修改；
- 点击删除，并确认删除后，可对该条数据进行删除；
- 输入语音名称、语音类型、所属设备等条件进行搜索；
- 点击新建，可配置风险的语音播报，其中语音类型、所属区域、应用设备中数据分别与风险管理、区域管理、设备管理中数据相关联。

**业务规则**：

- **「下载文件」**：下载 `audio_url` 指向的音频文件（文件名取 `audio_name`）。
- **「试听」**：浏览器内直接播放该音频，不下载。
- **「修改」**：修改语音名称、语音类型、所属区域、应用设备、播报音频。
- **「删除」**：确认后软删除；点取消不删除。
- **新建表单联动**：
  - 语音类型 ← 风险类型管理（`ac_risk_type`，写入 `risk_type_id` 与 `voice_type`）；
  - 所属区域 ← 区域管理（`ac_region`）；
  - 应用设备 ← 设备管理（`ac_device`）。
- 音频文件通过 `POST /web/upload/audio` 上传，返回 URL 后写入 `audio_url`。
- 风险记录落库时若匹配到该风险类型的语音配置且设备归属区域/设备匹配，则播放音频并置
  `ac_risk_record.voice_played=true`。

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 语音名称 | — | `ac_voice_config.name` |
| 语音类型 | 关联风险类型名称 | `ac_risk_type.name`（经 `risk_type_id`） |
| 所属区域 | — | `ac_region.name` |
| 应用设备 | — | `ac_device.name` |
| 播报音频 | 音频文件名，提供下载与试听 | `ac_voice_config.audio_name` / `audio_url` |
| 状态 | 启用/禁用 | `ac_voice_config.active` |
| 创建时间 | — | `ac_voice_config.created_dt` |
| 操作 | 下载文件、试听、修改、删除 | — |

**搜索条件**：语音名称（模糊）、语音类型（`risk_type_id`）、所属设备（`device_id`）；
扩展支持所属区域（`region_id`）。

**排序**：按创建时间倒序。

### 4.3 物联网卡管理

**操作说明**（手册 8.1.3）：

- 物联网卡管理中可查看物联网卡相关信息，包括物联网卡名称、卡号、所属区域、所属设备、流量总额、剩余流量、到期时间、状态等相关内容。
- 点击编辑，可对其内容进行修改；
- 点击删除，并确认删除后，可对该条数据进行删除；
- 选择所属区域、物联网卡名称、卡号、所属设备等条件进行搜索；
- 点击新增，可新增物联网卡，其中所属区域中数据与区域管理中数据相关联。

**业务规则**：

- 卡号（`card_no`）全局唯一。
- 流量字段单位为 **MB**：`traffic_total`（总额）、`traffic_used`（已用）、`traffic_left`
  （剩余）；三者关系为 `left = total - used`，由平台在流量同步时计算写入。
- `stat_dt` 记录本次流量统计的时间点，用于展示数据新鲜度。
- `expire_dt` 到期时间；临近到期或流量不足时由「设备告警」按流量告警类型触发告警
  （阈值在「设备告警设置」中配置）。
- **新增时「所属区域」下拉来自区域管理**。
- 更换物联网卡请走「物联网卡更换记录」的新增流程，不要直接改写已有卡的归属，以保证审计链完整。

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 物联网卡名称 | — | `ac_iot_card.name` |
| 卡号 | — | `ac_iot_card.card_no` |
| 所属区域 | — | `ac_region.name` |
| 所属设备 | — | `ac_device.name` |
| 流量总额 | MB | `ac_iot_card.traffic_total` |
| 已使用流量 | MB | `ac_iot_card.traffic_used` |
| 剩余流量 | MB | `ac_iot_card.traffic_left` |
| 到期时间 | — | `ac_iot_card.expire_dt` |
| 统计时间 | 流量数据时间点 | `ac_iot_card.stat_dt` |
| 状态 | 正常/欠费/到期/停用 | `ac_iot_card.status` |
| 操作 | 编辑、删除 | — |

**搜索条件**：所属区域（`region_id`）、物联网卡名称（模糊）、卡号（模糊）、所属设备
（`device_id`）。

**排序**：按创建时间倒序；即将到期的卡可置顶提示。

### 4.4 物联网卡更换记录

**操作说明**（手册 8.1.4）：

- 物联网卡更换记录中可查看物联网卡的更换记录信息，包括设备名称、设备编号、所属区域、设备位置、物联网卡、更换时间、操作人等相关内容。
- 选择所属区域、设备名称、设备编号、物联网卡、更换时间等条件进行搜索。

**业务规则**：

- 本表**追加写入，不做修改**（无编辑入口），保证审计不可篡改。
- 新增一条更换记录时，平台同时：
  1. 写入 `ac_iot_card_replace_log`（含设备与区域的冗余快照）；
  2. 更新 `ac_device.iot_card_id` 为新卡；
  3. 更新新卡的 `ac_iot_card.device_id` 为本设备，并清空原卡的 `device_id`。
- **冗余快照说明**：`device_code`（设备编号）、`region_id`（所属区域）、`location`
  （设备位置）为更换当时的快照；**「设备名称」通过 `device_id` 关联 `ac_device.name` 实时读取**。
  两者结合，既能反映当前设备名，也能还原更换当时的位置与归属。
- **「物联网卡」列**展示原卡号 → 新卡号（`old_card_no → new_card_no`）；若是首次装卡，
  原卡号为空。
- `operator` 由登录上下文自动填充为当前操作人。
- 记录不可删除；若录入有误，由管理员在数据库层面更正并留痕。

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 设备名称 | 实时关联 | `ac_device.name`（经 `device_id`） |
| 设备编号 | **冗余快照** | `ac_iot_card_replace_log.device_code` |
| 所属区域 | **冗余快照** | `ac_iot_card_replace_log.region_id` |
| 设备位置 | **冗余快照** | `ac_iot_card_replace_log.location` |
| 物联网卡 | 原卡号 → 新卡号 | `old_card_no` / `new_card_no` |
| 更换时间 | — | `ac_iot_card_replace_log.replace_dt` |
| 操作人 | — | `ac_iot_card_replace_log.operator` |
| 备注 | — | `ac_iot_card_replace_log.remark` |

**搜索条件**：所属区域（`region_id`）、设备名称（关联 `ac_device.name` 模糊）、设备编号
（`device_code` 模糊）、物联网卡（`old_card_no` / `new_card_no` 模糊）、更换时间（区间）。

**排序**：按更换时间倒序。

### 4.5 设备模式管理

**操作说明**（手册 8.1.5）：

- 设备模式管理中可配置设备的工作模式，包括模式名称、备注、创建时间等相关内容。
- 点击编辑，可对其内容进行修改；
- 点击删除，并确认删除后，可对该条数据进行删除；
- 输入模型名称进行搜索；
- 点击新增，可配置设备的工作模式（目前工作模式仅包括充电模式、全开模式、省电模式）。

**业务规则**：

- **当前内置三种模式**：充电模式、全开模式、省电模式。表结构允许扩展，但手册明确
  「目前工作模式仅包括」这三种。
- 模式名称必填；`code` 用于设备端协议对接，建议使用英文短码
  （`charging` / `always_on` / `power_save`）。
- 设备模式被「设备管理」的新增/编辑表单作为下拉引用；也被列表中的「点击设备模式切换」使用。
- 删除模式前应先确认无设备正在使用；`ac_device.device_mode` 存的是模式文本（非外键），
  删除字典项不会破坏已有设备记录。
- 支持启用/禁用。

> **注意**：手册原文写「输入**模型名称**进行搜索」，从上下文判断应为「输入**模式名称**
> 进行搜索」的笔误——本页管理的对象是设备模式，不含模型。实现时按**模式名称**模糊搜索。

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 模式名称 | — | `ac_device_mode.name` |
| 模式编码 | 设备端协议标识 | `ac_device_mode.code` |
| 排序 | — | `ac_device_mode.sequence` |
| 状态 | 启用/禁用 | `ac_device_mode.active` |
| 备注 | — | `ac_device_mode.remark` |
| 创建时间 | — | `ac_device_mode.created_dt` |
| 操作 | 编辑、删除 | — |

**搜索条件**：模式名称（模糊匹配 `name`）。

**排序**：按 `sequence` 升序。

## 5. 状态机

### 5.1 设备运行状态

```
   ┌──────────────────┐   心跳上报 / 平台探测可达   ┌──────────────────┐
   │     online       │ ─────────────────────────▶ │     offline      │
   │     在线         │ ◀───────────────────────── │     离线         │
   │ online_dt 更新   │   超过心跳间隔未上报         │ offline_dt 更新  │
   └──────────────────┘                            └──────────────────┘
                            │
                            └──▶ 离线达阈值 → 生成 ac_alarm_record
                                 （告警类型 = offline，见 06 模块）
```

### 5.2 设备监控开关

```
   ┌──────────────────────┐   点击「设备监控」   ┌──────────────────────┐
   │  monitor_enabled     │ ───────────────────▶ │  monitor_enabled     │
   │     = false          │                      │     = true           │
   │  不在实时监控画面     │ ◀─────────────────── │ 出现在实时监控-设备监控│
   └──────────────────────┘   再次点击           └──────────────────────┘
```

### 5.3 物联网卡状态

```
   ┌──────────┐  欠费   ┌──────────┐
   │  normal  │ ──────▶ │ arrears  │
   │  正常    │ ◀────── │  欠费    │
   └────┬─────┘  缴清   └──────────┘
        │
        │ 到期
        ▼
   ┌──────────┐  管理员停用   ┌───────────┐
   │ expired  │ ────────────▶ │ disabled  │
   │  到期    │ ◀──────────── │   停用    │
   └──────────┘   重新启用    └───────────┘
```

### 5.4 物联网卡更换流程

```
   选择设备 + 选择新卡
          │
          ▼
   校验：新卡未被其他设备占用
          │
          ├── 已被占用 ──▶ 拒绝，提示「该卡已绑定其他设备」
          │
          ▼
   ① 写入 ac_iot_card_replace_log
      （device_id / device_code / region_id / location 快照
        + old_iot_card_id / old_card_no + new_iot_card_id / new_card_no
        + replace_dt + operator）
   ② ac_device.iot_card_id := 新卡ID
   ③ ac_iot_card(新卡).device_id := 本设备ID
   ④ ac_iot_card(旧卡).device_id := NULL
          │
          ▼
   记录出现在「物联网卡更换记录」列表（只读，不可修改）
```

### 5.5 设备模式切换

```
   点击列表中的「设备模式」列
          │
          ▼
   弹出模式选择（来自 ac_device_mode，active=true）
          │
          ▼
   PUT /web/devices/:id/mode
          │
          ▼
   ac_device.device_mode 更新 → 设备端收到模式指令
   （充电模式 / 全开模式 / 省电模式）
```
