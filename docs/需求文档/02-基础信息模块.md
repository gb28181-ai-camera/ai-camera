# 基础信息模块

> 版本: v0.1.0
> 最后更新: 2026-09-21
> 需求来源: AI摄像头操作手册 第 8.4 节

## 1. 模块概述

基础信息模块维护平台的**三张核心字典**：区域、风险类型、告警类型。它们是全平台的公共
维度，被几乎所有业务表引用：

- **区域**：设备、风险记录、告警记录、巡检任务、巡检记录、物联网卡、语音配置、升级计划、
  升级记录全部带 `region_id`；所有列表页都支持「所属区域」筛选；GIS 地图与可视化大屏的
  区域统计也基于它。
- **风险类型**：AI 识别结果的分类（如未戴安全帽、明火、人员闯入）。风险等级（high /
  medium / low）驱动首页与大屏的分级配色，也是风险通知设置与语音配置的关联对象。
- **告警类型**：设备自身状态类告警的分类，**平台内置离线告警、电量告警、流量告警**三种，
  也可自定义扩展。告警类型是「设备告警设置」的通知策略维度。

> **注意**：操作手册开篇的日常操作流程把「新建区域」列为**第一步**——区域未建立时，
> 设备、风险、告警均无法归属，因此本模块是平台初始化的起点。

## 2. 角色与权限

| 角色 | 可执行操作 |
|:---|:---|
| 系统管理员 | 区域/风险类型/告警类型的全部增删改查 |
| 区域管理员 | 区域/风险类型/告警类型的全部增删改查（受数据权限约束） |
| 安全员 | 只读查看（用于筛选条件选择） |
| 设备运维员 | 只读查看（新增设备时选择区域） |
| 巡检员 | 只读查看（移动端） |

权限码：

| 权限码 | 说明 |
|:---|:---|
| `region:list` / `region:create` / `region:update` / `region:delete` | 区域管理 |
| `riskType:list` / `riskType:create` / `riskType:update` / `riskType:delete` | 风险类型管理 |
| `alarmType:list` / `alarmType:create` / `alarmType:update` / `alarmType:delete` | 告警类型管理 |

> **注意**：三个字典表都带 `dept_id`，其列表与下拉选项受**数据权限**行级过滤
> （`utils.NewDataScope(c).ApplyToQuery(q, "<alias>.dept_id")`）。

### 3.2 ac_region - 区域

```sql
CREATE TABLE ac_region (
    id              BIGSERIAL PRIMARY KEY,
    deleted_at      TIMESTAMPTZ,
    created_by      VARCHAR(50),
    created_dt      TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    updated_by      VARCHAR(50),
    updated_dt      TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,

    active          BOOLEAN DEFAULT TRUE,                  -- 是否启用
    sequence        INTEGER DEFAULT 10,                    -- 排序
    name            VARCHAR(255) NOT NULL,                 -- 区域名称
    code            VARCHAR(50),                           -- 区域编码
    remark          VARCHAR(500),                          -- 备注
    dept_id         BIGINT                                 -- 所属部门(数据权限)
);
CREATE INDEX idx_ac_region_dept_id ON ac_region (dept_id);
CREATE INDEX idx_ac_region_deleted_at ON ac_region (deleted_at);

COMMENT ON TABLE ac_region IS '区域。设备、风险、告警、巡检的核心归属维度';
COMMENT ON COLUMN ac_region.name IS '区域名称';
COMMENT ON COLUMN ac_region.code IS '区域编码';
COMMENT ON COLUMN ac_region.dept_id IS '所属部门(数据权限)';
```

## 4. 功能需求

### 4.1 区域管理

**操作说明**（手册 8.4.1）：

- 区域管理中包括区域名称、备注、创建时间等相关内容。
- 点击新增可添加区域；
- 点击编辑可修改区域内容；
- 输入区域名称进行搜索。

**业务规则**：

- 区域名称必填（`name` 非空）；区域编码（`code`）可选，建议填写以便与外部系统对接。
- 区域支持启用/禁用（`active`）。**禁用后不再出现在设备、风险等页面的区域下拉中**，
  但历史数据仍展示原区域名称。
- 区域支持排序（`sequence`），从小到大升序展示。
- 本文档未列「删除」操作条目：手册 8.4.1 仅描述新增/编辑/搜索。系统提供删除能力，但
  **区域已被设备、风险、告警、巡检等业务数据引用时禁止删除**，应提示改为禁用。
- 区域是**数据权限的次要维度**：区域本身带 `dept_id`，按部门过滤后，用户只能看到
  自己权限范围内的区域。

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 编号 | 主键 | `ac_region.id` |
| 区域名称 | — | `ac_region.name` |
| 区域编码 | — | `ac_region.code` |
| 排序 | — | `ac_region.sequence` |
| 状态 | 启用/禁用 | `ac_region.active` |
| 备注 | — | `ac_region.remark` |
| 创建时间 | — | `ac_region.created_dt` |

**搜索条件**：区域名称（模糊匹配 `name`）；扩展支持状态（`active`）。

**排序**：按 `sequence` 升序，其次按创建时间倒序。

### 4.2 风险类型管理

**操作说明**（手册 8.4.2）：

- 风险类型管理中包括风险类型、风险编码、风险等级、描述、创建时间等相关内容。
- 点击新增可新增风险类型、风险等级、风险编码等信息；
- 点击编辑，可修改风险内容；
- 输入风险类型进行搜索；
- 点击删除，并确认删除后，可对该条数据进行删除。

**业务规则**：

- 新增时需填写**风险类型名称**（必填）、**风险等级**、**风险编码**。
- **风险等级**三选一：高（`high`）/ 中（`medium`，默认）/ 低（`low`）。等级用于：
  - 风险记录落库时冗余到 `ac_risk_record.risk_level`；
  - 首页「风险类型分析」与可视化大屏「风险统计」按等级配色与聚合。
- 风险编码（`code`）用于设备端上报时标识风险类型，建议使用英文短码（如 `no_helmet`、
  `fire`、`intrusion`），保证与固件/模型输出一致。
- 风险类型支持启用/禁用；**禁用后不再出现在「风险通知设置」「语音配置管理」的类型下拉中**。
- **点击删除并确认后执行删除**；已被风险记录引用的类型禁止删除。
- 风险类型是「语音配置管理」的语音类型关联对象（`ac_voice_config.risk_type_id`）。

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 编号 | 主键 | `ac_risk_type.id` |
| 风险类型 | 名称 | `ac_risk_type.name` |
| 风险编码 | 设备上报标识 | `ac_risk_type.code` |
| 风险等级 | 高/中/低 | `ac_risk_type.level` |
| 描述 | — | `ac_risk_type.description` |
| 排序 | — | `ac_risk_type.sequence` |
| 状态 | 启用/禁用 | `ac_risk_type.active` |
| 创建时间 | — | `ac_risk_type.created_dt` |

**搜索条件**：风险类型（模糊匹配 `name`）；扩展支持风险等级（`level`）、状态（`active`）。

**排序**：按 `sequence` 升序，其次创建时间倒序。

### 4.3 告警类型管理

**操作说明**（手册 8.4.3）：

- 平台内置的告警类型管理中包含告警名称、告警编码、告警等级、创建时间等相关信息。

**业务规则**：

- 手册明确本节为「**平台内置**」，即离线告警、电量告警、流量告警三种**由系统初始化写入**，
  用户无需手工创建。
- 三个内置类型的编码必须与后端常量一致：`offline` / `battery` / `traffic`。设备上报
  告警时通过编码匹配类型。
- 平台同时支持**自定义扩展**告警类型（表结构已预留 `level`、`description`、`dept_id`）。
- 告警类型是「设备告警设置」的配置维度：每个用户可对每种告警类型单独配置通知人员、
  通知类型与报警频率（见 `10-首页与告警设置模块.md`）。
- 内置类型不建议删除；若需停用，使用启用/禁用开关。

**列表字段**：

| 字段 | 说明 | 来源表 |
|:---|:---|:---|
| 编号 | 主键 | `ac_alarm_type.id` |
| 告警名称 | — | `ac_alarm_type.name` |
| 告警编码 | offline/battery/traffic 或自定义 | `ac_alarm_type.code` |
| 告警等级 | 高/中/低 | `ac_alarm_type.level` |
| 描述 | — | `ac_alarm_type.description` |
| 排序 | — | `ac_alarm_type.sequence` |
| 状态 | 启用/禁用 | `ac_alarm_type.active` |
| 创建时间 | — | `ac_alarm_type.created_dt` |

**搜索条件**：告警名称（模糊）、告警编码（精确）、告警等级（`level`）、状态（`active`）。

**排序**：按 `sequence` 升序，内置三项排序为 1 / 2 / 3。

## 5. 状态机

### 5.1 字典项启用状态

```
     ┌──────────────────┐   点击「禁用」   ┌──────────────────┐
     │     启用          │ ───────────────▶ │     禁用          │
     │  active = true    │                  │  active = false   │
     │ 出现在下拉与筛选  │ ◀─────────────── │ 不出现在下拉      │
     └──────────────────┘   点击「启用」   │ 历史数据仍可展示  │
                                          └──────────────────┘
```

### 5.2 引用保护流程（删除字典项）

```
点击「删除」
     │
     ▼
检查是否被业务表引用
  ac_region      ← ac_device / ac_risk_record / ac_alarm_record /
                    ac_inspect_task / ac_inspect_record / ac_iot_card /
                    ac_voice_config / ac_device_upgrade_plan / ac_device_upgrade_record
  ac_risk_type   ← ac_risk_record / ac_voice_config / ac_risk_notify_setting
  ac_alarm_type  ← ac_alarm_record / ac_alarm_setting
     │
     ├── 未被引用 ──▶ 确认后软删除（deleted_at 置值）
     │
     └── 已被引用 ──▶ 拒绝删除，提示「该记录已被业务数据引用，请改为禁用」
```
