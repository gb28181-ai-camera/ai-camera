# v0.6.0 智能语音聊天实现说明

> 日期：2026-10-25
> 协议：[00-设计与协议.md](./00-设计与协议.md)

## 1. 已实现

### Pipecat（deploy/pipecat）

- 新增 `WS /ws/voice`，与现有 GB28181 RTP `/session/start` 并存。
- 小智兼容子集：`hello / listen(detect|start|stop) / abort / stt / llm / tts / mcp / tool / error / wake / ping / pong`。
- PCM16（App/Web）与 Opus（ESP32）协商；上行 16k、下行 24k。
- 半双工 gate：TTS 期间丢弃上行 + 300ms 尾巴；`abort` 打断。
- 快速应答：`fast_ack_text`（默认「我在」）文字立即下发，PCM 缓存后台预热。
- 服务端 MCP：HTTP JSON-RPC → Go `/internal/mcp`，工具映射为 FunctionSchema。
- 设备端 MCP：同一 WS 上 `type=mcp` JSON-RPC bridge，工具名 `device_*` 映射。
- 记忆：短上下文 + 摘要；会话开始注入长期记忆，结束写摘要。
- 鉴权：`PIPECAT_TOKEN` + `X-Voice-Context` HMAC-SHA256。

### Go 后端

- 8 张新表 + `ac_voice_session` 扩展；pgvector 1024 维 + HNSW。
- `POST /web/voice/ws-ticket`、`POST /app/voice/ws-ticket`；60s 一次性 ticket。
- WS 网关：`/web/voice/ws`、`/app/voice/ws`、`/device/voice/ws`，反向代理 Pipecat。
- 内部 MCP：`POST /internal/mcp`（6 个工具、权限、确认、审计）。
- 记忆：`/internal/voice/memory/{retrieve,write}`；Web 列表/删除/导出。
- 管理：`/web/voice/mcp/tools`、`/web/voice/mcp/logs`。
- 配置键：`ws_enabled`、`fast_ack_text`、`mcp_enabled`、`memory_*`、`embedding_*` 等。

### Flutter App

- `VoiceWsClient`：ticket、hello、listen、abort、stt/llm/tts、二进制 PCM16、重连。
- `VoiceAudioSession`：record 采集 16k PCM16、flutter_sound 边收边播 24k。
- `VoiceChatPage`：按住说话、半双工、字幕、MCP 工具提示、错误/重连。
- 入口：首页与国标实时播放页。

### Web 管理端

- `/voice/agent` 新页面：基础 / WebSocket / MCP / 记忆 / 观测。
- 连接测试：获取 ticket → 连 Go 网关 → 展示服务端 hello。
- MCP 工具编辑、调用日志、记忆列表/删除/CSV 导出。

### Embedding 与向量落库（2026-10-25 补齐）

- 新增 `deploy/embedding`：OpenAI-compatible `/v1/embeddings`，默认
  `BAAI/bge-m3`（1024 维），支持两种加载方式：
  - `EMBEDDING_MODEL_DIR` 指向离线 ONNX 目录（`model.onnx` + `model.onnx_data` +
    `tokenizer.json`），用 onnxruntime 直接推理；
  - 未配置目录时回退 fastembed（需要 HuggingFace 可达）。
- 模型文件从 ModelScope 下载（HuggingFace 在内网不可达），
  compose 保存到 `embedding_models` 卷；启动约 2.5s，`/health` 返回
  `source=onnx / loaded=true / dim=1024`。
- Go `EmbeddingClient` 写入前真实调用 `/v1/embeddings`，成功后
  `ac_voice_memory.embedding` 落 1024 维向量、`embedding_status=ok`；
  检索用 pgvector 余弦距离，失败才降级关键词/时间。
- 新增管理端点：
  - `POST /web/voice/embedding/test`：返回模型、维度、耗时；
  - `POST /web/voice/memories/backfill`：为历史 `failed/pending` 记忆补向量，
    分批最多 500 条，返回 `scanned/updated/failed/remaining`。
- Web「记忆」页新增「测试 Embedding」「历史记忆重建向量」按钮。

### STT / TTS 配置与离线模型（2026-10-25 补齐）

- 配置仍走 `ac_thirdparty_config(Category='voice_agent')`：
  - STT：`stt_provider=local_whisper`、`stt_model=small`、`stt_language=zh`；
  - TTS：`tts_provider=edge_tts`、`tts_voice=zh-CN-XiaoxiaoNeural`、`tts_speed=1.0`；
  - VAD：`vad_provider=silero`；
  - 上述默认值已写入 `01-初始数据.sql`，只插入不存在的键，不覆盖管理员修改。
- 离线 STT：`Systran/faster-whisper-small` 从 ModelScope 下载到
  `whisper_models` 卷 `/models/faster-whisper-small`。Pipecat 在
  `pipeline._instantiate_service` 中自动把裸模型名 `small` 映射到
  `/models/faster-whisper-small`，无需在配置里写绝对路径。
- 实测（容器内）：
  - Edge TTS 合成中文 15,984 bytes 音频；
  - faster-whisper 转写为「请确认东门摄像头,今天有没有发现,未带安全帽的人员?」，
    `language=zh`、概率 1.0；
  - Pipecat `/test`：stt/tts/vad 均 `ok=true`，LLM 因未配置 `llm_api_key`
    返回 `ok=false`（这是预期）。

### 设备能力补齐（2026-10-25）

**安防相机（GB28181）**

- 后端既有 `OnAlarm` / `OnMobilePosition` 落 `ac_gb_alarm` /
  `ac_gb_mobile_position`；本轮补齐模拟器：
  `gbsim --alarm-interval 15s --position-interval 10s`。

**适老化相机（WebRTC / AIChat）**

- WebRTC：房间信令新增 `invite/agree/reject/hangup`；
  - App ticket：`POST /app/av/devices/:id/call-ticket`（role=app，校验设备已绑定用户）；
  - App WS：`GET /app/av/ws`；
  - 设备 invite 时只投给 role=app 的连接，Web 预览不受打扰；
  - 无在线 App → 个推离线通知（`POST /app/push-tokens` 上报 CID）。
- MQTT 上报：`iot/<group>/device/<code>/report`，支持
  `heartbeat/battery/position/alarm`；告警落 `ac_alarm_record`，
  位置落 `ac_iot_device_position`，电量/最新经纬度同步 `ac_device`。
- 内置告警类型新增 `fall` / `sos`。
- App：新增 `AppAvCallClient` 与 `/iot/call` 页面，设备列表增加通话入口。

## 3. 已知限制

1. ticket 一次性存储为进程内，多副本需 Redis。
2. WS 网关不解析 `hello`，`ac_voice_session.input_format/output_format/turn_count` 未自动填充。
3. 设备 Basic 是产品级凭据；未传 `device_code` 时上下文 `device_id=0`。
4. `ptz.control` 依赖内嵌 SIP 控制面；分进程部署时不可用。
5. 写工具的人类确认 UI 未做；当前由 LLM 在参数里传 `confirm=true`。
6. 长期记忆的逐轮事实抽取未做，当前只写会话摘要；Embedding 已可用，语义检索依赖 `embedding_endpoint` 可访问。
7. LLM 仍需管理员填写可用的 `llm_api_key`；未配置时语音握手/STT/TTS 可用，但完整对话不可用。
8. RTP 路径仍存在 Pipecat 1.13 aggregator/VAD 的既有不兼容，本次未改（WS 不受影响）。
9. 真实 ESP32/Opus、真机 AEC、100 并发压力测试未验证。
