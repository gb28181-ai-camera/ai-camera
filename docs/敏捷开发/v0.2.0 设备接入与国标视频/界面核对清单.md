## 16. 有意差异（避免被当成漏做）

| # | WVP 行为 | 本项目行为 | 理由 |
|:--|:--|:--|:--|
| 1 | 通道字段保留设备上报原值 + 用户定制值双列 | 单列 + 定制覆盖 | 设计 §11+.3 #1 |
| 2 | 录像计划 `start/stop` 用分钟整数 | `HH:mm:ss` 字符串 | 设计 §11+.3 #2 |
| 3 | 云端录像支持合并打包下载 | 只做单文件下载 | 设计 §11+.3 #3 |
| 4 | 电子地图使用高德 / 天地图瓦片 | 不引入地图库，CSS 打点 + ECharts 坐标图 | 本轮明确要求；减少外部依赖与授权风险 |
| 5 | 级联会向上级 REGISTER 并推送目录 | 只做配置与可见范围映射 | 本期信令范围（设计 §1.4） |
| 6 | 推流由平台持续向外部推流 | 只维护配置状态，外部编码器按 `push_url` 推流 | 后端无持续推流能力 |
| 7 | 录像计划由调度器自动触发 | 只落库，不触发 | 后端无调度器 |
| 8 | 媒体节点有 CPU/内存/磁盘/网络趋势面板 | 只有线程负载 + 在线检查 | 缺 ZLM 系统指标接口 |
